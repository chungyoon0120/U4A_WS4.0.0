# AGENTS.md — 별창 팝업 개발 규칙 (이 폴더 스코프)

이 폴더(`Popups/`) 아래에서 **별창 팝업을 만들거나 고칠 때는 반드시 공통 UX 가드레일을 따른다.**

→ 규칙 원문: **`_common-ux-bundle/GUARDRAIL.md`** (레포 루트) 를 먼저 읽고 그대로 따를 것.

핵심(자세한 건 위 GUARDRAIL 참고):

1. **착수 전 구조 설계(자율)** — 화면 그리기 전에 ① 팝업 이름 확정 → ② `ux-gallery.html`·`.analy/16`·`15` 를 먼저 확인해 UX 구조(영역·배치·쓰는 공통 부품)를 표준대로 정함 → ③ 그대로 구현(임의 레이아웃 금지). 원격 승인 절차 없음.
2. **견본 복사** — `Popups/_win-popup-template` 를 복사해 `Popups/<이름>/` 로 시작. `frame.*` 는 손대지 말고 `index.*` 만 구현.
3. **공통 자산은 참조만** — `../../theme/*`, `../../../../lib/*` 를 상대경로로 참조. 복사·수정 금지(이관 시 충돌).
4. **공통 컴포넌트 소비** — UI 는 `window.U4AUI.*` 빌더 + `.u4a-*` 클래스로. 직접 `<table>`·새 버튼·새 스타일 만들지 말 것.
5. **색은 `tokens.css` 의미 토큰만**(하드코딩 hex 금지), 고정 px 폭 금지(반응형).
6. **모르면 물어라** — 대응 부품이 없거나 애매하면 새로 만들지 말고, 이 요청을 준 사용자에게 되묻는다.
