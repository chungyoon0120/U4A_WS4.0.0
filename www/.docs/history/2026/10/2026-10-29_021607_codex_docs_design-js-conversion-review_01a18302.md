# UX 디자인 JS 문제점 분석 문서 작성

## 요청

기존 디자인 JS 및 WS 4.0 변환 코드에서 문제로 판단된 내용과 앱 데이터의 중복 광역 관리 분석을 Markdown 파일로 정리한다.

## 변경 내용

- 문제 10개를 R01~R07, D01~D03으로 구분해 정리했다.
- 발생 조건, 영향, 기존 로직과 변환 코드의 관계, 개선 방향 및 소스 근거를 기록했다.
- 참조 공유와 실제 복사, 구조 데이터 중복, 속성 목록의 갱신 불일치를 구분했다.
- 격리 재현·합성 측정과 SAP 실화면 미검증을 구분하고 후속 검증 항목을 작성했다.

## 변경 이유

대화에서 확인한 문제와 검증 한계를 이후 수정·검토의 근거로 사용할 수 있도록 보존한다.

## 영향 범위

문서만 추가했다. 제품 JS, 기존 문서, `.docs/CURRENT.md`, 실행 동작 및 서버 데이터는 변경하지 않았다.

## 검증

- 문서 작성 전 `.docs/CURRENT.md`와 `.docs/README.md`를 확인했다.
- 문제 항목 ID 10개가 중복 없이 구성되었고, 소스 링크 24개의 대상 파일이 모두 존재하며, 작업 이력의 필수 섹션 7개가 포함된 것을 스크립트로 확인했다.
- 제품 소스를 수정하지 않았으므로 제품 테스트는 다시 실행하지 않았다.
- 기존 분석의 격리 재현·합성 측정 결과를 정리했으며, SAP 연결 실화면은 미검증이다.

## 참고 사항

- 사용자가 지정한 비교 기준은 현재 WS 4.0 폴더의 `design/`이다.
- 이번 요청은 분석 결과 문서화이며 실제 수정 요청이 아니다.
- 보고서의 행 번호는 검토 시점 기준이며, 추후 코드 변경 후 다시 확인해야 한다.
