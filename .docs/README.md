# 작업 이력 (.docs)

이 폴더는 **어떤 agent 가 와도 이전 맥락을 이어받도록** 남기는 기록이다.
Claude · codex · antigravity 가 **같은 폴더**를 함께 쓴다.

## 새 대화를 시작하면

1. `.docs/CURRENT.md` 를 먼저 읽는다 — 지금 상태·진행 중·다음 할 것
2. 전체 이력을 매번 읽지 말 것. **지금 건드릴 화면 이름으로만** 찾아 읽는다

## 이력 파일 남기기

**파일을 고쳤으면 답변을 끝내기 전에** 이력을 남긴다. 질문만 하고 끝난 대화는 남기지 않는다.

### 저장 위치

```
.docs/history/YYYY/MM/
```

### 파일 이름

```
YYYY-MM-DD_HHmmss_<agent>_<type>_<화면이름>_<session>.md
```

| 자리 | 무엇 | 예 |
|---|---|---|
| `agent` | claude / codex / antigravity | `claude` |
| `type` | add / fix / refactor / remove / config / docs / test / mixed | `fix` |
| `화면이름` | **소스 폴더 이름 그대로** — 이걸로 나중에 찾는다 | `bindPopup` |
| `session` | 대화 id 앞 8자리 | `a3889c81` |

예: `2026-09-10_143012_claude_fix_bindPopup_a3889c81.md`

**★화면 이름은 반드시 소스 폴더 이름과 같게 쓴다.** 나중에 그 화면 버그가 들어왔을 때
파일 이름으로 바로 찾기 위한 것이다. 임의로 지어내면 못 찾는다.

### 필수 섹션

```markdown
## 요청
## 변경 내용
## 변경 파일
- 추가:
- 변경:
- 삭제:
## 변경 이유
## 영향 범위
## 검증
## 참고 사항
```

## 지킬 것

- 하나의 완결된 작업당 파일 하나. 같은 작업의 후속 수정은 **같은 파일에 이어서** 쓴다
- 새 요청·다른 목적이면 새 파일로 나눈다
- **실패·미검증·되돌린 것도 숨기지 않고 쓴다** — 다음 agent 가 같은 실수를 반복한다
- 기존 이력 파일은 **지우거나 비우지 않는다**
