### CK4~CK9 — 접속 주소 × https 인증서 × 서버 보안 설정 (장군님 2026-10-29)

- `login/ticket_only_by_https` — 1 이면 `Secure` 를 붙임, 0 이면 안 붙임

|---|---|---|---|:---:|---|---|
