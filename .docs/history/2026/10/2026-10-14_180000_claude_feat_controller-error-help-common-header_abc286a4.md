# 컨트롤러 실행 오류 점검사항 창 — 공통 헤더로 전환 + parent 제거

- 날짜: 2026-10-14

## 전체 흐름

SAPGUI 실행(2차 VBS)이 stderr 를 쓰면 → 오류 메시지 창(공통 `.u4a-dialog`) → 그 푸터의 **「점검사항」**
→ `ws_fn_04.js` `_showControllerErrorHelpPopup()` → `www/help/controllerClass/<언어>/index.html`

## 한 일

| 무엇 | 어떻게 |
|---|---|
| 공통 제목줄 | 새 창틀 `Popups/controllerErrorHelpPopup/frame.html` + `frame.js` (오류코드 접두 `CEHP`) |
| 설명서 본문 | **설명서 파일은 손대지 않고** 창틀의 iframe 에 그대로 띄운다 |
| 흰 번쩍 방지 | 창 배경·쿼리(THEME/BGCOL/TITLE)로 첫 페인트 전에 테마 적용 |
| 라이브 테마 추종 | 별창 필수 규약(.analy/16 §2.6.2) — 창틀에만, 설명서 본문은 원본 색 그대로 |
| 닫기 규약 | `closable=false` 를 **창 수명 내내 유지**(전에는 로드 후 true 로 되돌려 Alt+F4 가 먹었다) |
| **parent 제거** | 공통 헤더로 바꾸며 **최소화 버튼이 생겼으므로** 뗐다 |

**왜 설명서를 iframe 으로 내렸나**: 설명서는 언어별로 여러 벌(EN·KO)이고 자기 CSS·이미지를
**상대 경로**로 참조한다. 창 문서로 직접 열면 공통 제목줄을 넣을 자리가 없고, 설명서를 고치면
언어 수만큼 같은 일을 반복해야 한다. (오류 페이지 미리보기 창과 같은 식)

## parent 를 떼며 같이 넣은 것 3가지

1. 이미 열림 판정을 `getCheckAlreadyOpenWindow2`(창 종류 + 브라우저키)로 — 종전 방식은 parent 기반이라 못 찾는다
2. 최소화돼 있으면 **되살린 뒤 focus**
3. 메인 창이 죽을 때 같이 닫히도록 **자식 창 목록에 등록**(+ 닫힐 때 목록에서 제거)

## 테스트를 위해 한 것 (되돌린 것 포함)

- 처음에 **테스트 메뉴 항목**을 만들었다 → 장군님 지적(「굳이 왜 테스트 메뉴를 만드냐」)으로 **전부 되돌렸다.**
- 이어서 **콘솔 스크립트**를 드렸는데 창 만드는 코드를 통째로 재현해 길었다 → 장군님 지적
  (「단순 팝업 하나만 띄우면 되는 걸로 아는데」).
- 길어진 진짜 이유 = 오류 창을 띄우는 `_openControllerErrorDialog` 가 **파일 안 지역 함수**라 콘솔에서 못 부른다.
  → **이름만 `oAPP.fn.fnOpenControllerErrorDialog` 로 내보냈다**(동작 변경 없음). 그러면 콘솔 한 줄로 끝난다.

## ★ 또 밟을 함정

- **공통 헤더로 바꾸면 최소화 버튼이 생긴다 → 그 창은 parent 제거 대상이 된다.**
  「전에 대상 아님으로 판정했다」를 그대로 믿지 말 것 — **전제(창틀 모양)가 바뀌면 판정도 바뀐다.**
- 테스트를 위해 **화면에 메뉴를 만들지 않는다.** 지역 함수를 **이름만 내보내면** 콘솔 한 줄로 띄울 수 있다.
- 설명서·사용자 콘텐츠처럼 **여러 벌이고 상대 경로 자원을 쓰는 HTML** 은 손대지 말고 iframe 으로 내린다.
