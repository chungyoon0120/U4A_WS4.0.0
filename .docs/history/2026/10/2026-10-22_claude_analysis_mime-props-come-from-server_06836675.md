# MIME 리포지토리 별창의 생성자·날짜·시각은 **서버 값 그대로**다 — 2026-10-22

- 종류: analysis
- 세션: 06836675
- 지시: 장군님 「**마임 레파지토리 별창 팝업**에서 폴더를 생성하면 생성자 이름이 로그인 아이디가 아니라
  "SAP" 으로 들어가는지 확인 좀 해줘」 · 「생성 날짜랑 시간도 이상해 같이 좀 봐 봐」
- **코드는 한 줄도 고치지 않았다**(확인 지시).

## ★내가 처음에 틀린 것 — 엉뚱한 파일을 봤다

장군님이 **첫 문장에 「별창 팝업」이라고 명시**하셨는데,
나는 **인앱 판 옛 파일**(`js/fnMimePopupOpen.js`)을 보고
「폴더 생성은 아직 변환 전, 준비중 토스트만 뜬다」고 **틀린 보고**를 했다.

**진짜 창은 `Popups/mimeRepository/mime.js`** 이고 폴더 생성·삭제·Import·다운로드가
**전부 구현돼 있다**(`lf_openCreateFolder` 등).

**왜 틀렸나**: 파일 이름이 비슷해서(`fnMimePopupOpen.js`) 그걸로 단정했다.
**그 창이 어느 파일로 뜨는지 확인하지 않았다.** 장군님 말씀에 답이 있었는데 안 들었다.

## 조사 결과 (진짜 파일 기준)

**생성자·날짜·시각 셋 다 서버가 정한다. 화면은 손대지 않는다.**

1. **폴더 생성 요청에 생성자·날짜·시각을 안 보낸다.** 보내는 것은 10개뿐 —
   `TRCOD`(C) · `OBJTYPE`(FOLD) · `FLDNM` · `FLDPATH`(부모 경로) · `DESC` ·
   `DEVPKG` · `REQNO` · `CONTENT`(폴더는 빈값) · `CLSID` (`mime.js` 1137~1147).
2. **생성 성공 뒤 트리에 넣는 새 노드는 서버 응답(`oResult.MIMETREE`) 그대로**다
   (`lf_insertCreatedFolder` 1228~1249). 화면이 값을 만들어 넣지 않는다.
3. **속성 세 칸은 노드 값을 그대로 표시**한다. 그 세 필드를 쓰는 곳은 **다섯 줄뿐**
   (650 · 655 · 835~838), 전부 읽기 전용. 날짜·시각은 **자르기만** 한다
   (`20140604` → `2014-06-04`, `105226` → `10:52:26`).
4. 원본(WS3.0)도 같은 구조 — 생성 요청에 생성자가 없다.

## 못 본 것 (내 범위 밖)

**서버가 왜 생성자를 `SAP` 으로, 날짜를 2014년으로 주는지는 ABAP 쪽**이라 소스로 확인할 수 없다.
화면에서 바꿀 수 있는 것은 없다.
