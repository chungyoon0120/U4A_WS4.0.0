# 색 고르기가 「Propery 모두 바꾸기」 창 뒤에 숨던 것 — 2026-10-22

- 종류: fix
- 세션: 06836675
- 지시: 장군님 「아예 동작 안 한다」 (값 변경 칸의 값도움을 눌러도·`F4` 를 눌러도 아무 일이 없다)

## 증상

편집 화면(WS20)에서 속성 줄 우클릭 → **「동일 속성 동기화」** → 뜨는 **「Propery 모두 바꾸기」** 창.
`colorString` 처럼 색 속성일 때 **값 변경** 칸 오른쪽의 겹친 네모 단추를 눌러도, 칸에 커서를 두고
`F4` 를 눌러도 **아무 일도 일어나지 않는다.**

## 원인 — 열리기는 열렸다. 창 뒤에 깔려 안 보였다.

| 무엇 | 어떻게 떠 있나 | 결과 |
|---|---|---|
| 「Propery 모두 바꾸기」 창 | `<dialog>` + **`showModal()`** (`fnSameAttrSyncPopupOpen.js` 839행) | **top layer** |
| 색 고르기 | `document.body` 에 붙인 보통 DOM + `position:fixed; z-index:11000` (`fnColorPickerPopover.js`) | top layer **밖** |

`showModal()` 로 연 `<dialog>` 는 top layer 에 올라간다.
**top layer 밖에 있는 것은 `z-index` 를 아무리 키워도 그 아래로 깔린다.**
그래서 색 고르기는 정상으로 열렸지만 창에 완전히 가려져 「동작 안 함」으로 보였다.

★이 창은 **이미 같은 함정을 한 번 겪었다** — 컬럼 머리글 메뉴는 `container: oUI.dlg` 로
dialog 안에 붙이고 있다(`fnSameAttrSyncPopupOpen.js` 529행, 주석도 그렇게 적혀 있다).
색 고르기만 빠져 있었다.

## 고친 것 — `www/ws30/ws10_20/js/fnColorPickerPopover.js` 한 곳

`fnColorPickerOpen` 이 **앵커(값도움을 누른 입력칸)가 떠 있는 `<dialog>` 안에 있으면
팝오버도 그 dialog 안에 붙이도록** 했다(`lf_hostOf`). 그 밖이면 전처럼 `document.body`.

- **호출처는 한 줄도 안 고쳤다** — 2곳(동일 속성 동기화 창 · 속성 영역) 전부 자동으로 고쳐진다.
  속성 영역은 dialog 밖이라 전과 똑같이 `body` 에 붙는다.
- 어디에 붙였는지 로그로 남긴다 — `OPEN / fnColorPickerOpen / host=body` 또는 `host=dialog (top layer)`.
- `node --check` 통과.

## 확인한 것 (판정 근거)

- 창이 `showModal()` 인 것 — 소스 839행.
- 색 고르기가 `document.body` 자식 + `z-index:11000` 인 것 — 소스 217·331행.
- 값도움 단추와 `F4` 배선은 멀쩡하다 — `createField` 의 `f4` + 겹친 네모 아이콘이라
  공통이 `attachF4` 를 자동으로 건다. 화면에 단추가 보이는 것 자체가 `attrIsColorProp` 가
  `true` 였다는 뜻이고, 같은 함수를 다시 보는 `_callInputF4Help` 도 당연히 색 갈래로 간다.
- `F4` 는 화면 단축키로 등록돼 있지 않다 → 중간에서 가로채는 것이 없다(grep 0건).
- 드래그는 `left/top` 으로 하고 `transform` 을 쓰지 않는다 → dialog 안에 넣어도
  `position:fixed` 가 viewport 기준 그대로다(조상에 `transform`·`filter` 가 있으면 깨진다).

## 함정 — 다음에 또 밟는다

**`showModal()` 로 연 창 안에서 무언가를 띄우려면 그것도 그 창 안에 붙여야 한다.**
`z-index` 로는 절대 못 이긴다. 이 프로젝트에서만 세 번째다 —
처리중 표시(2026-10-16 바인딩 창) · 컬럼 머리글 메뉴 · 이번 색 고르기.

**증상이 「아무 일도 안 일어난다」일 때 배선부터 의심하지 말 것.**
이번엔 배선이 멀쩡했고 **보이지 않았을 뿐**이다. 눌렀을 때 로그가 찍히는지부터 봤어야 했다.
그래서 이번에 여는 자리에 로그를 심었다.
