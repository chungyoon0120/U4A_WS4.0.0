## 지시

> WS10 → 앱 생성 → 데이터 세트 → 검색 필드 선택 팝업에서 **테이블이 가상 스크롤이 반영이 안 되어 있어**

## 원인 (소스로 확인)

그 창은 **공통 표 생성기를 쓰지 않고** `<table>` 을 손으로 만들고,
`_renderTable()` 이 받은 행을 **전부** `<tr>` 로 만들어 `tbody` 에 넣었다(299건이면 299행).

- 공통 표 생성기(`U4AUI.makeDataTable`)는 **가상 스크롤이 기본**이다(`virtual` 을 false 로 줘야 꺼진다).
- 원본 UI5 는 `sap.ui.table.Table` — **보이는 행만 그리는 것이 원래 동작**이다.
  즉 공통 표준과 원본 동작 **양쪽 모두와 어긋나 있었다.**

## 고친 것

표를 **공통 생성기로 교체**했다.

- `selectable: false`(선택은 체크박스로만 — 원본 `selectionMode:"None"` 과 같다)
- 컬럼 4개: 선택 체크박스 / Field Name / Key Field / Description
- `rowHook` 에서 선택 불가 행 흐리기 · `aria-selected` · 설명 칸 툴팁(FLDTT) 처리
- 머리글 첫 칸에 **전체선택 체크박스**를 직접 끼워 넣는다(공통 머리글은 글자만 받는다)
- `node --check` 통과

### ★가장 중요한 변경 — 선택 상태를 DOM 에서 떼어냈다

예전 코드는 행을 만들 때 그 체크박스를 `r.__chk` 에 **들고 있다가** 전체선택·칩 지우기에서 그것을 직접 만졌다.
**가상 스크롤에서는 행이 사라졌다 다시 만들어지므로 그 참조가 죽는다.**

그래서 `__chk` 를 전부 없애고,

- 체크 여부는 **데이터(`r.SEL`)** 가 갖는다. 행을 그릴 때마다 거기서 읽어 체크를 찍는다.
- 전체선택·칩 지우기는 **데이터만 바꾸고** `refresh()` 로 보이는 행만 다시 그린다(스크롤 자리 유지).

## ★또 밟을 함정

- **표를 손으로 만들면 가상 스크롤이 빠진다.** 행이 수백 건 넘는 목록은 공통 생성기를 쓴다.
- **가상 스크롤 표에서 DOM 참조를 들고 있으면 안 된다**(`r.__chk` 같은 것).
  행은 언제든 버려지고 다시 만들어진다 — 상태는 **데이터에** 둔다.
- 공통 머리글은 **글자만** 받는다. 머리글에 체크박스 같은 것을 넣으려면 만든 뒤 그 칸에 직접 끼운다.
