## 증상

「정보 → U4A 워크스페이스 정보」 를 열면 창은 비고 크리티컬 오류창이 뜬다:
`Uncaught SyntaxError: Unexpected end of JSON input`

## 원인 (실측으로 확정)

그 창은 서버 주소를 **`path.join`** 으로 만들고 있었다. 실제로 찍어 본 결과:

```
path.join("http://서버:10101/zu4a_wbc/u4a_ipcmain", "about_u4aide?WSVER=…")
→ 점·역슬래시 + "http:" + 역슬래시 + "서버:10101" + 역슬래시 + … (주소가 아니라 상대 경로)
```

`path.join` 은 **파일 경로용**이라 Windows 에서 역슬래시로 이어 붙이고 앞에 점·역슬래시까지 붙인다.

화면이 `u4a-ws://` 로 뜨는 Electron 45 에선 그 상대 경로가 **서버가 아니라 앱 폴더 안**을 가리킨다.
없는 것을 가리키니 빈 응답이 오고, 그걸 `JSON.parse` 가 받아 터졌다.

★이 코드는 **원본(WS3.0.0)과 한 글자도 다르지 않다.** 원본은 화면이 `file://` 이었고,
지금은 `u4a-ws://` 로 바뀌었다 — **전제가 바뀐 것이지 코드가 틀려졌던 것이 아니다.**

## ★함정

1. **서버 주소를 `path.join` 으로 만들지 말 것.** 파일 경로용이다. 문자열로 잇는다.
2. 원본과 같다고 안전한 것이 아니다 — **화면 주소(origin)가 바뀌면 같은 코드가 다르게 돈다.**
3. 이 창의 요청은 `xhr.status` 를 안 본다. 실패해도 빈 글자를 파싱해 크리티컬 오류창이 뜬다.
   원본도 같은 모양이라 이번엔 안 건드렸다 — 고칠지는 장군님 지시 대기.
4. 내가 처음에 한 것: **원본 비교부터 했다.** 그건 「우리가 뭘 바꿨나」를 보는 것이라,
   **환경이 바뀐 사고**에서는 답이 안 나온다. 환경(Electron 버전·화면 주소·프로토콜)이 바뀌었으면
   **바뀐 전제부터 짚는다.**
