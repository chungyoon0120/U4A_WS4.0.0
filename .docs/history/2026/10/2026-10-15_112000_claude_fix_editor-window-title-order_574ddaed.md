  (CSS Editor 창 제목줄을 캡처해 빨간 동그라미로 짚어 주심)

## 1. 한 일

`www/ws30/ws10_20/js/fnEditorPopupOpen.js` 40~43 — 제목 만드는 두 줄.

| 전 | 후 |
|---|---|
| `YLCY_MCP099 - CSS Editor` | `CSS Editor - YLCY_MCP099` |

앱 이름을 앞에 붙이던 것을 떼고, 종류 + 「Editor」 뒤에 ` - 앱이름` 을 붙이는 순서로 바꿨다.
「Editor」 는 종전대로 메시지 키에서 가져온다(글자를 박아 넣지 않았다).

## 2. 같이 바뀌는 것 — 보고

이 창을 여는 함수는 **CSS · Javascript · Html 에디터가 같이 쓴다**(`js/fnHmws.js` 153·174·196,
그리고 WS20 쪽 919·939·960 — 실측 호출처 7곳, 그중 1곳은 `design/js/uiAttributeArea.js`).
따라서 **세 에디터 제목이 전부 같은 순서로 바뀐다.** CSS 만 바꿀 길은 분기를 새로 만드는 것뿐이라
하지 않았다 — 세 창이 다른 순서를 쓰면 그게 더 어긋난다.

## 3. 또 밟을 함정

- **이 제목은 창 옵션(`title`)과 창 안 제목줄에 넘기는 값(`TITLE`) 두 군데에 같이 쓰인다**(79·120).
  한 변수(`sBrowserTitle`)를 둘 다 쓰므로 한 곳만 고치면 작업표시줄과 창 안 글자가 어긋난다.
  이번에는 **변수를 만드는 자리**를 고쳐 둘 다 같이 바뀐다.
- 같은 모양의 제목을 쓰는 **다른 창들은 건드리지 않았다**(오류 페이지 에디터 · 미리보기 등은
  자기 파일에서 따로 만든다). 순서를 전체로 맞추려면 그건 **별도 지시**가 필요하다.
