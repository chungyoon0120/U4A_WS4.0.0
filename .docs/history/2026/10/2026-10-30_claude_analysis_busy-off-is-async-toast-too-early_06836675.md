# busy 가 아직 떠 있는데 토스트가 먼저 뜬다 — 끄기가 **300ms 비동기**인 것을 안 쓰고 있다

- 날짜: 2026-10-30
- 지시: 장군님 「스니펫 디자이너에서 저장 시, busy랑 메시지 토스트랑 같이 나오는데 …
  보통 busy라고 하면 뭔가 처리중 표시인데 처리가 다 끝나고 메시지가 나와야하지 않아?」 (화면 캡처 첨부)
- **코드는 한 줄도 안 고쳤다.** 조사만 했다.

## 결론 — 장군님 말씀이 맞다. 토스트가 **최소 300ms 먼저** 뜬다

| 확인한 것 | 결과 |
|---|---|
| 저장 코드의 순서 | `fn_setBusy(false)` → `_toast("저장되었습니다!")` — **순서는 맞게 짜여 있다** |
| `fn_setBusy(false)` 가 하는 일 | `U4ABusy.hide()` 를 **콜백 없이** 부른다 (`Popup/js/index.js:135`) |
| `U4ABusy.hide()` 가 즉시 끄나 | **아니다** — `setTimeout(_checkQuiet, 150)` → `_waitIdle` → `setTimeout(_finish, 150)` → `close()`. **최소 300ms**, 화면이 계속 바뀌면 더 |
| 토스트가 busy 위에 보이는 까닭 | **일부러 그렇게 해 놨다** — `_toast` 가 host 를 고를 때 `dialog[open]:not(.u4a-busy)` 로 busy 를 빼고 `body` 에 붙인다 (`index.js:113~115`) |

→ 저장 코드는 **「끄기를 부르면 바로 꺼진다」를 전제**하고 짜여 있다.
그 전제는 2026-10-21 에 「조용해질 때까지 기다렸다 끈다」가 들어오면서 깨졌는데, 호출하는 쪽은 안 바뀌었다.

## 고치는 길 — `hide()` 는 이미 콜백 자리를 갖고 있다

```js
function hide(fnDone)   // u4a-busy.js:319 — close() 직후 fnDone() 을 부른다
```

`fn_setBusy(false)` 에 콜백을 넘기고 그 안에서 토스트를 띄우면 된다.
**선례가 이미 있다** — 쇼컷링크 생성 창: `U4ABusy.hide(_runAfterBusyOff)` (`ShortCutCreator/js/index.js:384`).

## 같은 병일 수 있는 창 — **후보 13곳** (전수 아님)

`U4ABusy.hide()` 를 **콜백 없이** 부르는 곳이 20곳, 그중 토스트도 쓰는 파일이 13곳이다.

ServerList · 속성 프리셋 목록 · 바인딩 · 기술 문서 · 소스 패턴(editorPopup) · 오류 페이지 편집기 ·
글꼴 마법사 · **스니펫 디자이너** · 테마 디자이너 · 옵션 · 내 패턴 · 런타임 클래스 · 버전 관리

★**「전수」라고 부르면 안 된다.** 파일 안에 토스트가 있다는 것만 셌고,
**그 토스트가 busy 를 끈 직후인지는 줄마다 안 봤다.** 고치려면 그때 한 줄씩 본다.

콜백을 넘기는 곳은 지금 2곳뿐 — 전역 `setBusy`(`ws30/resources/index.js:1727`) · 쇼컷링크 생성 창.

## 또 밟을 함정

- **`U4ABusy.hide()` 는 동기가 아니다.** 「끈 다음에 ○○」를 하려면 **반드시 콜백**으로 넘긴다.
  `hide()` 바로 뒤에 쓴 코드는 busy 가 **아직 떠 있는 상태**에서 돈다.
- 그래서 「busy 다음에 확인창·토스트·포커스 이동」을 넣은 자리는 전부 같은 병이다.
- 토스트는 일부러 busy 바깥(`body`)에 붙는다 — **가려지지 않아서** 이 어긋남이 눈에 바로 보인다.
  반대로 busy 안에 붙이면 busy 가 닫힐 때 토스트도 같이 사라진다(그래서 뺀 것이다).

# 후속 2 (같은 날) — 남은 **11곳을 전부 고쳤다** · 공통에 `U4ABusy.afterOff` 를 넣었다

- 지시: 장군님 「우선 작업 우선 순위를 만들자.. 지금 하는건 일단 **busy 작업 끝내고** 다시 나한테 반드시 언급해」

## 공통으로 뺐다 — `U4ABusy.afterOff(fn)`

창마다 busy 함수를 고치는 대신, **공통 busy 에 대기열을 하나** 뒀다(`theme/u4a-busy.js`).

```js
U4ABusy.afterOff(function () { ... });   // busy 가 실제로 꺼진 그때 부른다
```

- busy 가 떠 있지 않으면 **바로** 부른다. 떠 있으면 꺼지는 자리(`_hideCore` 의 `_done`)에서 비운다.
- **끄기를 거는 쪽과 뒷일을 거는 쪽이 달라도 된다** — 그래서 화면 쪽은
  「끄기 한 줄 + `afterOff` 한 줄」로 끝나고, **창마다 busy 함수를 고칠 필요가 없다**(영향도 0).
- AI 자물쇠로 끄기가 막혀 있으면 기다렸다가 AI busy 가 꺼질 때 같이 불린다.

각 파일에는 작은 헬퍼 하나씩만 뒀다(공통 busy 가 없는 환경에서는 그냥 띄운다).

| 파일 | 헬퍼 |
|---|---|
| `design/attrPresetPopup/list/index.js` | `_toastAfterBusy` |
| `Popups/patternPopup/frame.js` | `_toastAfterBusy` |
| `ServerList_v2/ServerList.js` | `oAPP.fn.showToastAfterBusy` |
