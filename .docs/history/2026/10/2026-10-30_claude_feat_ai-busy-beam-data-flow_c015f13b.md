### 왜 zoom 인가
그림의 숫자(크기·좌표·박자)는 시안 세션이 넘긴 값이다. 하나하나 키우면 입자 12개 좌표까지
다시 맞춰야 하고 시안과 값이 갈려 다음에 또 어긋난다. `zoom` 한 줄이면 **입자 좌표까지 같은 비율로**
커지고, 되돌릴 때 그 한 줄만 지운다. Electron 45 = Chromium 156 이라 `zoom` 이 레이아웃까지 적용된다.

### 함정
- **테두리 빛 원뿔 판은 카드 대각선보다 커야 한다.** 작으면 모서리에서 빛이 끊긴다.
  카드 `max-width` 를 또 키우면 이 판(지금 900px)도 같이 키운다.
- **두께는 정수 px.** 1.4배인 4.2px 은 쓰지 않았다 — 소수면 카드가 반 픽셀 자리에 놓일 때
  좌우만 얇아 보인다(2026-10-29 장군님 지적).
- **AI 모드 테두리 빛 규칙은 지우지 않고 `display: block` 으로 되살렸다.** 다시 끄려면 `none` 으로
  한 글자만 바꾼다. 시안 쪽 CSS 와 다른 **유일한 한 줄**이다 — 시안을 다시 받아 붙이면 이 줄이 덮인다.

### 정정 — 커지는 것은 AI 모드만 (장군님 지시 2026-10-30)
> 「공통 busy만 겁나 커졌는데 공통 busy는 원래 크기로 원복하고 ai busy만 지금 상태로 해줘.
>  어짜피 대표 css 클래스로 분기해서 처리하면 변경할 것도 많이 없잖아」

공통 카드(`.u4aWsBusyCard`)·테두리 빛을 **종전 값으로 되돌리고**, `data-u4a-busy-mode="ai"` 로만
분기해 네 덩어리를 덮어쓴다. 일반 busy(API Call)는 한 글자도 안 바뀐다.

| 선택자 | 무엇 |
|---|---|
| `[data-u4a-busy-mode="ai"] .u4aWsBusyCard` | gap 24 / min-width 420 / max-width 600 / padding 40px 48px 36px |
| `[data-u4a-busy-mode="ai"] .u4aWsBusyEdge` | 두께 4px |
| `[data-u4a-busy-mode="ai"] .u4aWsBusyEdge i` | 원뿔 판 900px (margin -450px) |
| `.u4aWsBusyAi` | `zoom: 1.6` (AI 모드에서만 보이는 요소라 선택자 하나로 충분) |

이 덩어리는 **AI 전용 CSS(「40안 01」) 밖**에 두었다 — 그 덩어리는 시안에서 통째로 받아 덮어쓰는
자리라, 밖에 두면 다시 받아 붙여도 크기 설정이 살아남는다.

### 함정 (실제로 한 번 덮였다)
**같은 특이도면 뒤에 오는 규칙이 이긴다.** 시안에서 받은 CSS 안에
`[data-u4a-busy-mode="ai"] .u4aWsBusyCard { min-width: 220px }` (시안 폭에 맞추려고 넣은 줄)이
내 블록보다 **뒤에** 있어서 `min-width: 420px` 를 **220px 로 덮었다.** 그 줄을 지우고 왜 지웠는지
주석을 남겼다. 시안 CSS 를 다시 받아 붙이면 그 줄이 되살아나므로 **붙인 뒤 이 자리를 다시 본다.**

### 다시 정정 — 크기는 카드 `zoom` 두 줄로 끝냈다 (장군님 지시 2026-10-30)
> 「ai busy 에서 desc 폰트만 좀 키웠으면 좋겠다」 → 「공통 busy도 같이 키워줘라 약 zoom으로 했을때 1.2 정도?」

항목마다 따로 적던 것(카드 폭·`padding`·`gap`·테두리 두께·원뿔 판·`desc` 글자·그림 `zoom`)을
**전부 지우고** 카드 하나에 `zoom` 을 거는 것으로 바꿨다.

```
.u4aWsBusyCard { zoom: 1.2; }                                          /* 공통 */
[data-u4a-busy-mode="ai"] .u4aWsBusyCard { zoom: 1.5; }                /* AI 전용 */
```

- 카드에 `zoom` 을 걸면 안의 **전부**가 같은 비율로 커진다 — 비례가 저절로 맞아서
  테두리 빛 두께·원뿔 판을 따로 키울 필요가 없고 **모서리에서 빛이 끊기는 일도 없다.**
- `zoom` 은 **겹치지 않는다** — 같은 요소의 같은 속성이라 AI 값이 공통 값을 덮는다.
- 그래서 규칙이 7개 → 2개가 됐다. 장군님 말씀(「대표 css 클래스로 분기하면 변경할 것도 많이 없잖아」) 그대로.

★AI 쪽은 종전(카드 1.4배 + 그림 1.6배 + desc 17px)과 **미세하게 달라진다** — 전부 1.5배로 통일됐다.
  카드 폭 450~660px · 그림 1.5배 · desc 19.5px.

함정: 시안 CSS 안의 `[ai] .u4aWsBusyCard { min-width: 220px }` 를 뺀 것은 **그대로 유효**하다.
그 줄이 되살아나면 `zoom` 과 무관하게 AI 카드가 좁아진다.

### 최종 — 크기는 공통과 똑같이 (장군님 확인 2026-10-30)
> 「공통 busy가 지금 딱 이쁘게 잘 나오는 사이즈 잖아 busy dialog 크기도 그렇고 그 안에 아이콘도 그렇고」

배율을 키웠다 줄였다 네 번 했다(카드 1.4 → zoom 1.5 → 1.35 → 1.15 → 없앰). 장군님이 화면을 보시고
「왜이렇게 극과 극이야 … 적당히 키워」 · 「적당히 안할래?」 두 번 지적하셨다.
**숫자를 혼자 정하지 말고, 이미 좋다고 하신 것이 있으면 거기에 맞춘다.**

최종 CSS = 세 줄이다.

```
.u4aWsBusyCard { zoom: 1.2; }                                       /* 카드 — 공통·AI 공용 */
.u4aWsBusyApi, .u4aWsBusyAi { zoom: 1.15; }                         /* 그림 — 공통·AI 공용 */
[data-u4a-busy-mode="ai"] .u4aWsBusyCard { min-height: 120px; justify-content: center; }
```

AI 전용은 **높이 하나뿐**이다. AI 그림은 가운데 한 줄(「AI」 — 선 — 로고)이라 공통 그림(높이 60px)보다
납작해서, 아무것도 안 하면 카드가 공통보다 얇아진다. 120px = 공통 카드 안쪽 높이.
