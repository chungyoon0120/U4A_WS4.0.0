## 가져온 방법

시안 페이지를 내장 브라우저로 열어, 그 페이지 안 시안 정의(`id: "api"`)의 `html` · `css` 를
그대로 읽어 왔다. `.host` 가 비어 있어 **모양은 전부 CSS 가 그린다** — 마크업은 빈 상자 몇 개다.

| 시안 | 우리 | 왜 |
|---|---|---|
| `.ub-api` | **`.u4aWsBusyApi`** | 이 파일의 선택자는 busy 전용 이름으로 시작해야 한다(파일 머리 §9) |
| `@keyframes ub-api-*` | `@keyframes u4aWsBusyApi*` | 이름 충돌 방지 |
| `${MONO}` | `"JetBrains Mono", ui-monospace, Consolas, monospace` | 시안의 상수를 펼친 것 |
| `${GLOW}` | `var(--busy-glow)` | **우리 파일에 이미 같은 토큰이 있다** |
| `--busy-accent` / `--busy-accent-2` | 그대로 | 우리 파일 83~84행에 **같은 값**(`#c705f7` / `#ff7af5`)이 이미 있다 |

WS 로고는 시안과 같은 path(viewBox `0 0 307 311`, W 4개 + S 1개)를 **`<svg>` 로** 넣었다.
종전 로고는 CSS mask 방식이었다 — 그 블록은 **지우지 않고 그대로 뒀다**(아래 참조).

## 고친 파일 2개

| 파일 | 무엇 |
|---|---|
| `theme/u4a-busy.js` | `_create()` 의 카드 안 그림을 `.u4aWsSpinner` → **`.u4aWsBusyApi`** 마크업으로 교체 |
| `theme/u4a-busy.css` | `.u4aWsBusyApi` 블록 추가(애니메이션 5개). 전역 스타일 방어로 `box-sizing: border-box` 도 같이 |

카드 테두리를 도는 빛(`.u4aWsBusyEdge`)은 **건드리지 않았다** — 지시가 가운데 그림이었다.

## ★안 지운 것 — 이전 모양(Sparkle) CSS

`.u4aWsSpinner` 블록(로고 mask + 별빛 3개)이 **CSS 에 그대로 남아 있다.** 이제 아무도 안 쓴다.
지우지 않은 까닭: 그 모양은 **어제(2026-10-29) 작업분인데 아직 커밋 전**이라,
지우면 되돌릴 데가 없다. 지울지는 지시를 받는다.

## 미검증 — ★실제로 그려지는 것을 못 봤다

- 앱으로 돌려 보지 않았다. `node --check` 통과, CSS 중괄호 짝 72:72 로 맞다.
- 자체 포함 확인 페이지를 만들어 내장 브라우저로 열려 했으나,
  **로컬 파일 탭에서는 페이지 도구가 막혀 화면을 볼 수 없었다.**
  그 파일은 장군님께 따로 드렸다(`scratchpad/busycheck2.html`) — 열면 바로 보인다.

## 또 밟을 함정

- **시안 페이지의 모양 정의는 CSS 에 없다.** `document.styleSheets` 에서 `18-api` 를 찾으면 0건이다.
  시안은 `<script>` 안 객체(`{id, name, desc, html, css}`)로 들어 있고, 고를 때 그때 주입된다.
  → 시안을 가져올 때는 **script 본문에서 그 객체를 찾는다.**
- **내장 브라우저의 로컬 파일(file://) 탭에서는 screenshot·read_page 가 막힌다.**
  확인용 페이지는 프로젝트 안에 둬도 `data:` 스냅샷으로 열려 외부 CSS·JS 가 로드되지 않는다.
  → 확인이 필요하면 **CSS·JS 를 한 파일에 인라인**으로 넣고, 그 파일을 사용자에게 보낸다.
