# 공통 드롭다운 — 값 글자를 마우스로 끌어 복사 (구글시트 19번)

- 날짜 2026-10-15 · 세션 06836675 · type=fix · 장군님 지시 「진행해」

## 왜 안 됐나 (소스로 확인)

- 원본 WS3.0 의 20번 페이지 속성 영역 Events 값 칸 = `sap.m.ComboBox`
  (`design/js/uiAttributeArea.js:900`) → 속이 `<input>` 이라 값 글자를 끌어서 복사할 수 있었다.
- WS4.0 공통 드롭다운(`theme/u4a-ui.js` `createSelect`)은 `<div class="u4a-combo">` +
  `<span class="u4a-combo__text">` 다. 앱 전역이 `user-select:none` 이고(.analy/16 §2.9)
  되살린 목록은 `input, textarea, .u4a-input, .u4a-field__input, .u4a-table tbody, .u4a-selectable`
  뿐이라 **콤보 값 글자는 선택 대상이 아니었다.** `.u4a-combo` 자체에도 `user-select:none` 이 박혀 있다.

## 고친 것 (공통 2곳 — 전 화면 적용)

1. `theme/shell.css` `.u4a-combo__text` → `user-select: text`. **값 글자만** 열었다.
   화살표·빈 칸은 `.u4a-combo` 의 `none` 유지 → 눌러서 펴는 자리는 안 줄었다.
2. `theme/u4a-ui.js` `createSelect` → 끌어서 글자를 고른 경우에만 목록 열기를 건너뛴다.
   판정 조건 **2개 모두** 만족할 때만: ① 누른 지점에서 4px 이상 움직임 ② 선택 영역이 값 글자 안에 생김.
   (하나만 보면 손떨림 클릭이 죽는다.) 건너뛸 때 `U4ALOG.info("SKIP_OPEN", …)` 한 줄.
3. 로그 표준(`.works/DEV_STANDARD_로그.md`)에 사건 이름 `SKIP_OPEN` 한 줄 추가.

## 영향 범위

공통 드롭다운을 쓰는 파일 15개(로그인 · 20번 페이지 속성/편집/드래그 · 앱 만들기 창 · 각종 팝업 ·
USP 에디터 등) 전부. **창 이동용 띠(`-webkit-app-region: drag`) 안에 콤보를 넣는 곳은 없다** — 창 끌기와 안 겹친다.
비활성 콤보는 `pointer-events:none` 이라 변화 없음. 키보드 조작·값 바뀜·목록 고르기는 손대지 않았다.

## 또 밟을 함정

- **공통 콤보는 `<input>` 이 아니다.** 「입력칸이니까 글자가 선택되겠지」로 판단하지 말 것 —
  전역 `user-select:none` 에 걸린다. 새 공통 컴포넌트를 만들 때 값 글자는 `.u4a-selectable` 이든
  해당 셀렉터든 **명시적으로 열어야** 한다.
- 값 글자를 선택 가능하게 열면 **클릭 열기와 겹친다**(끌고 떼면 click 이 뜬다). 열기 억제 없이 CSS 만
  바꾸면 글자를 고를 때마다 목록이 펴진다.

- 드롭다운 **밖**의 글자(라벨·패널 제목 등)는 그대로 막혀 있다. 범위가 달라 따로 여쭙기로 했다(TODO).

## 1차가 부족했다 — 글자에 조준해야만 잡혔다 (같은 날 바로 지적받음)

장군님 지적: 「사람이 어떻게 텍스트 딱 그 위치에서부터 드래그할 수 있겠냐」 —
보통은 **글자 오른쪽 빈 칸부터** 끌기 시작한다. 1차는 글자 span 만 열어 그 빈 칸이 선택 밖이었다.

**이것은 `.analy/16 §2.9` 에 이미 적혀 있던 교훈이다** — 테이블에서 `td` 하나만 열었다가
「글자에 정확히 조준해야만 블럭이 잡힌다」고 지적받아 `tbody` 단위로 바꿨던 것과 똑같다.
공통 컴포넌트에 선택을 열 때는 **글자가 아니라 칸 단위로** 연다.

고친 것 3가지:
1. `.u4a-combo` 자체를 `user-select: text` (칸 전체) · 화살표(`.u4a-combo__arrow`)만 `none` 으로 되돌림.
2. `.u4a-combo__text` 에 `flex: 1 1 auto; min-width: 0` — 글자 span 이 남은 폭을 채운다(ellipsis 유지).
3. 열기 억제 판정을 선택 시작·끝 **어느 쪽이든 그 칸 안이면** 인정하도록 넓혔다
   (여백에서 끌기 시작하면 시작 노드가 글자가 아니라 칸이다).
