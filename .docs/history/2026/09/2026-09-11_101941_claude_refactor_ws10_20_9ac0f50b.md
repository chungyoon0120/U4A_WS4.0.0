## 변경 내용

console.error 문구와 `lf_wrap` 의 desc 인자가 한국어 → 영어로 바뀌어 있음 (9 insert / 9 delete).

- `PREV-ERR-00` : "오류 표면화 설치 실패 — 미리보기 함수가 나타나지 않음"
  → `error hook not installed - getUIClassInstance never appeared in the preview iframe after 100 retries (~20s)`
- `PREV-ERR-04` : "화면 묶음 함수 감쌈 실패 — 미리보기 엔진이 나타나지 않음"
  → `error hook not installed - sap.ui never appeared in the preview iframe`
- `PREV-ERR-04` catch 2곳 : "화면 묶음 함수 감쌈 중 오류:" → `error while wrapping sap.ui loaders:`
- `lf_wrap` desc : "UI 부품 정보 읽기"/"UI 속성 구성"/"UI 속성 직접 적용"/"화면 묶음 즉시 불러오기"/"화면 묶음 불러오기"
  → 각각 `getUIClassInstance` / `setUIProperty` / `setUIPropertyDirectly` / `sap.ui.requireSync` / `sap.ui.getCore().loadLibrary`

로직 변경 없음. 문구만 바뀜.

★ 이 세션에서 장군님께 보고한 **미해결 결함 3건** (지시 대기 중, 코드 미수정):
1. `iTry > 100` × 200ms 로 시간을 못 박음 → 느린 PC 에서 preview 가 20초 넘게 걸리면 그냥 포기.
   엔진 쪽 `iEngTry > 150` 도 동일. (장군님 지시 "항상 느린 PC 도 고려" 위반)
2. retry chain 중복 — iframe `load` 마다 새 chain 이 시작되는데 counter 는 `contentWindow` 공유.
   chain 이 늘수록 상한을 빨리 소진 → **느릴수록 더 빨리 포기하는 거꾸로 된 구조.**
3. 포기 로그에 판단 근거(`src` 부착 여부 · `document.readyState` · 실제 경과 ms · chain 수)가 없어,
   "preview 가 진짜 안 뜬 것"인지 "src 도 안 붙은 빈 document 를 쳐다본 것"인지 로그로 구분 불가.
   → 실제로 이번 자동 시험 기록 1건의 원인을 확정하지 못했다.
