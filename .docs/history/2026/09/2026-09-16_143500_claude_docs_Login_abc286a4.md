# 로그인 화면 시작 서버 호출 — 예외처리 원본 대조

## 요청

장군님 지적 2026-09-16: 「로그인창 실행 하자마자 서버 호출하는 로직에 예외처리가 원본이랑 완전 다르다」.

## 변경 내용

코드는 안 고쳤다. 원본(`U4A_WS3.0.0`)과 현행 `Login.js` 를 대조해 차이 목록을 문서로 만들었다.

핵심 차이:
- 접속 서버 설치 언어 조회: 원본은 HTTP 오류 응답(4xx·5xx)을 통신오류로 보고 「서버 연결 실패」 창을 띄운다. 현행은 상태 코드를 안 봐서 **하위 버전 서버로 오인하고 정상 진행**한다.
- 원본에 없는 것 추가: 쿠키 같이 보내기, SSO 자동 로그인 30초 강제 끊기.
- 콘솔 안내 글 뜻이 원본과 반대(「SAML 삭제」→「SAML 설정」 등).
- 오류 창 버튼 모양이 원본과 다름.

## 후속 1 — 원본대로 고침 (2026-09-16, 장군님 지시 「빨리 고쳐 원본처럼」)

장군님 실측: 502 Bad Gateway 에서 원본은 「Server connection failed!」 창, 현행은 창 없이 로그인 화면.

- 변경: `www/ws30/ws10_20/Login/Login.js` · 백업 `_Login.js.origerrbak`
  - 접속 서버 설치 언어 조회: 응답이 2xx·304 가 아니면 원본 jQuery.ajax 처럼 오류 갈래(E999)로 보낸다 → 오류 창이 뜬다. 오류 원문(`statusText` / `"timeout"` / `""`)을 원본처럼 먼저 남긴다. 원본에 없던 `withCredentials` 제거. 콘솔 안내 글 원본 문장·등급 그대로.
  - 언어 조회 결과 처리: 원본의 model 없음 막는 줄 복원.
  - SSO 자동 로그인: 원본에 없던 30초 강제 끊기 제거, 콘솔 안내 글 원본 문장 그대로.
  - **안 건드린 것**: 오류 창 버튼 모양.
- 검증: `node --check` 통과, 백업과 diff 확인. **앱 확인 전** → `.works/Login/00_현황판.md` LE1~LE5.
- 작업 중 실수: 파이썬으로 넣을 때 줄바꿈 글자가 실제 줄바꿈으로 들어가 문법 오류 → 바로 고쳐 `node --check` 통과.
