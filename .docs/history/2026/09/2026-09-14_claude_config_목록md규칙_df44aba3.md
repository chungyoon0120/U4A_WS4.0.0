# 목록은 무조건 md 파일로 — 상시 규칙 추가

작업일: 2026-09-14 · 대화창: df44aba3

## 요청

> "항상 md로 내가 볼수 있게 목록화하라고"

직전에 「판정 결과를 몇 개씩 끊어서 보고할지」를 **채팅창에만 표로** 답한 것에 대한 지적이다.
2026-08-14 의 「테스트 시나리오는 현황판에」 지시를 **모든 목록으로 넓히라**는 뜻.

## 변경 내용

**코드 변경 없음. 규칙·문서만.**

| 파일 | 무엇 |
|---|---|
| `.claude/rules/always.md` | 「테스트 시나리오는 채팅에 붙이지 말 것」 한 줄을 **「목록은 무조건 md 파일로」** 로 넓혀 다시 씀. 대상(테스트 항목·조사 결과·판정 결과·대상 목록·비교표·할 일)과 어디에 쓸지, 채팅에는 한 줄 요약+링크만 이라는 것까지 명시. 테스트 표 형식은 그대로 유지 |
| 메모리 `always-put-lists-in-md` (신규) + `MEMORY.md` | 같은 내용 |
| `.docs/CURRENT.md` | 미해결 표에 한 줄 추가 — 채팅에만 보고했던 발견(옛 UI5 판 CSS 팝업의 테스트 잔재)을 문서로 옮김 |

백업: `.claude/rules/_always.md.mdlistbak`

## 변경 이유

채팅은 흘러가서 장군님이 나중에 다시 못 찾는다. 목록은 언제든 열어볼 수 있어야 한다.

## 영향 범위

- **앞으로 모든 답변.** 여러 줄짜리 목록은 파일로 만들고 채팅에는 링크만 준다.
- 장군님이 채팅으로 물어보신 것도 마찬가지 — 답을 문서에 넣고 링크를 드린다.
- `always.md` 는 매 턴 주입되므로 다음 대화창부터 바로 걸린다.

## 검증

- `.claude/rules/always.md` 를 다시 읽어 반영 확인.
- 규칙을 그 자리에서 적용 — 채팅에만 있던 발견 1건을 `.docs/CURRENT.md` 미해결로 옮김.
- 코드 변경 없음 → `node --check` 대상 없음.

## 참고 사항

- `always.md` 는 「늘리지 말 것」이 원칙이라 **줄을 새로 추가하지 않고 기존 줄을 넓혀 다시 썼다.**
- 이번 대화에서 만든 목록은 이미 파일에 있다 — 별창 busy 테스트는 `.works/별창busy시작/00_현황판.md`,
  필수 의존성 판정 기준·결정은 `.works/필수의존성크리티컬/00_현황판.md`.
