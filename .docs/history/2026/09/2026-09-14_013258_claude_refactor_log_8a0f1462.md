바뀐 모양:

```js
console.error('[CRSH-011] could not build the crash report.', e);
        ↓
_writeMainLog('오류', '[CRSH-011] could not build the crash report.' + _errText(e));
```

**예외 내용이 이제 글자로 붙는다.** 전에는 `console.error` 의 둘째 인자라 로그 줄에 안 들어갔다.

### 2. 파일마다 작은 함수 2개를 새로 넣음

`ws_main_log.js` 를 뺀 6개 파일에:

```js
function _writeMainLog(sLevel, sText) {
    try {
        require('./ws_main_log').writeLog(sLevel, sText);   // msg/ 는 '../log/ws_main_log'
    } catch (e) {
        console.error(sText);   // 로그 장치를 못 얻으면 예전처럼 콘솔로(유실 방지)
    }
}

function _errText(e) {
    if (!e) { return ''; }
    return ' | ' + (e.message ? e.message : String(e));
}
```

`ws_main_log.js` 에는 `_errText` 만 넣었다(`writeLog` 가 같은 파일 안에 있다).

**순환 참조 없음** — `main.js:56` 이 `WsMainLog.install(app)` 을 가장 먼저 부르고,
여기서는 부를 때마다 늦게 `require` 한다. `ws_crash_report.js` 는 원래부터 이 방식이었다.

## 변경 이유

**화면(renderer)은 `console.error` 를 electron-log 로 갈아끼워 놨다**
(`www/ws30/ws10_20/js/ws_log.js:153` — `Object.assign(CONSOLE, log.functions)`).

누가 `'WARNING'`·`'Info'` 를 넘기면 그대로 찍혀 등급 글자가 제각각이 된다.
