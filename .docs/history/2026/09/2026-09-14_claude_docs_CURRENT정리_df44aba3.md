# CURRENT.md 에서 화면 작업과 무관한 도구·hook 항목을 제자리로 옮김

작업일: 2026-09-14 · 대화창: df44aba3

## 요청

> "지금 current.md 내용에 현재 작업해야할 내용과 무관한 내용이 있던데 정리좀해라"

## 무엇이 섞여 있었나

`.docs/CURRENT.md` 는 **새 대화창이 제일 먼저 읽는 문서**인데, 화면(UI5→HTML5) 작업과
**Claude 도구·hook·MCP 설정** 이야기가 한 표에 섞여 있었다. 새 대화창이 "지금 할 일"을 잘못 잡는다.

| 어디 | 섞여 있던 것 |
|---|---|
| 「지금 하는 일」 | 이력 게이트·CURRENT.md 관찰 · Claude 설정 전역화 |
| 「미해결」 | 세션 시작 hook 미동작 · 세션 시작 hook 문구가 옛 지시 · codex 답변끝 hook 미승인 · codex 전역 hook 2개 고장 |

## 변경 내용

**버리지 않고 전부 옮겼다.**

| 파일 | 무엇 |
|---|---|
| `.works/claude설정전역화/00_현황판.md` | 「남는 문제」 아래에 **"hook 관련 남는 문제 — CURRENT.md 에서 옮겨 옴"** 표를 새로 만들어 **5건 전부** 옮겨 적음(hook 4건 + 이력 게이트 관찰 1건). 미확인 표기도 그대로 유지 |
| `.docs/CURRENT.md` | 「지금 하는 일」 = **화면 작업 2줄만** 남김. 표 아래에 도구 현황판 링크 한 줄. 「미해결」 = 화면 것 2줄 + 도구 쪽 링크 1줄. 「쓰는 법」에 **"여기는 프로그램(화면) 작업만 적는다"** 한 줄 추가 |

백업: `.docs/_CURRENT.md.cleanupbak` · `.works/claude설정전역화/_00_현황판.md.movedbak`

## 변경 이유

CURRENT.md 는 **새 대화창의 출발점**이다. 여기에 도구 이야기가 섞이면 다음 agent 가
화면 작업 대신 hook 을 들여다본다. 영역별로 갈라 두는 기존 원칙(`.works/<영역>/00_현황판.md`)과도 맞다.

## 영향 범위

- 문서만. 코드·설정 변경 없음.
- **잃은 정보 없음** — 도구 작업의 테스트 항목·결정 대기는 원래부터 그 현황판 「지금 할 것 (장군님)」에
  있었고(확인함), 미해결 5건은 이번에 그 문서로 옮겼다.

## 검증

- 정리 후 `.docs/CURRENT.md` 전문을 다시 읽어 확인 — 「지금 하는 일」에 화면 작업 2줄만 남음.
- `.works/claude설정전역화/00_현황판.md` 의 「지금 할 것 (장군님)」에 테스트 항목이 그대로 있는지 확인함.
- 코드 변경 없음 → `node --check` 대상 없음.

  도구 현황판. 애매하면 CURRENT.md 에 두지 말고 영역 현황판으로 보낸다.
