## 요청

- 장군님 지적: 켜짐/꺼짐만 보는 busy 테스트(UB1~UB3)는 의미 없다. 볼 것은 **리소스 전 켜짐 · 끝난 뒤 꺼짐 · 중간 해제 0 · 오류 시 꺼짐+메시지**. 빠른 PC 에서는 눈으로 못 본다.
- busy 로그를 상시로 남기나 / 로그가 많이 쌓이지 않나 / PC 영향 / 비동기 쓰기 시 순서.
- 이후 지시: **로그 전략은 다른 AI 에이전트가 맡는다 — 여기서는 「화면이 뜨자마자 busy」에 집중.**
