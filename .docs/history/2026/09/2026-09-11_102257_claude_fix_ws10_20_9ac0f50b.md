# WS20 preview error hook - 대기 상한을 5분으로 (느린 PC 대응)

## 요청
장군님: "로드 시간 관련해서는 느린 pc도 고려해야되니까 최대 5분정도는 기다려야된다"
→ 추가 지시: "원본처럼 하는대신에 최대 5분정도 기다리는 로직"
(= 원본의 `_loaded` 완료 신호 방식으로 바꾸지 말고, 지금의 폴링 구조를 유지한 채 상한만 5분으로)

## 변경 내용
`www/ws30/ws10_20/js/ws_html5_ws20_prev.js` `_installPrevErrorSurface`

1. **상수 2개 신설** (1093~1094)
   - `PREV_ERR_SURFACE_WAIT_MS = 300000` (5분)
   - `PREV_ERR_SURFACE_POLL_MS = 200`
2. **`PREV-ERR-00` 대기 판정을 횟수 → 경과 시각으로** (1114~1150)
   - 종전 `iTry > 100` (100회 × 200ms ≒ 20초) → `Date.now() - __u4aPrevErrSurfaceT0 > 5분`
   - `setTimeout` 이 밀리는 느린 PC 에서도 실제 경과 기준이라 정확
3. **재시도 줄기 중복 방지** — `__u4aPrevErrSurfacePending` flag 추가
   - 종전엔 iframe `load` 마다 새 폴링 줄기가 생기는데 횟수는 `contentWindow` 에 공유돼,
     줄기가 늘수록 상한을 빨리 소진 = **느릴수록 더 빨리 포기**하는 거꾸로 된 구조였다
4. **포기 로그에 판단 근거 추가** (영문)
   - `waited=<ms> (limit <ms>) | tries=<n> | iframe src=<...> | readyState=<...>`
   - 종전엔 근거가 없어 "preview 가 진짜 안 뜬 것"인지 "src 조차 안 붙은 빈 document 를 본 것"인지
     로그로 구분 불가 → 실제로 2026-09-11 자동 시험 기록 1건의 원인을 확정하지 못했다
5. **`PREV-ERR-04`(sap.ui 대기)도 동일 처리** (1197, 1211~1229)
   - 종전 `iEngTry > 150` (약 30초) → 경과 5분, 포기 로그에 `waited/tries/readyState`

로직 흐름·감쌀 대상·오류 코드 체계는 그대로. 대기 판정 방식과 로그만 변경.

## 영향 범위

줄기 중복 방지를 넣어 iframe `load` 가 여러 번 나도 폴링 줄기는 1개만 돈다.

## 후속 (2026-09-11 10:2x) — 주석 정리

### 요청
장군님: "주석도 좀 가독성있게.., AI가 나중에 운영할때 참고해서 이해할 수 있는 수준이여야된다"

### 변경 내용
`_installPrevErrorSurface` 머리 주석을 통째로 다시 썼다. 절 구성:
- 무엇을 하는 코드인가 / 왜 필요한가
- wrap 대상과 오류코드 5개 (괄호 = 원본에서 그걸 부르는 자리)
- 설치 순서 1~4
- **AI 운영자용 — 로그로 판정하는 법** ← 핵심.
  `iframe src=(none)` = src 미부착 / `readyState=loading` = 진짜 로드 지연 /
  `readyState=complete` 인데 function 없음 = index.js 가 중간에 throw 했을 가능성.
  PREV-ERR-00/04 는 "미리보기가 깨졌다"가 아니라 "감시를 못 붙였다"는 뜻임을 명시.
- 원본(as-is) 과의 차이 + 왜 원본 방식(`_loaded`)을 안 쓰는지(장군님 지시)

상수 블록에 "왜 횟수→시각으로 바꿨는지 + 줄이려면 느린 PC 기준으로 재실측" 경고를 붙였다.
함수 안 주석은 contentWindow 에 붙는 상태 3개(`__u4aPrevErrSurfaceT0` / `...Try` / `...Pending`)가
각각 무슨 뜻인지 나열하고, iframe 이 새 document 로 바뀌면 자동 초기화된다는 점을 적었다.

### 같이 고친 것 — 지어낸 한글 제거 (장군님 지시 2026-09-11 반영)
- 주석: `덧씌우기`/`줄기`/`감쌈`/`엔진` → `wrap` / `retry` / `sap.ui`
- 로그 2개를 영문으로:
  - `"감쌀 대상 없음: " + sName` → `"wrap target missing - " + sName + " is not a function"`
  - `sDesc + " 실패:"` → `sDesc + " threw:"`
- 남아 있던 `[HTML5][WS20][prev]` prefix 1곳을 `[WS20][prev]` 로 통일
  (다른 세션이 이미 나머지를 그렇게 바꿔 둔 상태였다)
- 과거 일괄 치환이 **주석 안까지 먹어서** `try/catch (_u4aErr) { if (typeof U4ALOG ...) }` 가
  설명문 한가운데 박혀 있던 것 3곳 제거. 읽을 수가 없는 상태였다.
