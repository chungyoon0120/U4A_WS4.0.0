# 서버 목록 창 — 창이 뜰 때 busy 부터 켜기

## 요청

장군님 지시 2026-09-16: **「서버 목록 화면도 창이 뜰때 busy 부터」.**
이 대화창의 중점 = 「화면이 실행하자마자 busy 부터 잘 켜지는지」.

## 변경 내용

- `ServerList.js` 가 **읽히는 동안**(= 창이 보이기 전) busy 를 켜도록 한 줄을 넣었다.
  - 넣은 자리: 설정 정보 수신(`if-globalSetting-info`) 등록 **바로 앞**.
  - busy 요소는 `ServerList.html` 의 `<body>` 안, 이 스크립트보다 **위**에 있어 그 시점에 찾을 수 있다.
- busy 요소를 못 찾았을 때 조용히 그만두던 자리에 흔적을 남겼다(`SVLS-002`, 같은 이름 한 번만).
- 파일 머리 오류코드 다음 번호 002 → 003.

**끄는 곳은 종전 그대로** 시작 처리(`fnOnMainStart`)의 끝 한 곳뿐이다. 중간 해제는 만들지 않았다.

## 변경 파일

- 변경: `www/ServerList_v2/ServerList.js`
- 삭제: 없음

## 변경 이유

이 창을 여는 쪽(`www/intro.js`)은 문서 로드가 끝나면 설정 정보를 보내고 **곧바로 `show()`** 한다.
그런데 busy 를 켜는 곳은 그 설정 정보를 받은 뒤 도는 시작 처리 맨 위였다 —
**창이 보이는 순간에는 busy 가 꺼져 있었다**(서버 목록 busy 는 기본이 안 보임: `theme/shell.css` 970~984줄).

## 영향 범위

- 서버 목록 창만. 다른 창은 안 건드렸다.
- **알고 둘 것**: 설정 정보가 끝내 안 오면 이제 busy 가 계속 돈다(종전에는 빈 화면). 둘 다 고장이지만 화면 모습이 달라진다.
- busy 동안 화면 누름이 막히는 구간이 조금 길어진다(문서 로드 완료 ~ 시작 처리 끝).
