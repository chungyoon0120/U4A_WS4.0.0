# 신신당부 — 단순하게 가라 (장군님 지시 2026-10-13)

## 장군님 말씀 그대로

> 해야할 목록을 좀 깔끔하게 좀 정리해서 내가 해야할일 하나만 보고 차근차근 순서대로 할수 있게 환경 다 만들어놔
>
> 이렇게 단순한 작업을 이렇게 장황한 내용으로 존나 복잡하게 일을 하는 기분이 들어..
> 단순히 별창에 parent 띠고 그거 잘 됐는지 보는거 말고는없는데
> 니가 작성한 문서랑 니가하는 말을 보면 오히려 그거 읽느라, 파악하느라,
> 아 뭔가 존나 더 정신없고 가끔 뭘해야되는지 헷갈릴때가 있어.. 좀 단순히 가고 싶어
>
> **분석은 철저하게 답변은 이해하기 쉽고 군더더기 없게**

## 그래서 지켜라

1. **일의 실체를 한 줄로 못 적으면 손대지 마라.** 대개 일은 단순하다. 복잡한 건 내 설명이다.
2. **문서는 표 하나 + 조작 한 줄.** 10줄 넘기지 마라. 까닭·경위·근거·실패 기록은 **안 물으면 쓰지 않는다**(이력 파일에만).
3. **한 번에 하나만 보여라.** 선택지 늘어놓지 말고, 다음 할 하나만. 「1·2·3 중 고르십시오」를 남발하지 마라.
4. **분석은 끝까지.** 소스는 함수 본문·호출부까지 다 읽고 판정한다. 읽는 것은 답 길이와 무관하다 — 1000줄 읽고 3줄로 답한다.
5. **장군님이 알아야 할 것만 말한다.** 내가 뭘 빼먹었고 왜 그랬는지 따위는 보고가 아니라 소음이다.

## 어겼을 때 나오는 말 (경보)

「정신없다」 · 「뭘 하라는 거지」 · 「장황하다」 · 「읽을 게 많다」 · 「헷갈린다」
→ 이 말이 나오면 **그 즉시 문서를 줄이고 할 일 하나만 남긴다.**
