# 문서(.md/현황판/계획) 편집 직전 체크

- 테스트 절차·화면 설명·버튼 동작·표시 조건은 **소스로 확인 후** 기재. 추측 금지, 미확인은 "미확인" 표기.
- **용어는 화면/원본(as-is)** 것만. 내 코드 라벨 금지.
- 현황판(`00_현황판.md`)은 **현재 것만** 유지, 완료는 `00_히스토리.md`로 이관.
- 메시지 문구: **기존 메시지 = 원본(as-is) 참조**. 원본에 없는 새 문구는 **별도 지시가 없을 때만** `ZMSG_WS_COMMON_001` 사용(번호 거의 포화 → 추후 `ZMSG_WS_COMMON_002`로 바뀔 예정). 어느 경우든 임의 문구 생성 금지, 필요 키는 보고.
