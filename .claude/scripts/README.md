# 반복 작업 도구 (2026-10-06 장군님 지시로 만듦)

매번 손으로 여러 번 왔다 갔다 하던 것을 **한 번에** 끝내는 도구. 새로 짜지 말고 이걸 쓴다.

| 도구 | 언제 | 쓰는 법 |
|---|---|---|
| `gitcp.sh` | 커밋·푸시 지시를 받았을 때 | `bash .claude/scripts/gitcp.sh <<'EOF' … EOF` · `--to-main` 붙이면 main 머지·푸시까지 · `--dry` 는 계획만 |
| `testpass.py` | 테스트 통과 보고를 받았을 때 | `python .claude/scripts/testpass.py <영역폴더> <코드접두> [통과코드…]` |

## gitcp.sh 가 자동으로 지키는 것 (`.claude/rules/commit.md`)

- 제목 맨 앞 `[YYYY-MM-DD HH:MM]` · 끝에 `Co-Authored-By` 한 줄 (이미 있으면 안 붙인다)
- `main` 브랜치에서 커밋하려 하면 **멈춘다**(먼저 브랜치)
- 바뀐 파일이 없으면 멈춘다 · 머지 충돌이면 작업트리를 그대로 두고 멈춘다
- 끝나면 브랜치·커밋 번호·원격 번호·작업트리 건수를 한 번에 보여 준다

## testpass.py 가 자동으로 지키는 것 (`.claude/rules/document.md`)

- 통과 항목은 **그 자리에서** ☐ → ✅ O (순서 안 바꿈)
- 그룹의 **전 항목**이 통과해야 `00_히스토리.md` 로 **그룹째** 옮긴다. 하나라도 남으면 안 옮긴다
- 옮긴 뒤 현황판에는 「테스트할 것 — 없음 + 이관 완료」 한 줄만 남는다
- 무엇을 왜 고쳤는지 설명 문단은 **사람이 직접** 히스토리에 적는다(도구가 지어내지 않는다)

## 백업 파일은 만들지 않는다

장군님 지시 2026-10-06 — **git 이 백업이다.** `_` 접두 사본을 만들지 말고, 복원이 필요하면
`git restore <파일>` · `git checkout <커밋> -- <파일>` 로 되돌린다. `.gitignore` 에 백업 확장자를
추가하는 일도 하지 않는다. (상세 = `.claude/rules/code.md`)
