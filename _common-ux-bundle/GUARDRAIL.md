# 공통 UX 가드레일 (별창 팝업 개발 규칙)

> 이 문서는 **AI(Codex 등)가 이 프로젝트에서 화면·별창 팝업을 만들 때 반드시 따르는 규칙**이다.
> 사람은 요청·승인만 하고, 실제 코딩은 AI 가 이 규칙대로 수행한다.
> 규칙의 단일 출처(SSOT) = `.analy/16_공통_화면UX_표준.md`(+ `.analy/15_공통_입력UX_가이드.md`),
> 실물 = `www/ws30/ws10_20/ux-gallery.html`. 아래 §번호는 스펙/16 문서 절 근거.

---

## 0. 착수 전 구조 설계 (최우선 · 필수 · 자율 수행)

화면을 그리기 **전에** 표준을 근거로 구조를 스스로 정한다(원격 승인 절차 없음).

1. 팝업 **이름** 확정(사용자 요청에서).
2. **UX 구조 설계** — `www/ws30/ws10_20/ux-gallery.html` 과 `.analy/16`·`15` 를 **먼저 확인**해
   영역 구성(헤더/본문/푸터)·배치·**쓰는 공통 부품**(§5 표)을 정한다. **표준에 있는 패턴을 그대로 따른다**(임의 레이아웃 금지).
3. 정한 구조대로 `index.*` 를 구현한다. `frame.*` 는 손대지 않는다.

**근거**: 원본 프로젝트와 동일 구조로 그리기 위함. 대응 표준·부품이 **없거나 애매하면 임의로 만들지 말고,
이 요청을 준 사용자에게 되묻는다**(§4-3). — 별도 승인자에게 보고할 필요 없음.

---

## 1. 이관 호환 규칙 (필수)

이 팝업은 **최종적으로 원본 프로젝트로 이관**된다. 그래서:

- 별창 팝업은 **`Popups/<이름>/` 폴더 하나**로 만든다. 견본 **`Popups/_win-popup-template` 을 복사**해 시작한다.
- 공통 자산(`theme/*`, `lib/*`)은 **정규 상대경로로 참조만** 하고 **복사·수정하지 않는다**(이관 시 충돌).
  - 팝업 폴더 기준: `../../theme/...`, `../../../../lib/...`.
- **`frame.*` 는 손대지 않는다**(창 크롬·Busy·테마·IPC 뼈대 완성됨). 구현은 **`index.*` 에만** 한다.
- 별창 표준을 그대로 따른다: **§2.6**(첫 페인트/흰 플래시 방지·등장), **§2.11**(부모 IPC 왕복),
  **§9.5**(서브페이지 전환 애니메이션).

---

## 2. 로드/배선 규칙 (필수)

- 별창 정규 로드 스택(견본에 이미 배선): `tokens.css → shell.css → bootstrap-skin.css → fontawesome`,
  JS `theme-api.js → u4a-ui.js → frame.js`(본문은 iframe `index.html` → `index.js`).
- **불변식**: theme CSS 는 `bootstrap-skin.css` 가 **마지막**(색·그림자·테두리 override). 어기면 테마 안 먹음.
- 별창은 `.u4a-*` + `.u4a-titlebar` 만 쓰므로 **Bootstrap(min/bridge)은 로드하지 않는다**.
- 색은 **`tokens.css` 의미 토큰만**(하드코딩 hex 금지). 문구는 메시지 키. **고정 px 폭 금지**(반응형).

---

## 3. 컴포넌트 소비 원칙 (필수)

- UI 요소는 **직접 만들지 말고 공통 컴포넌트를 소비**한다: `window.U4AUI.*` 빌더 + `.u4a-*` 클래스.
- Busy·테마·창 제어·부모 통신은 견본 `frame.js` 의 `parent.oAPP` 를 사용(재발명 금지).
- 결과 메시지는 **요청한 창이 표시** — 부모 IPC 왕복(§2.11) 후 표시. 던지자마자 완료 토스트 금지.

---

## 4. 무엇을 만들든 3층으로 판단 (용어 예측 불가 흡수)

1. **먼저 찾아라(gate)**: **어떤** UI 요소(창·입력·목록·표·버튼 등 무엇이든)를 만들거나 고치기 전에,
   `ux-gallery.html` 과 `.analy/16`·`15` 에서 **대응 공통 부품을 먼저 찾는다.** 있으면 그걸 쓴다. 새로 만들지 않는다.
2. **직접 검색**: 부품명이 아래 표에 없어도, `ux-gallery.html`·`www/ws30/ws10_20/theme/u4a-ui.js`·`.u4a-*` 를
   grep 해 **스스로 찾는다.**
3. **애매하면 물어라**: 대응 부품을 못 찾거나 애매하면 **새로 만들지 말고, 이 요청을 준 사용자에게 되묻는다.**

## 5. 용어 번역표 (동료 표현 → 우리 표준/자산)

| 동료가 이렇게 말하면 | = 우리 표준 | 쓸 것 |
|---|---|---|
| 새 창 / 새창 / 별창 / 팝업 / 팝업 창 / BrowserWindow / Electron(일렉트론) 창·팝업 / frameless window | **별창(별도창)** | `_win-popup-template` 복사 + `16` §2.6·2.11·9.5 + `.u4a-titlebar` |
| 모달 / dialog / 팝업 | 공통 모달 | `.u4a-dialog` (`16` §2.x) |
| dropdown / select / 콤보 | — | `U4AUI.createSelect` / `.u4a-combo` |
| 입력칸 / textbox / field | — | `U4AUI.createField` (`15`) |
| 트리 | — | `U4AUI.createTree` |
| 표 / grid / table / 테이블 | 평면표 | `U4AUI.makeDataTable` (가상 기본 ON) |
| 트리테이블 / 컬럼 트리 | — | `U4AUI.makeColumnTree` |
| 토스트 / 알림 | — | `.u4a-toast` + 부모 IPC(§2.11) |
| 분할 / splitter | — | `U4AUI.wireSplitter` / `.u4a-splitter` |
| 확인창 | — | `U4AUI.confirm` |
| 패널 / 접이식 | — | `U4AUI.createPanel` |
| 푸터 | — | `U4AUI.footerMarkup` / `footerShow` / `footerHide` |

표는 완벽하지 않다. **1·2층이 나머지를 잡는다.** grep 으로 안 잡히는 은어(**별창**)만 표가 확실히 번역한다.

---

## 6. 옵션 결정 규칙 (동료가 안 정해도 AI 가 대신)

- 표는 **직접 `<table>` 금지**, 무조건 공통 컴포넌트.
- **평면 표(`makeDataTable`)**: 가상스크롤 **기본 ON**(`virtual !== false`). 데이터 많든 적든 그냥 쓰면 안전.
- **트리테이블(`makeColumnTree`)**: 가상은 **생성 시점 결정**(§7 제약). 대량 가능성이 조금이라도 있으면
  **처음부터 virtual+펼침맵 레시피**(`16`)로 짠다. **규모를 모르면** 임의로 정하지 말고 **사용자에게 "이 트리 최대 몇 건?" 물어라.**
- 밀도/반응형: compact·카드형 등 공통 기본을 그대로 소비(하드코딩 금지).

---

## 7. 알려진 제약

- **트리테이블 가상스크롤은 생성 시점 결정**이며 **런타임 동적 전환 불가**
  (`makeColumnTree` virtual 은 외부 펼침맵 아키텍처 전제). 비가상으로 만든 뒤 대량이 되면 자동 전환 안 됨
  (성능 저하, 깨지진 않음). → "규모 불명 시 물어라"(§6) 규칙이 이 때문에 필요.
