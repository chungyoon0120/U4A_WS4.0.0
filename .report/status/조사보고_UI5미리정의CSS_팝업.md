# 조사 보고서 — "UI5 미리 정의된 CSS" 메뉴

- **작성일**: 2026-07-08
- **조사한 것**: 화면 위 메뉴 `CSS 스타일 클래스` 안의 **"UI5 미리 정의된 CSS"** 버튼
- **한 줄 결론**: 이 창은 **속은 그대로 두고, 창 테두리(제목줄·닫기 버튼 같은 겉모습)만** 우리 공통 디자인으로 바꾸면 됩니다. **할 일 많지 않습니다.**

---

## 한눈에 보기

| 질문 | 답 |
|---|---|
| 지금 이 버튼 누르면? | **"아직 작업중입니다"** 안내 문구만 뜨고 아무것도 안 열립니다. |
| 원래 뭐 하는 창인가? | SAP가 미리 만들어 둔 **CSS 꾸미기 목록**을 보여주고, 고른 걸 미리보기 화면에 적용해 주는 창. |
| 왜 지금 안 열리나? | 예전 버전(SAP 방식)으로 만들어져 있고, **우리 새 디자인으로 아직 안 바꿔서** 잠가 둔 상태. |
| 바꾸기 어렵나? | **안 어렵습니다.** 창 안 내용물은 손 안 대고 겉모습만 갈아끼우면 됩니다. |

---

## 1. 지금 상태

- 이 버튼을 누르면 실제 창은 안 열리고 **"아직 작업중입니다"** 라는 안내만 뜹니다.
- 원래 이 창을 여는 코드는 **일부러 막아 둔(주석 처리)** 상태입니다. 즉, **아직 새 디자인으로 안 바꾼 미완성 화면** 중 하나입니다.

## 2. 이 창이 원래 하는 일

- **SAP가 기본으로 제공하는 화면 꾸미기(CSS) 목록**을 보여주는 창입니다.
- 사용자가 목록에서 하나를 고르면, 그 꾸미기가 **왼쪽 미리보기 화면에 바로 적용**됩니다.
- 예: 여백 주기, 여백 없애기, 화면 폭에 맞춰 간격 조절 같은 SAP 표준 스타일 샘플들.

## 3. 창의 속을 들여다본 결과 (제일 중요)

- 이 창의 **내용물(목록, 상세, 샘플 등)은 전부 SAP(서버)가 만들어 주는 걸 그대로 가져다 씁니다.**
- 즉, 우리가 **내용을 새로 만들 필요가 전혀 없습니다.** 이미 서버 쪽에 다 있습니다.
- 이건 예전에 이미 바꿔 본 **"아이콘 목록 팝업", "이미지 아이콘 팝업"과 똑같은 구조**입니다.
  - 그때도 **속은 그대로 두고 창 겉모습만** 바꿨고, 이번도 똑같이 하면 됩니다.

## 4. 그래서 뭘 바꾸면 되나

**창의 겉모습(테두리·제목줄·배경) 3군데만** 손보면 끝입니다. 창 안의 실제 목록/기능은 **건드리지 않습니다.**

| 순서 | 할 일 | 쉬운 설명 |
|---|---|---|
| ① | 버튼을 누르면 다시 창이 열리게 살리기 | 지금 막아 둔 "아직 작업중입니다"를 걷어냄 |
| ② | 창 여는 방식 바꾸기 | 예전 SAP식 창틀 → 우리 공통 창틀(제목줄·닫기 버튼 통일)로 교체 |
| ③ | 창 배경·제목줄 맞추기 | 열릴 때 흰 화면 깜빡임 없애고, 테마 색·제목줄을 우리 표준으로 |

**손대지 않는 부분**: 창 안에 뜨는 실제 CSS 목록·상세·샘플 (전부 SAP가 주는 내용 그대로).

## 5. 결정해 주셔야 할 것 (아직 안 정함)

- 이 창은 **두 종류**가 있습니다.
  - **최신용**: 요즘 서버에서 쓰는 창
  - **구버전용**: 오래된 서버에 접속할 때만 쓰는 창
- **최신용만 바꿀지, 둘 다 바꿀지** 정해 주시면 됩니다. (최신용만 바꾸면 일이 더 적습니다.)
