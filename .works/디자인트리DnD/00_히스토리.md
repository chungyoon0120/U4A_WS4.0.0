## BR15 — 끌기 후 흐린(놓기 금지) 표시 잔류 (2026-08-11 통과)

**무엇을 고쳤나(쉽게)**: Design Tree에서 UI를 끌면 놓을 수 없는 줄이 **흐리게(놓기 금지)** 표시된다. 손을 떼면 풀려야 하는데, **트리를 아래로 끌어 자동 스크롤이 내려간 뒤** ①놓을 수 있는 줄에 놓아 위치 선택 창이 뜨거나 ②트리 밖에 놓으면, 흐린 표시가 여러 줄에 **계속 남아** 있었다. 이제 끌기가 끝나면 어떤 경우든 흐린 표시가 확실히 풀린다.

원인: 트리가 가상 스크롤(보이는 줄만 그림)이라 자동 스크롤이 끌던 줄을 지워 네이티브 끌기종료 신호가 유실 → "끌기중" 상태가 안 꺼져 줄마다 흐림 유지. 원본 대조·코덱스·안티 3중 검수 통과.

| 코드 | 동작 | 조작·확인 포인트 | O/X |
|---|---|---|---|
| BR15-1 | 자동 스크롤 후 "놓기 가능 줄"에 놓아 선택 창이 떠도 흐림 안 남음 | ① WS20 편집 모드 ② Design Tree 여러 개 펼쳐 세로 스크롤 생기게 ③ UI 한 줄 끌기 ④ 트리 맨 아래로 내려 자동 스크롤 ⑤ 놓기 가능 줄에 손 떼기 → 위치 선택 창 ⑥ 위치 고르거나 창 닫기 → 흐린 표시 모두 사라짐 | ✅ O |
| BR15-2 | 자동 스크롤 후 "트리 밖"에 놓아도 흐림 안 남음 | ① 세로 스크롤 준비 ② UI 한 줄 끌어 아래로 자동 스크롤 ③ 트리 밖 빈 공간에 손 떼기(미리보기 놓기 가능 자리 제외) → 흐린 표시 모두 사라짐 | ✅ O |
| BR15-3 | 정상 끌기·연속 끌기 회귀 없음 | ① 스크롤 없이 UI 한 줄을 가까운 줄로 끌어 정상 이동/추가 ② 곧바로 다른 UI 한 번 더 끌어 놓기 → 두 번째도 정상 | ✅ O |

### 수정 위치(참고)
- `www/ws30/ws10_20/js/ws_html5_ws20_dnd.js` — `_dnd.seq`(끌기 회차) 추가 + `designTreeDragStart`에서 "끝나면 한 번만" 도는 종료 안전망(`_armDragEndSafetyNet`) 배선. Chromium은 끌기 중 마우스이동이 억제되므로 종료 후 첫 마우스이동으로 정리.

## DG — 놓기 대상 초록 테두리 오른쪽 잘림 (2026-08-11 통과) ※장군님 직접 지적(테스터 BR 아님)

**무엇을 고쳤나(쉽게)**: Design Tree에서 UI를 끌어 어떤 줄 위에 올리면 그 줄에 **초록 테두리(여기 놓을 수 있음 표시)**가 뜬다. 오른쪽 **[+][삭제] 고정 버튼칸이 불투명하게 줄 위를 덮고** 있어 초록 테두리의 **오른쪽이 잘려** 보였다. 초록 테두리를 **버튼칸보다 위 층에 얇게 덧그려** 오른쪽 끝까지 안 잘리게 했다(덧그림은 클릭 통과라 버튼은 그대로).

| 코드 | 동작 | 조작·확인 포인트 | O/X |
|---|---|---|---|
| DG1 | 놓기 대상 줄의 초록 "사방 테두리"가 안 잘림 | ① WS20 편집 모드 ② Design Tree에서 UI 한 줄을 끌기 ③ 다른 줄 가운데에 올려 초록 사방 테두리 뜨게 ④ 오른쪽 [+][삭제] 버튼 자리까지 초록 테두리가 이어지는지 | ✅ O |
| DG2 | 놓기 위치 "가로선"(위/아래)도 안 잘림 | ① UI 한 줄 끌기 ② 다른 줄 위/아래 경계에 올려 초록 가로선 뜨게 ③ 그 선이 오른쪽 버튼칸 자리까지 이어지는지 | ✅ O |
| DG3 | 버튼 클릭 통과(회귀) | ① 평소 상태에서 아무 줄의 [+]·[삭제] 버튼 눌러 정상 동작 | ✅ O |
