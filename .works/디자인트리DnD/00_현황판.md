## 지금 할 것 — DG(놓기 대상 초록 테두리 잘림) 수정 확인 ※장군님 직접 지적(테스터 BR 아님)

**무엇을 고쳤나(쉽게)**: Design Tree에서 UI를 끌어 어떤 줄 위에 올리면 그 줄에 **초록 테두리(여기 놓을 수 있음 표시)**가 뜬다. 그런데 오른쪽 **[+][삭제] 고정 버튼칸이 불투명하게 줄 위를 덮고** 있어서 초록 테두리의 **오른쪽이 잘려 보였다.** 이제 초록 테두리를 **버튼칸보다 위 층에 얇게 덧그려** 오른쪽 끝까지 안 잘리게 했다(버튼은 그대로 눌림).

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| DG1 | 놓기 대상 줄의 초록 "사방 테두리"가 안 잘림 | ① WS20에서 편집 모드로 들어간다. ② Design Tree에서 UI 한 줄을 잡아 끈다. ③ 다른 줄 **가운데**에 올려 그 줄에 **초록 사방 테두리**가 뜨게 한다. ④ 그 줄의 **오른쪽 [+][삭제] 버튼 자리까지 초록 테두리가 이어져** 보이는지 본다. → 오른쪽이 잘리면 ❌. | ☐ |
| DG2 | 놓기 위치 "가로선"(위/아래)도 안 잘림 | ① 위처럼 UI 한 줄을 끈다. ② 다른 줄의 **위쪽 경계**(또는 아래쪽 경계)에 올려 **초록 가로선**이 뜨게 한다. ③ 그 가로선이 **오른쪽 버튼칸 자리까지 이어져** 보이는지 본다. → 오른쪽이 잘리면 ❌. | ☐ |
| DG3 | 버튼 클릭 통과 확인(회귀) | ① 끌지 않은 평소 상태에서 아무 줄의 **[+]**(추가)와 **[삭제]** 버튼을 각각 눌러 본다. → 덧그린 테두리 때문에 버튼이 안 눌리면 ❌(정상 동작해야 함). | ☐ |

## BR15(끌기 후 흐린 표시 잔류) 수정 확인

**무엇을 고쳤나(쉽게)**: Design Tree에서 UI를 끌면 놓을 수 없는 줄이 **흐리게(놓기 금지)** 표시된다. 손을 떼면 풀려야 하는데, **트리를 아래로 끌어 자동으로 스크롤이 내려간 뒤** ①놓을 수 있는 줄에 놓아 위치 선택 창이 뜨거나 ②트리 밖에 놓으면, 흐린 표시가 여러 줄에 **계속 남아** 있었다. 이제 끌기가 끝나면 어떤 경우든 흐린 표시가 확실히 풀리게 했다.

> ※ 재현하려면 **트리 줄이 화면보다 많아 세로 스크롤이 생기는 상태**여야 한다(트리를 여러 개 펼쳐 둔다). 그래야 끌 때 자동 스크롤이 일어난다.

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| BR15-1 | 자동 스크롤 후 "놓기 가능 줄"에 놓아 선택 창이 떠도 흐림 안 남음 | ① WS20에서 편집 모드로 들어간다. ② 왼쪽 Design Tree를 여러 개 펼쳐 **줄이 화면을 넘겨 세로 스크롤이 생기게** 한다. ③ 트리에서 UI 한 줄을 잡아 끈다. ④ 끈 채로 **트리 맨 아래쪽으로 내려 자동 스크롤이 아래로 움직이게** 한다. ⑤ 놓을 수 있는 줄(놓기 표시가 뜨는 줄)에 손을 뗀다 → **위치(Aggregation) 선택 창**이 뜬다. ⑥ 창에서 위치를 고르거나 창을 닫는다. → **트리의 흐린(놓기 금지) 표시가 모두 사라져야 한다.** 여러 줄이 계속 흐린 채 남으면 ❌. | ☐ |
| BR15-2 | 자동 스크롤 후 "트리 밖"에 놓아도 흐림 안 남음 | ① 위처럼 세로 스크롤이 생기게 준비한다. ② UI 한 줄을 잡아 끌고 **아래로 내려 자동 스크롤을 일으킨다.** ③ **트리 영역 밖의 빈 공간**(회색 여백 등)에 손을 뗀다(★가운데 미리보기의 놓을 수 있는 자리는 제외 — 순수 빈 공간에 놓기). → **트리의 흐린 표시가 모두 사라져야 한다.** | ☐ |
| BR15-3 | 정상 끌기·연속 끌기 회귀 없음 | ① 스크롤을 일으키지 않고 UI 한 줄을 가까운 다른 줄로 끌어 놓아 **정상 이동/추가**되는지 본다(끌 때 흐림 떴다가 놓으면 사라짐). ② 곧바로 **다른 UI를 한 번 더** 끌어 놓는다 → **두 번째 끌기도 정상 동작**해야 한다. → 안전망 때문에 끌기가 중간에 끊기거나 다음 끌기가 안 되면 ❌. | ☐ |

### 수정 위치(참고)
- `www/ws30/ws10_20/js/ws_html5_ws20_dnd.js`
  - `_dnd.seq`(끌기 회차) 추가.
  - `designTreeDragStart`에서 끌기 시작 시 "끝나면 한 번만 도는" 종료 안전망(`_armDragEndSafetyNet`) 배선.
  - 원인: 트리가 가상 스크롤(보이는 줄만 그림)이라 자동 스크롤이 끌던 줄을 지워 네이티브 끌기종료 신호가 유실 → `_dnd.active`가 안 꺼져 줄마다 흐림 유지. Chromium은 끌기 중 마우스이동이 억제되므로 종료 후 첫 마우스이동으로 확실히 정리.
