## ▶️ 미적용 대기 (원본과 다른 3건 — 장군님 지시 있을 때만 손댐)

> 안티(agy) 검수 완료. 완전 누락은 0건이고, 아래는 "원본과 다르게 구현된" 항목이라 **지시 전엔 그대로 둠**.

1. **★UI 유형 바꾸면 작성 중 표가 통째로 사라짐** — 원본은 "빈값으로 바꿀 때만" 초기화. 현행은 매번 초기화(모델 재선택 필요). **데이터 유실 위험 → 1순위 원복 권장.** (현행 `_wzOnChoice` 1117~1122)
2. **정렬순서 칸 음수 입력 가능** — 원본은 0 미만 막는 +/- 숫자칸. 현행은 일반 입력칸. (음수 차단 `Math.max(0,…)` 정도 권장) (현행 1417~1424)
3. **필수 칸 별표(*) 없음** — 검증(268/050/348)은 정상이라 기능 결함 아님. 여유 시 표기만.
4. (별건) Web Dynpro **준비중 안내 문구가 메시지 키가 아니라 글자로 박힘**(현행 436~440). 원본에 해당 키 없으면 **신규 키 1개 필요**(보고 대상).
