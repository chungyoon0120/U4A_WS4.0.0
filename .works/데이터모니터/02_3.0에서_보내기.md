## ★ 하는 순서

| # | 할 것 |
|---|---|
| ① | **4.0** 을 띄우고 **테스트 메뉴 > 데이터 모니터** 를 연다 → 창이 뜨면서 **8888 이 열린다** |
| ② | 그 창에서 **비교 뷰** 를 누른다 → 왼쪽 위에 `8888 열림 — 3.0 에서 보내십시오` 가 보이면 준비 끝 |
| ③ | **3.0** 을 띄우고 WS10 화면까지 간다 |
| ④ | 3.0 화면에서 **개발자 도구** 를 열고 **Console** 에 아래 **[코드 1]** 을 붙여 넣는다 |
| ⑤ | 이어서 **[코드 2]** 를 붙여 넣는다 → 화면 오른쪽 아래에 **3.0 → 4.0 보내기** 단추가 생긴다 |
| ⑥ | 3.0 에서 확인할 조작을 한다 (예: 앱이름 작성 후 편집모드 진입) |
| ⑦ | **3.0 → 4.0 보내기** 를 누른다 |
| ⑧ | 4.0 데이터 모니터 창의 비교 뷰에서 **왼쪽(3.0)** 에 데이터가 뜬다. 4.0 것은 그때 같이 담긴다 |
| ⑨ | 4.0 에서도 **같은 조작**을 한 뒤 **4.0 지금 담기** 를 누르면 오른쪽이 그 시점으로 바뀐다 |
| ⑩ | **다른 것만** 을 켜면 어긋난 자리만 남는다 |

## [코드 1] 감지 코드 싣기

4.0 의 감지 파일을 **그 자리에서 읽어 돌린다.** 3.0 에 파일을 만들지 않는다.

```js
(function () {
    var sPath = "C:\\Users\\socce\\Documents\\Github\\CHUNGYOON0120\\U4A_WS4.0.0\\www\\ws30\\ws10_20\\js\\ws_html5_datamon.js";
    var sSrc = require("fs").readFileSync(sPath, "utf8");
    (0, eval)(sSrc);
    console.log("[DM30] INFO ENGINE_LOADED datamon=", typeof oAPP.datamon);
})();
```

> **경로는 4.0 소스가 있는 자리다.** 다른 PC 에서는 그 PC 의 4.0 경로로 바꾼다.
> 파일 내용을 통째로 복사해 붙여 넣어도 결과는 같다.

이어서 감시를 켠다(조작할 때마다 3.0 안에서 변경을 모아 둔다).

```js
oAPP.datamon.start(function (oBatch) {
    console.log("[DM30] INFO CHANGE_BATCH", oBatch.번호, oBatch.조작, oBatch.변경.length);
});
```

## [코드 2] 보내기 단추 만들기

```js
(function () {

    var C_URL = "http://127.0.0.1:8888/snapshot";

    //이미 만들어 둔 것이 있으면 지우고 새로 만든다(여러 번 붙여 넣어도 하나만 남게).
    var oOld = document.getElementById("dm30SendBtn");
    if (oOld) { oOld.remove(); }

    var oBtn = document.createElement("button");
    oBtn.id = "dm30SendBtn";
    oBtn.type = "button";
    oBtn.textContent = "3.0 → 4.0 보내기";
    oBtn.style.cssText =
        "position:fixed; right:16px; bottom:16px; z-index:2147483647;" +
        "padding:8px 14px; font-size:13px; cursor:pointer;" +
        "background:#0070f2; color:#fff; border:0; border-radius:6px;";

    oBtn.addEventListener("click", function () {

        if (!window.oAPP || !oAPP.datamon || typeof oAPP.datamon.snapshot !== "function") {
            console.error("[DM30] ERROR ENGINE_MISSING - run the loader snippet first. nothing was sent.");
            oBtn.textContent = "감지 코드 먼저";
            return;
        }

        var oSnap = oAPP.datamon.snapshot();

        if (!oSnap) {
            console.error("[DM30] ERROR SNAPSHOT_EMPTY - nothing was sent.");
            oBtn.textContent = "담을 것이 없음";
            return;
        }

        var sBody = "";
        try {
            sBody = JSON.stringify({ FROM: "3.0", TIME: new Date().toISOString(), SNAP: oSnap });
        } catch (e) {
            console.error("[DM30] ERROR SNAPSHOT_STRINGIFY_FAILED - nothing was sent:", e);
            oBtn.textContent = "글자로 못 바꿈";
            return;
        }

        oBtn.disabled = true;
        oBtn.textContent = "보내는 중…";

        fetch(C_URL, {
            method: "POST",
            headers: { "Content-Type": "application/json" },
            body: sBody
        }).then(function (res) {
            if (!res.ok) { throw new Error("HTTP " + res.status); }
            return res.json();
        }).then(function (oRes) {
            console.log("[DM30] INFO SEND_DONE size=" + sBody.length + " roots=" + (oRes && oRes.ROOTS));
            oBtn.textContent = "보냄 (" + sBody.length + "자)";
        })["catch"](function (e) {
            //4.0 창이 안 떠 있거나 8888 이 안 열렸으면 여기로 온다 - 조용히 넘기지 않는다.
            console.error("[DM30] ERROR SEND_FAILED url=" + C_URL + " - is the 4.0 data monitor window open?", e);
            oBtn.textContent = "보내기 실패";
        }).then(function () {
            oBtn.disabled = false;
            setTimeout(function () { oBtn.textContent = "3.0 → 4.0 보내기"; }, 2500);
        });
    });

    document.body.appendChild(oBtn);
    console.log("[DM30] INFO SEND_BUTTON_READY url=" + C_URL);
})();
```

## 안 될 때 보는 곳

| 증상 | 어디를 보나 |
|---|---|
| 단추를 눌러도 **보내기 실패** | 4.0 데이터 모니터 창이 떠 있는지. 그 창 개발자 도구에 `COMPARE_PORT_LISTEN_FAILED` 가 있으면 8888 을 이미 다른 것이 쓰고 있다 |
| **감지 코드 먼저** 라고 뜸 | [코드 1] 을 안 돌렸거나 경로가 틀렸다 |
| **담을 것이 없음** | 3.0 콘솔에 `DMON-009` 가 있는지 본다 |
| 4.0 화면에 아무 변화 없음 | 4.0 창 개발자 도구에 `SNAPSHOT_FROM_3_0 received` 가 찍히는지 본다 |
