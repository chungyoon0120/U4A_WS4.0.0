### 테스트 그룹 DMT — 트리 뷰 (미테스트 16건)

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| DMT1 | 뷰 바꾸기 | ① 창 위쪽 줄에서 **트리 뷰** 를 누른다 ② 표 대신 접었다 펼치는 목록이 나오는지 본다 ③ **리스트 뷰** 를 누르면 원래 표로 돌아오는지 본다 | ☐ |
| DMT2 | 칸 다섯 개 | ① 트리 뷰에서 맨 윗줄에 **이름 / 종류 / 이전 / 현재 값 / 시각** 다섯 칸이 보이는지 본다 ② 칸 사이 경계를 끌어 폭이 바뀌는지 본다 | ☐ |
| DMT3 | 값 바꾸면 트리도 따라온다 | ① **감시 시작** 을 누른다 ② **트리 뷰** 를 누른다 ③ 편집 화면(WS20)에서 속성 값 하나를 고쳐 확정한다 ④ **트리 뷰를 보고 있는 그대로** 그 자리 줄에 새 값·**종류**·**이전**·**시각** 이 나타나는지 본다 (리스트 뷰로 갔다 오지 않아도 됨) | ☐ |
| DMT4 | 종류로 걸러내기 | ① 트리 뷰에서 왼쪽 펼침 목록을 연다 ② **전체 데이터 / 변경분만 / 변경 / 추가** 네 가지가 있는지 본다 ③ **변경** 을 고르면 **종류** 칸이 **변경** 인 줄만 남는지 본다 ④ **추가** 를 고르면 **추가** 인 줄만 남는지 본다 ⑤ **변경분만** 은 둘 다 나오는지 본다 ⑥ **전체 데이터** 로 고르면 전부 돌아오는지 본다 | ☐ |
| DMT5 | 이름 찾기 | ① 트리 뷰에서 **이름 찾기** 칸에 이름 일부를 쳐 넣는다 ② 그 이름이 든 자리와 **거기까지 가는 길**만 남는지 본다 ③ 걸린 자리에 자식이 있으면 **자식이 같이 보이는지** 본다(눌러서 더 내려갈 수 있어야 함) ④ **값에만 있는 글자**(화면 값에는 있지만 이름에는 없는 글자)를 쳐 넣으면 **찾는 것이 없습니다.** 가 나오는지 본다 ⑤ 칸 오른쪽 **X** 를 눌러 지우면 전부 돌아오는지 본다 | ☐ |
| DMT6 | 아무것도 없을 때 문구 | ① **기록 지우기** 를 누른 뒤 ② 펼침 목록을 **변경분만** 으로 고른다 ③ 가운데에 **변경된 것이 없습니다.** 라고 나오는지 본다 (**볼 데이터가 없습니다.** 가 아니어야 함) | ☐ |
| DMT8 | 이름 셀 눌러서 펼치기 | ① 트리 뷰에서 접힌 줄의 **이름** 셀을 누른다 ② **글자 위·아래 빈 자리**, **글자 오른쪽 빈 자리**, **들여쓰기 자리** 어디를 눌러도 펼쳐지는지 본다 ③ 다시 누르면 접히는지 본다 ④ 화살표를 직접 눌렀을 때도 한 번만 먹는지(눌렀는데 도로 닫히지 않는지) 본다 | ☐ |
| DMT9 | 추가된 게 뭔지 보인다 | ① **감시 시작** 을 누르고 **트리 뷰** 로 간다 ② 편집 화면(WS20)에서 UI 를 하나 새로 추가한다 ③ **종류** 가 **추가** 인 줄의 **현재 값** 컬럼에 무엇이 생겼는지 내용이 적히는지 본다 (펼치지 않아도 보여야 함) | ☐ |
| DMT10 | 접으면 그 아래도 접힌다 | ① 트리 뷰에서 줄 하나를 펼치고, 그 안의 줄도 펼친다 ② 맨 위 줄을 **접는다** ③ 같은 줄을 **다시 펼친다** ④ 안쪽 줄이 **접힌 채로** 나오는지 본다(통째로 다시 펼쳐지면 안 됨) | ☐ |
| DMT11 | 걸러내기 켠 채로 접었다 펴기 | ① 트리 뷰 왼쪽 펼침 목록에서 **추가** 를 고른다 ② 맨 위 줄을 **접는다** ③ 같은 줄을 **다시 펼친다** ④ 안쪽 줄이 **접힌 채로** 나오는지 본다 ⑤ **이름 찾기** 칸에 글자를 넣은 상태에서도 ②③④ 를 똑같이 해 본다 | ☐ |
| DMT12 | 여러 번 눌러도 어긋나지 않는다 | ① 줄 하나의 **이름** 칸을 눌러 접는다 ② 같은 자리를 눌러 편다 ③ 이것을 **다섯 번 되풀이**한다 ④ 매번 접힘·펼침이 번갈아 되는지 본다(눌렀는데 아무 일도 안 일어나거나, 도로 제자리로 돌아오면 X) ⑤ 화살표를 눌러서도 똑같이 다섯 번 해 본다 | ☐ |
| DMT14 | path 눌러 트리로 점프 | ① **리스트 뷰** 에서 줄이 쌓이게 화면을 조작한다 ② 한 줄의 **path** 칸에 마우스를 올려 **손 모양**으로 바뀌고 밑줄이 생기는지 본다 ③ 그 칸을 누른다 ④ **트리 뷰** 로 넘어가면서 그 자리가 **화면 가운데에 선택된 채로** 나오는지 본다 ⑤ 가는 길(윗자리)이 전부 펼쳐져 있는지 본다 | ☐ |
| DMT15 | 걸러내기 켠 채로 점프 | ① 트리 뷰에서 **이름 찾기** 칸에 아무 글자나 넣어 목록을 좁힌다 ② 왼쪽 펼침 목록도 **추가** 로 고른다 ③ **리스트 뷰** 로 가서 아무 줄의 **path** 칸을 누른다 ④ 찾기 칸이 **비워지고** 펼침 목록이 **전체 데이터** 로 돌아온 채, 그 자리에 서는지 본다 | ☐ |
| DMT16 | path 글자 복사는 그대로 | ① 리스트 뷰에서 **path** 칸의 글자를 마우스로 끌어 블럭을 잡는다 ② 마우스를 뗀다 → **트리 뷰로 넘어가지 않고** 블럭이 남아 있는지 본다 ③ Ctrl+C 로 복사되는지 본다 | ☐ |
| DMT13 | 종류 이름이 바뀌었다 | ① 감시를 켜고 편집 화면(WS20)에서 값을 하나 고친다 ② 리스트 뷰 **종류** 칸에 **변경** 이라고 나오는지 본다(**바뀜** 이면 X) ③ UI 를 하나 새로 추가하고 **추가** 라고 나오는지 본다(**생김** 이면 X) | ☐ |
| DMT7 | 덩치 커도 버티나 | ① **공통코드 포함** 과 **라이브러리 원장 포함** 을 둘 다 켠다 ② 트리 뷰에서 위아래로 빠르게 굴려 본다 ③ 끊기거나 멈추지 않는지 본다 | ☐ |

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| DME1 | 속성 dropdown 값 바꾸면 잡히나 | ① 앱을 다시 띄운다 ② 앱을 열어 편집 화면(WS20)으로 간다 ③ **테스트 > 데이터 모니터** 를 열고 **감시 시작** 을 누른다 ④ WS20 오른쪽 속성 영역에서 아무 **펼침 목록** 을 열어 다른 값을 고른다 ⑤ 모니터 **리스트 뷰** 에 그 값 줄이 뜨는지 본다(안 뜨면 X) | ☐ |

| DME4 | 끌어 놓기가 잡히나 | ① 감시 켠 상태에서 WS20 트리에서 항목을 **끌어다 다른 자리에 놓는다** ② 놓은 뒤에 모니터에 줄이 뜨는지 본다(끄는 도중엔 안 떠도 정상) | ☐ |

### 테스트 그룹 DM — 내부 데이터 모니터 (미테스트 12건)

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| DM1 | WS10 메뉴에 항목이 보인다 | ① 로그인해서 앱 목록 화면(WS10)까지 간다 ② 위 메뉴에서 **테스트** 를 누른다 ③ 목록 맨 아래에 **데이터 모니터** 가 보이는지 본다 | ☐ |
| DM2 | WS20 메뉴에 항목이 보인다 | ① 앱을 하나 열어 편집 화면(WS20)으로 간다 ② 위 메뉴에서 **테스트** 를 누른다 ③ 목록 맨 아래에 **데이터 모니터** 가 보이는지 본다 | ☐ |
| DM3 | 창이 뜨고 흰 번쩍이 없다 | ① 어두운 테마인 상태에서 **테스트 > 데이터 모니터** 를 누른다 ② 창이 뜨는 순간 **하얗게 번쩍이지 않는지** 본다 ③ 창 안 배경이 앱과 같은 색인지 본다 | ☐ |
| DM4 | 감시 켜고 끄기 | ① 창에서 **감시 시작** 을 누른다 ② 오른쪽 글자가 **감시 켜짐** 으로 바뀌고 버튼 글자가 **감시 중지** 로 바뀌는지 본다 ③ 다시 누르면 **감시 꺼짐** 으로 돌아오는지 본다 | ☐ |
| DM5 | 속성 값을 바꾸면 기록이 쌓인다 | ① 창에서 **감시 시작** 을 누른다 ② 편집 화면(WS20)에서 왼쪽 트리의 UI 하나를 고른다 ③ 오른쪽 속성 목록에서 아무 값이나 고쳐 넣고 다른 데를 눌러 확정한다 ④ 창에 줄이 하나 새로 쌓이는지 본다 | ☐ |
| DM6 | 열마다 걸러내기 | ① 리스트 뷰에서 열 제목 바로 아래 칸에 글자를 쳐 넣는다 ② 그 글자가 든 줄만 남는지 본다 ③ 칸 오른쪽 **X** 를 눌러 지우면 전부 돌아오는지 본다 ④ **종류** 칸의 펼침 목록에 **전체 / 바뀜 / 생김** 세 가지만 있는지 본다(**없어짐** 은 없어야 함) ⑤ **생김** 을 골라도 같은 식으로 걸러지는지 본다 | ☐ |
| DM7 | 지금 비교 | ① 편집 화면에서 값을 하나 바꾼다 ② 창에서 **지금 비교** 를 누른다 ③ 바뀐 게 더 있으면 줄이 쌓이고, 없으면 아무 일도 안 일어나는지 본다 | ☐ |
