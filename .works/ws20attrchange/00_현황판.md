## 지금 할 것 (미테스트)

### BR54 — 속성 값 변경 갈래 정리

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| BR54-1 | 글자 입력 속성 값이 그대로 반영된다 | ① 앱을 껐다 켠다 ② 편집(Change) 모드로 연다 ③ 왼쪽 `Design Tree` 에서 Button 을 클릭한다 ④ 오른쪽 `Attribute` 에서 `text` 줄의 값 칸에 `가나다` 를 입력하고 Tab 을 누른다 ⑤ 그 줄에 변경 표시가 생기는지 본다 ⑥ 가운데 미리보기의 Button 글자가 `가나다` 로 바뀌는지 본다 | ✅ O |
| BR54-2 | 드롭다운·체크박스 속성 값이 그대로 반영된다 | ① 왼쪽 `Design Tree` 에서 Button 을 클릭한다 ② 오른쪽 `Attribute` 에서 `type` 줄의 드롭다운을 열어 `Emphasized` 를 고른다 ③ 그 줄에 변경 표시가 생기는지 본다 ④ 같은 목록에서 `enabled` 줄의 체크를 끈다 ⑤ 그 줄에도 변경 표시가 생기는지 본다 | ✅ O |
| BR54-3 | `Reset` 이 바꾼 속성을 **하나도 빠짐없이** 되돌린다 ★핵심 | ① BR54-1·BR54-2 를 이어서 한다(속성 3개가 바뀐 상태) ② 오른쪽 `Attribute` 위쪽의 `Reset` 을 누른다 ③ `text` 값이 비워지는지 본다 ④ `type` 이 `Default` 로 돌아오는지 본다 ⑤ `enabled` 체크가 다시 켜지는지 본다 ⑥ 세 줄 모두 변경 표시가 사라지는지 본다 | ✅ O |
| BR54-4 | `Reset` 을 되돌리기 한 번으로 전부 복원한다 | ① BR54-3 직후 상태에서 시작한다 ② 위쪽 도구모음의 되돌리기(↶) 를 **한 번만** 누른다 ③ `text` 가 `가나다` 로 돌아오는지 본다 ④ `type` 이 `Emphasized` 로 돌아오는지 본다 ⑤ `enabled` 체크가 다시 꺼지는지 본다 | ❌ X — 값은 복원되나 **미리보기에 버튼이 안 그려짐**(2026-08-31) |
| BR54-5 | 값도움으로 고른 값이 그대로 반영된다 | ① 왼쪽 `Design Tree` 에서 Input 을 클릭한다 ② 오른쪽 `Attribute` 에서 `Search Help` 줄의 값 칸 오른쪽 돋보기를 누른다 ③ 뜬 목록에서 아무 줄이나 더블클릭한다 ④ 고른 값이 `Search Help` 줄에 들어오는지 본다 ⑤ 다른 속성 줄을 눌러 화면이 잠기지 않았는지 본다 | ☐ |
| BR54-6 | 값 변경 중 화면 잠금이 남지 않는다 | ① BR54-1 ~ BR54-5 를 마친 뒤 왼쪽 `Design Tree` 의 다른 UI 를 클릭한다 ② 트리가 바로 반응하는지 본다 ③ 오른쪽 `Attribute` 목록이 새 UI 것으로 바뀌는지 본다 ④ F12 콘솔에 빨간 오류가 없는지 본다 | ☐ |
| BR54-7 | 전용 처리 대상 속성에서 전용 창이 뜬다 ★본기능 | ① 앱을 껐다 켠다 ② 편집(Change) 모드로 연다 ③ 오른쪽 `Attribute` 위쪽의 `Show Changed Items` 가 꺼져 있는지 본다 ④ 왼쪽 팔레트에서 `FileUploader` 를 화면에 끌어다 놓는다 ⑤ 왼쪽 `Design Tree` 에서 방금 넣은 `FileUploader` 를 클릭한다 ⑥ 오른쪽 `Attribute` 목록을 내려 `imageCompressSettings` 줄을 찾는다 ⑦ 그 줄의 값 칸을 클릭한다 ⑧ 켜기/끄기와 품질 조절이 있는 작은 창이 뜨는지 본다 ⑨ 안 뜨면 F12 콘솔에 빨간 오류가 남는지 본다 | ☐ |

> BR54-7 결과 해석 — **창이 뜬다** = 정상 / **반응 없고 콘솔 오류** = 창이 아직 옛 화면틀(RM8) / **속성 줄이 안 보인다** = 서버 라이브러리를 앱이 다 못 받은 상태
