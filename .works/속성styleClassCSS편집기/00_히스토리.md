# 속성 styleClass 값칸 더블클릭 → CSS 편집기 (히스토리)

> 통과 완료된 그룹을 그룹째 이관. 최신이 위.

## BR32 — styleClass 값칸 더블클릭 → CSS 편집기 (2026-08-14 통과, 노션=수정완료)

원본 attrDblclickEvent→attrDblClickStyleClass 이식. 값칸 더블클릭 시 **커서가 놓인 그 단어(공백 기준)만** 취득해 CSS 편집기에 넘기면, 편집기가 그 단어를 찾아 블럭(선택강조)한다. 없으면 강조 없음. F4 복사·값 지우기 버튼·바인딩 styleClass·빈 값은 제외. 화면잠금은 편집기 여는 함수가 관리(디스패처 선-잠금 없음 → 로드 실패 고착 없음).

| 코드 | 동작 | 조작·확인 포인트 | O/X |
|---|---|---|---|
| BR32-1 | 편집기에 없는 단어를 더블클릭하면 아무것도 강조 안 됨 | ① Edit 메뉴 CSS Editor에 `.test{...}` 만 저장 ② `SELECTOPTION21` 선택 ③ styleClass 값칸에 `sapUiTinyMargin test` ④ 앞 단어 `sapUiTinyMargin` 두 번 클릭 → 편집기 뜨지만 강조 없음 | ✅ O |
| BR32-1b | 편집기에 있는 단어를 더블클릭하면 그 부분 강조 | 같은 값에서 뒤 단어 `test` 두 번 클릭 → 편집기의 `test` 블럭 강조·스크롤 | ✅ O |
| BR32-2 | 값칸 오른쪽 복사(겹친 사각형) 아이콘 두 번 클릭 → CSS 편집기 안 뜸 | 복사 아이콘 두 번 클릭 → 코드 편집 창 안 뜸 | ✅ O |
| BR32-3 | 값칸 지우기(X) 버튼 두 번 클릭 → CSS 편집기 안 뜸 | X 버튼 두 번 클릭 → 값만 지워짐 | ✅ O |
| BR32-4 | 바인딩(사슬) 걸린 styleClass 값칸 두 번 클릭 → 안 뜸 | 사슬 건 뒤 값칸 두 번 클릭 → 안 뜸 | ✅ O |
| BR32-5 | 빈 값 styleClass 값칸 두 번 클릭 → 안 뜸 | 빈 값칸 두 번 클릭 → 안 뜸 | ✅ O |
| BR32-6 | 편집기 연 뒤 화면잠금 정상 해제(고착 없음) | 편집기 띄우고 닫은 뒤 WS20 클릭 → 정상 조작 | ✅ O |
