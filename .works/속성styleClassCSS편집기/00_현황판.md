# 속성 styleClass 값칸 더블클릭 → CSS 편집기 (현황판)

> 화면: WS20 속성 영역. styleClass 프로퍼티 값칸을 두 번 클릭하면 CSS 편집기 창이 뜬다(원본 attrDblclickEvent→attrDblClickStyleClass 이식). 검수: `.audit/br32/`.
> 표기: ☐ 미테스트 / ✅ O 통과 / ❌ X.

## 지금 할 것 — BR32

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| BR32-1 | styleClass 값칸 두 번 클릭 → CSS 편집기 뜨고, 같은 이름 클래스가 블럭(선택강조)됨 | ① 화면 위 `Edit` 메뉴 → `CSS Editor` 를 열어 `.myBox { color:red; }` 처럼 클래스 하나를 적어 저장하고 닫는다(편집기에 그 클래스가 있게 만든다). ② WS20에서 `SELECTOPTION21` UI를 한 번 클릭해 선택한다. ③ 오른쪽 속성 목록의 `styleClass` 값 입력칸에 위와 같은 이름 `myBox` 를 직접 입력하고 Enter 한다. ④ 그 값 입력칸(글자 부분)을 **빠르게 두 번 클릭**한다. → **CSS 편집기 창이 뜨고, 편집기 안의 `.myBox` 부분이 블럭(선택강조)된 채 그 위치로 스크롤된다.** (편집기에 같은 이름 클래스가 없으면 창만 뜨고 강조는 없다 — 일치할 때만 강조) | ☐ |
| BR32-2 | 값칸 오른쪽 복사(겹친 사각형) 아이콘 두 번 클릭 → CSS 편집기는 안 뜸 | ① BR32-1 상태(styleClass 값 있음)에서. ② styleClass 값 입력칸 **오른쪽 끝의 겹친 사각형(복사) 모양 아이콘**을 두 번 클릭한다. → 미리 정해진 CSS 클래스 목록 창은 뜰 수 있어도 **CSS 편집기(코드 편집 창)는 뜨지 않는다.** (★값 입력칸 글자 부분과 다른, 오른쪽 끝 아이콘) | ☐ |
| BR32-3 | 값칸 지우기(X) 버튼 두 번 클릭 → CSS 편집기는 안 뜸 | ① BR32-1 상태에서. ② styleClass 값 입력칸 안 **값을 지우는 X 버튼**을 두 번 클릭한다. → 값만 지워지고 **CSS 편집기는 뜨지 않는다.** | ☐ |
| BR32-4 | 바인딩(사슬) 걸린 styleClass 값칸 두 번 클릭 → CSS 편집기 안 뜸 | ① `SELECTOPTION21` 선택 후 `styleClass` 줄의 **사슬(바인딩) 아이콘**으로 바인딩을 건다. ② 값칸에 사슬(바인딩) 표시가 된 상태에서 값칸을 두 번 클릭한다. → **CSS 편집기가 뜨지 않는다.** | ☐ |
| BR32-5 | 값이 비어 있는 styleClass 값칸 두 번 클릭 → CSS 편집기 안 뜸 | ① `SELECTOPTION21` 선택 후 `styleClass` 값칸이 **빈 상태**인지 확인한다(값 없음). ② 빈 값칸을 두 번 클릭한다. → **CSS 편집기가 뜨지 않는다.** | ☐ |
| BR32-6 | 편집기 연 뒤 화면잠금 정상 해제(고착 없음) | ① BR32-1로 CSS 편집기를 띄운다. ② CSS 편집기 창을 닫는다. ③ WS20 화면의 UI 트리·속성 목록을 클릭해 본다. → **화면이 잠기지 않고 정상으로 클릭·조작된다.** | ☐ |
