## 1. 접속 정보 보관 — 노션 스킬과 같은 방식

| 노션 스킬 | 이 스킬 |
|---|---|
| `env/<노션이름>.env` 파일 하나 = 연결 하나 | `env/<시스템이름>.env` 파일 하나 = **SAP 접속 하나** |
| 파일 이름이 곧 부르는 이름 | 같음 (예: `dev.env` → `dev`) |
| `.default` = 이름 생략 시 쓸 연결 | 같음 |
| 토큰은 **명령줄로 안 받는다** — 파일을 직접 만든다 | **비밀번호도 명령줄로 안 받는다** — 장군님이 편집기로 직접 넣으신다 |
| 토큰 값은 응답·명령 출력에 **절대 안 나온다**(마스킹한 형태도 안 넣음) | 비밀번호도 같다 |

**파일 형식** (그 파이썬 코드가 읽는 이름 그대로 — 새로 지어내지 않음)

```dotenv
SAP_ADT_HOST=https://host:44300     # 필수
SAP_ADT_CLIENT=100                  # 필수에 가까움
SAP_ADT_USER=DEVELOPER              # 필수(Basic)
SAP_ADT_PASSWORD=...                # 장군님이 직접 넣는다
SAP_ADT_LANGUAGE=KO                 # 없으면 EN
SAP_ADT_VERIFY_SSL=false            # 사설 인증서 시스템만
DESCRIPTION=회사 개발 시스템          # 목록에 보이는 한 줄
```

## 2. 명령

| 장군님 입력 | 하는 일 |
|---|---|
| `/yoon-sap-adt` (뒤에 아무것도 없이) | **목록** — 표로 (이름 · 설명 · 주소 · 클라이언트 · 계정 · 언어 · 마지막 확인). **비밀번호 칸은 아예 없다** |
| `/yoon-sap-adt 추가` | 등록 **절차 안내**(파일 만드는 법). 비밀번호를 대신 받지 않는다 |
| `/yoon-sap-adt 수정` | 어느 파일을 어떻게 고치면 되는지 안내. 값은 장군님이 고치신다 |
| `/yoon-sap-adt 삭제` | **먼저 확인받고** 그 접속 파일을 지운다 |
| `/yoon-sap-adt <이름> 접속확인` | 그 시스템에 붙어 보고 결과만 알려 준다 |
| `/yoon-sap-adt <이름> <할 일>` | 그 시스템에서 **읽기 전용** 작업 — 오브젝트 검색 · 소스 보기(프로그램·클래스·함수·CDS) · 테이블 정의 · 패키지 내용 · 읽기 전용 조회 · 문법 점검 · 사용처 찾기 · 정적 점검 |

- **이름을 안 주시면 제가 고르지 않는다** — 목록을 보여 드리고 여쭙는다(백업 스킬 원칙 그대로).
- 등록된 접속이 하나도 없으면 어떤 명령이든 **등록 안내**로 간다.

## 3. 안 하는 것

- 비밀번호를 채팅으로 받지 않고, 받으면 **이미 새어 나간 것이니 바꾸시라고** 말씀드린다(노션 스킬과 같은 규칙).
- 비밀번호·접속 열쇠를 화면·로그·문서 어디에도 안 남긴다.
- SAP 오브젝트를 **고치거나 잠그거나 활성화하거나 이송하지 않는다** — 그 파이썬 서버 자체가 읽기 전용이다.
