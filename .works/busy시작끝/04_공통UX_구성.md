# 공통 UX 는 무엇으로 이루어져 있나 — busy 는 어디에 들어가나

> 조사 2026-09-15. 근거 = `.analy/16_공통_화면UX_표준.md` §0.1 표 + `www/ws30/ws10_20/theme/` 실제 파일. **코드는 안 고쳤다.**

## 1. 정해 주실 것

없다. 질문에 대한 답만 정리했다. (busy 를 따로 뗄지는 [03_새창_busy_로드순서.md](03_새창_busy_로드순서.md) 에서 아직 답을 기다리는 중)

## 2. 답 — busy 만이 아니다

공통 UX 는 **화면 요소 23가지**를 정해 두었다(`.analy/16` §0.1). busy 는 그중 하나다.

### 공통 자산 파일 (`www/ws30/ws10_20/theme/`)

| 파일 | 크기 | 담당 |
|---|---|---|
| `tokens.css` | 5.7KB | 색 의미 토큰(`--accent` 등) |
| `shell.css` | 92KB | 구조·기본 모양: 버튼·모달 팝업 프레임·토스트·사이드 네비·스플릿바·테이블·compact·텍스트 선택 |

| `theme-api.js` | 12KB | 테마 적용 |

## 3. 새창 로드 순서에서 공통 자산이 몇 번째인가

`ws10_20/index.html` `<head>` 기준(자세한 순서는 03 문서 §3).

1. CSS: `ws10_20.css` → jQuery UI → `common.css` 2개 → `frame.css`(busy 모양) → `tokens.css` → `shell.css` → `bootstrap-skin.css` → `ws10.css`·`ws20.css`·`usp.css` → Font Awesome
2. JS: `jquery.min.js` → `theme-api.js` → **`u4a-ui.js`** → 테마 즉시 적용(inline) → **`resources/index.js`(busy 함수)**
3. `<body>`: busy `<dialog>` → 네트워크 끊김 `<dialog>` → … → `index.js`

공통 자산 JS(`theme-api.js`·`u4a-ui.js`)는 jQuery 바로 뒤라 **이미 앞쪽**이다. busy 함수만 그보다 **뒤**에 있다.

## 4. 화면 리소스는 따로 관리하나 — 한다. busy 만 빠져 있다

**정해진 자리**: `www/ws30/ws10_20/theme/` 폴더. 근거 = `.analy/12_테마_컨버전_전략.md` §6.1 「산출물 파일 트리」 + `.analy/16` §0.1.

| 실제 파일 | 들어 있는 것 |
|---|---|
| `theme/tokens.css` · `shell.css` · `bootstrap-skin.css` · `bootstrap-bridge.css` | 색·모양 |
| `theme/themes/horizon_*.css` 11개 | 테마별 색 |
| `theme/theme-api.js` | 테마 적용 |
| `theme/u4a-ui.js` | 공통 화면 동작(확인창·입력칸·트리·패널·푸터 등) |

**메인 창 busy 는 이 폴더에 없다.** ([정정 2026-09-15] 종전 「busy 는 이 폴더에 없다」는 틀렸다 — `shell.css` 에 서버리스트·별창용 공통 busy `.u4a-busy` 가 있다.)

| busy 조각 | 있는 곳 | 그 파일의 원래 성격 |
|---|---|---|
| 켜고 끄는 함수 | `resources/index.js` | 창 관리·세션·서버 정보·메타 정보 등 **앱 공통 로직** 파일 |
| 모양 CSS | `ws10_20/css/frame.css` | 원본 `Frame.html` 에서 옮겨온 CSS |
| `<dialog>` | `ws10_20/index.html` | 메인 화면 HTML |

원본(UI5)에서는 busy 가 UI5 라이브러리의 `sap.m.BusyDialog` 였다(`ws_html5_shell.js` 230줄 주석 「UI5 BusyDialog 호환 더미」). UI5 를 걷어내면서 그 대체품을 **원래 busy 를 부르던 자리(`resources/index.js`·`frame.css`)에 그대로 만들어 넣었고, `theme/` 로는 옮기지 않았다.** `.analy/16` §0.1 표의 busy 파일 칸이 「—」 인 것도 같은 이유다.

※ `.analy/12` §6.1 트리에는 `u4a-ui.js` 가 안 적혀 있고, `themes/` 아래 파일 이름도 실제(`horizon_*.css` 11개)와 다르다(문서 쪽이 옛날 이름 `white.css` 등 5개). **문서와 실제가 어긋나 있다 — 보고만 하고 안 고쳤다.**
