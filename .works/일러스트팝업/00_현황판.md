> 배경: 패키지에 로컬 UI5(`node_modules/U4A/…`)를 더 이상 싣지 않음 → 패키지에서 이 뷰어가 못 떠 "통신 오류… 네트워크 상태 확인" 안내가 나게 됨.
> 바뀜 것 = `illustMsgPopup/index.js` 한 곳. **패키지일 때만** 서버 UI5(접속 서버 + LIBPATH). 개발 모드(`npm start`)는 원본 설계대로 CDN 그대로.
> → 개발 테스트 = **회귀 없음 확인**. 서버 UI5 경로 자체는 패키지에서 장군님이 확인. UI5 Predefined CSS 팝업과 같은 컨셉.
> ⚠ 이 뷰어는 예전에 서버 UI5 로 바꿨다 "UI5 가 안 떠 백지" 가 된 기록이 있음(원인 미기록). 지금은 실패 검사 2개가 있어 백지 대신 오류 안내 후 닫힌다. **패키지 확인 때 안내가 뜨면 그대로 알려 주십시오**(그때 서버 UI5 로 이 뷰어가 안 뜨는 원인을 따로 잡아야 함).
