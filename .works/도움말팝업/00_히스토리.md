# 도움말(Tooltips) 팝업 — 히스토리

### BR58 — 도움말 버튼 구버전 서버 대비책 복원 (2026-08-31)

원본은 도움말 버튼을 누르면 **두 갈래**로 간다.
- 서버에 통합 도움말이 등록돼 있으면 → 통합 도움말 창을 연다.
- 등록이 없는 **구버전 서버**면 → 앱 안에 들어 있는 도움말 문서 창을 연다.

우리 화면은 앞갈래만 살아 있고 뒷갈래가 비어 있어, 구버전 서버에 붙으면 세 곳
(UI 트리 · 속성 · 미리보기) 도움말이 모두 안 떴다. 이번에 뒷갈래를 원본대로 복원했다.

**★먼저 앱을 껐다 켜야 반영된다.**

**구버전 서버가 없어도 확인하는 법 — 도구 2개**

서버는 전혀 안 건드린다. 도움말 버튼이 갈래를 고르는 판정만 잠깐 "등록 안 됨"으로
바꿔 구버전 서버인 척 만드는 것뿐이다.

**(가) 한 번에 자동 확인** — 눌러보기·판정 되돌리기·창 닫기까지 알아서 하고 결과표를 뽑는다.

```
node .works/auto-test/br58-help-fallback-test.js
```

**(나) 손으로 눈으로 볼 때 — 켜기/끄기** — 켜두면 **물음표 버튼을 누르는 그 순간에만**
구버전 서버로 판정된다(버튼 처리가 끝나면 곧바로 원래대로 돌아가므로 다른 기능엔 영향 없음).
켜둔 채로 마음껏 눌러보고, 끝나면 반드시 끈다. 앱을 껐다 켜도 자동으로 꺼진다.

```
node .works/auto-test/br58-old-server-mode.js on
```

```
node .works/auto-test/br58-old-server-mode.js off
```

**★주의** — 창 폭이 좁으면 왼쪽 UI 트리 영역의 물음표 버튼이 **⋯ 안으로 접혀** 보이지 않는다.
안 보이면 그 줄 오른쪽 끝 ⋯ 를 눌러 목록에서 "도움말" 을 고른다.
