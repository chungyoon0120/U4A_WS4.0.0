## 2. MIME 리포지토리 별창 (좌측 트리)

> 열기: WS20 편집화면 위쪽 툴바 **"MIME 리포지토리"** 버튼 클릭 → 별도 창이 뜸.

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| EM4 | 팝업 열 때 로딩(빙글빙글) 표시 후 사라짐 | ① "MIME 리포지토리" 버튼을 누른다 ② 창이 뜨면서 잠깐 로딩 표시가 돌다가 ③ 트리가 채워지면 로딩 표시가 사라지는지 확인 | ☐ |
| EM5 | 트리 **정상 로드**(회귀 없음) | ① 좌측에 폴더 트리가 정상적으로 나오는지 ② 폴더 아이콘·이름·설명 두 칸이 캡처처럼 제대로 보이는지 | ☐ |
| EM6 | 폴더 **펼침/접기** 정상(회귀 없음) | ① 폴더 앞 화살표(▶)를 눌러 펼친다 ② 하위가 나오고, 다시 눌러 접으면 닫히는지 ③ 펼칠 때 잠깐 로딩 후 하위가 채워지는지(지연 로드 폴더의 경우) | ☐ |
| EM7 | 행 선택 시 **우측 속성/미리보기** 정상(회귀 없음) | ① 파일/폴더 행을 클릭한다 ② 우측 Properties(유형·파일 이름·URL·생성)와 미리보기가 캡처처럼 채워지는지 | ☐ |
