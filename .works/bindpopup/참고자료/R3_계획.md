# R-3 SEL 패널 재동기화 구현 계획

> **작업자용:** 원본(as-is) + `.analy` SSOT 가 정답. 이 계획은 원본 `_refreshAdditBindInfo`(designTree.js:199) 이식.
> 검증 = 소스대조 + `node --check` + 장군님 재시작 테스트(Electron 별창이라 프리뷰 불가).
> 상태는 `../00_현황판.md` 소유.

**목표:** 바인딩 적용 후 중앙하단(SEL) 추가속성 패널이 최신 값으로 재구성되게 한다(원본 동작 복원).

**아키텍처:** 원본 `_refreshAdditBindInfo`(선택행 있으면 그 라인 재조회 → `_showBindAdditInfo` 재구성)를 HTML5 `designArea.js` 에 이식하고, 원본이 부르는 **두 지점**(멀티 적용·드롭 바인딩)에 배선.

## 전역 제약
- 공통 자산(shell/u4a-ui/tokens/bootstrap-skin) 직접 수정 금지. hex/color-mix 금지. 메시지 임의생성 금지.
- 원본에 없는 UX 추가 금지. `_` 접두 폴더 인용 금지.

### Task 1: `_refreshAdditBindInfo` 헬퍼 + 멀티 적용 배선 (R-3 핵심)

**Files:** Modify `Popups/bindPopup/designArea/designArea.js`

**Interfaces:**
- Consumes: `oAPP.attr.S_SEL_ATTR`, `oAPP.fn.getDesignTreeAttrData(OBJID, UIATK)`, `_showBindAdditInfo(sTree)`
- Produces: `_refreshAdditBindInfo()` (인자 없음, void)

- [ ] **Step 1: 헬퍼 신설** — `_showBindAdditInfo` 정의 근처에 원본 1:1 이식:

```js
// [R-3] 선택행(S_SEL_ATTR) 있으면 그 라인을 재조회해 중앙하단(SEL) 패널 재구성.
//   원본 _refreshAdditBindInfo(designTree.js:199) 1:1. 선택행 없으면 무동작.
function _refreshAdditBindInfo() {
    var _sAttr = oAPP.attr.S_SEL_ATTR;
    if (!_sAttr) { return; }
    if (typeof oAPP.fn.getDesignTreeAttrData !== "function") { return; }
    var _sTree = oAPP.fn.getDesignTreeAttrData(_sAttr.OBJID, _sAttr.UIATK);
    if (typeof _sTree === "undefined") { return; }
    _showBindAdditInfo(_sTree);   // SEL 패널 재구성(원본 _showBindAdditInfo).
}
```

- [ ] **Step 2: `additionalBindMulti` 배선** — `_refreshDesignTree();` 뒤(방송 전)에 추가(designArea.js:663 부근):

```js
        _refreshDesignTree();
        _refreshAdditBindInfo();   // [R-3] 원본 additionalBindMulti 말미 _refreshAdditBindInfo(designTree.js:2980).
        // [P6] WS20 반영 …(기존 방송 그대로)
```

- [ ] **Step 3: 문법 검증** — `node --check designArea.js` → OK
- [ ] **Step 4: 로직 트레이스** — 멀티 적용 시: getSelectedDesignTree → MPROP stamp → _refreshDesignTree → **_refreshAdditBindInfo**(선택행 있으면 _showBindAdditInfo 재구성) → 방송. 순서 원본과 일치 확인.
