## 🟡 잠재 (지금은 영향 0 — 미리보기 기능이 붙으면 드러남)

| 코드 | 무엇이 다른가 | 내용 | 위치 |
|---|---|---|---|
| BC3 | 여러 줄(집합) 바인딩 경로 계산 누락 | 원본은 4종(칼럼 셀색·행설정/행액션 템플릿 하위·RowAction 항목)까지 계산하는데 HTML5는 **3종 누락** → 그 UI들에서 하위 필드 "선택 가능(초록)" 표시가 달라질 수 있음. **지금은 미리보기가 임시본이라 전 경로가 꺼져 영향 0** | `fnBindPopupOpen.js:826` |
| BC4 | 최초 집합 바인딩에서도 트리 부모/자식 해제 루틴 실행 | 원본은 **재바인딩 때만** 도는데 HTML5는 **최초 바인딩에도** 돎(`fnBindPopupOpen.js:1523`). 대상이 안 걸리면 아무 일 안 해 보통 무해하나, 그 두 속성이 바인딩돼 있으면 원본과 달리 풀림 | `fnBindPopupOpen.js:1521~1523` |

## ⚪ 참고 (원본과 다르나 문제 아님 / 미변환)

| 코드 | 내용 |
|---|---|
| BC5 | 단축키 등록 시 바인딩 차단(원본에 있음)이 HTML5선 잠자는 상태 — 그 점검 함수 자체가 아직 미변환. 기능 변환할 때 함께. |
| BC6 | 검색도움 필드리스트 예외 분기에서 화면잠금 해제가 빠졌으나, 그 자리엔 잠금이 안 걸려 실효 없음(원본과 대칭성만 어긋남). |
| BC7 | 바인딩 해제 버튼에 원본에 없는 "편집 중일 때만" 조건이 추가됨 — 버튼이 편집 때만 켜져 무해. |
| BC8 | 미변환 특수기능(앱검색 F4 등) 클릭 시 "아직 작업중입니다" 안내가 **코드에 박은 문구**(메시지 DB 키 아님) — 임의 문구라 나중에 정리 대상. 원본 문구 오매핑은 아님(`fnBindPopupOpen.js:177`). |

## 권고 순서
1. BC1(되돌리기) — 사용 빈도 높고 티남. 되돌리기 배선 신중히.
2. BC2(참조필드 오류표시) — 공통 드롭다운 손봄(다른 화면 드롭다운 오류표시도 함께 살아남).
3. BC3·BC4 — 미리보기 기능(W2) 붙일 때 함께.
4. BC5~BC8 — 각 기능 변환/정리 시.
