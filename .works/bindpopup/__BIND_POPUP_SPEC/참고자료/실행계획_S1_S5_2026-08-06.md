# 동일속성 바인딩 화면 (S1~S5) — 실행 계획서

> **작업자용:** 이 계획은 원본 UI5 `uiModule/synchronizionBind.js`(1235줄) 1:1 이식이다.
> 구현은 스텝 단위로 진행하며 **각 스텝 끝 = 앱 재시작 1회 = 장군님 화면 확인 1개**.
> 통과해야 다음 스텝 착수. 몰아서 만들지 않는다.
> 상태 SSOT = `../00_현황판.md`. 설계 근거 = `S1_S5_설계.md` + `스텝계획서_바인딩팝업_잔여.md`.

**목표:** 가운데 트리에서 바인딩된 속성 1건을 고르고 "동일속성 바인딩(129)"을 누르면, 가운데 영역이 동일속성 화면으로 슬라이드 전환되어 선택 속성 정보(상단) + 같이 바꿀 후보 목록(하단)을 보여주고, 후보를 골라 한 번에 일괄 바인딩한다.

**아키텍처:** 원본은 `oDesign.ui.ROOT`=NavContainer 안에서 트리 페이지(PG_MAIN)↔동일속성 페이지를 `to()`로 스왑한다. HTML5는 NavContainer가 없으므로 **가운데 디자인트리 영역(`#bwpDesignArea`) 안에 동일속성 페이지 DOM을 얹고 CSS 슬라이드로 스왑**(`.analy/16 §9`), `moveDesignPage()` 대응 함수로 트리로 복귀한다. 데이터 매칭(`getSameAttrList`)·쓰기(`attrSetBindProp` 등)는 이미 이식 완료 — 화면·잠금·적용 배선만 신설.

**기술 스택:** 순수 HTML5/JS(별창 CommonJS 미지원 → `oAPP.fn`/`oAPP.attr` 전역 노출), 공통 자산(`u4a-ui.js` createPanel/makeColumnTree·`.u4a-table`·`.u4a-btn`), `frame.css` 스코프 override.
