## 1. ★프리퀄 발견 — 화면 잠금 함수 4개가 HTML5-live에 없음
원본은 진입/복귀 시 4개로 다른 영역을 잠갔다 푼다(SPEC §5.1-6 / §5.6):

| 함수 | 원본 동작 | HTML5-live |
|---|---|---|
| `setViewEditable(b)` | 모델 `edit`/`edit_sync_dialog_interaction`/`edit_layout_customizing` = b, refresh (designTree.js:2758) | ❌ 없음 (index.js:8015=원본) |
| `setAdditBindButtonEnable(b)` | 우측 추가속성 버튼 활성 (bindAdditInfo.js:1038) | ❌ 없음 |
| `setLayoutCustomizingEditable(b)` | 커스터마이징 기어 활성 (bindAdditInfo.js:1051) | ❌ 없음 |
| `bSyncEqualityScreenActive` | 단순 플래그 | ❌ 없음(플래그만) |

**함정**: 원본은 이 플래그들이 UI5 컨트롤 `enabled="{...}"` 바인딩을 **자동** 구동. HTML5엔 그 자동바인딩이 없으므로, **각 함수가 실제 컨트롤 disabled 상태를 영역별로 직접 토글**해야 함(좌측 모델트리 상호작용 / 중앙 트리 툴바 / 우측 추가속성 버튼 / 커스터마이징 기어). = 단순 이식 아님.
