### 🟠 (B)군 마지막 2개 — 처리 시작 시 WS20 로딩 이식  ·  08-09
> 원본은 이 두 동작을 시작할 때 뒤 WS20에 로딩을 거는데 우리는 빠져 있었음 → 이식.
- [ ] **DB1 중앙 하단 "추가속성적용"** — 가운데 트리에서 바인딩된 행의 **바인딩 경로 링크(파란 GS_TT1-F02 등) 클릭** → 중앙 하단에 그 속성 전용 화면이 뜸 → 값 확인/수정 → 그 화면의 **"추가속성적용"** 버튼 → 뒤 WS20에 **"…추가 속성 바인딩 처리를 진행하고 있습니다"(219)** 로딩 뜸 → 처리 후 꺼짐. / 입력오류·정보없음이면 로딩 안 남음.
- [ ] **DB2 좌측 필드 드롭** — 좌측 필드를 가운데 트리의 바인딩 가능한 행에 **끌어다 놓기** → 뒤 WS20에 **"…바인딩 처리를 진행하고 있습니다"(220)** 로딩 뜸 → 바인딩 반영 후 꺼짐(★성공 후 로딩이 확실히 꺼지는지). / WS20 캔버스에서 트리로 드롭하면 문구가 **"…디자인 TREE 영역을 갱신하고 있습니다"(221)**. / 드롭 실패(불가 행)면 로딩 안 남음.
- [ ] **DB3 트리 행 ✓(추가속성적용)** — 바인딩된 행의 **✓ 버튼** 클릭 **즉시** 뒤 WS20에 **219** 로딩 뜸(★**처음 적용 = 확인창 없이도** 로딩 떠야 함. 이미 걸린 속성은 확인창 뜨는 동안 뒤 WS20 로딩 유지). / 처리 후 꺼짐 / 검증오류·취소면 로딩 안 남음.
- [ ] **DB4 우측 "추가 속성 바인딩"(098)** — 속성 **여러 개 체크** + 우측 값 입력 → **"추가 속성 바인딩"** 클릭 **즉시** 219 로딩 뜸(검증·확인창 동안 유지) → 처리 후 꺼짐 / 미선택·오류·취소면 로딩 안 남음.

### 🔴 1순위 — 별창 X(닫기) 버튼  ·  08-09 결함수정(busy 전수감사)
> 어떤 동작을 **성공**시키면 X 버튼이 죽던 버그를 고침. (취소는 원래부터 정상)

**CB1 — 아래 6개 동작을 실제로 "성공"까지 시킨 뒤, 우상단 X 로 닫히나?** (하나라도 X 안 닫히면 실패)

| # | 동작 | 조작 방법(화면) | 성공 확인 → X |
|---|---|---|:---:|
| ① | **바인딩 해제** | 가운데 트리에서 **바인딩된 속성 행**에 있는 **해제 버튼(🔗 끊기, 빨강 — 바인딩된 행이면 항상 표시)** 클릭 → 확인창 **예** | ✅ **O**(08-09) |
| ② | **멀티 바인딩** | **좌측에서 필드 1개 선택** + 가운데 속성 **여러 개 체크** → 트리 툴바 **"멀티 바인딩"(파랑)** → 확인창 **예** | ✅ **O**(08-09) |
| ③ | **멀티 해제** | 가운데 **바인딩된 속성 여러 개 체크** → 트리 툴바 **"바인딩 해제"(빨강)** → 확인창 **예** | ✅ **O**(08-09) |
| ④ | **동일속성 일괄적용** | 속성 1개 체크 → "동일속성 바인딩" 진입 → 하단 후보 **여러 개 체크** → **"일괄적용"** → 확인창 **예** | 트리로 복귀·반영되면 → **X** ☐ |
| ⑤ | **추가속성 적용** | 속성 1개 선택 → 우측 추가속성 값 입력 → 그 속성 **행의 "추가속성적용"(✓) 버튼** 클릭 (처음 적용은 바로 / **이미 걸린 속성이면 확인창 예**) | 완료되면 → **X** ☐ |
| ⑥ | **멀티 추가속성적용** | 가운데 속성 **여러 개 체크** + 우측 추가속성 값 입력 → 우측 **"추가 속성 바인딩" 버튼** → 확인창 **예** | 완료되면 → **X** ☐ |

→ 각 동작을 **취소 말고 실제로 성공**시킨 다음 X 버튼 클릭. **6개 다 정상적으로 닫히면 CB1 O.** (예전엔 성공하면 X가 죽어서 안 닫혔음)

**CB2 — 회귀 없음** ☐  ·  각 동작 **취소** 후에도 X 눌림 / 로딩 뜬 **동안**엔 X 안 눌림(정상) / 진입·뒤로도 X 정상.
