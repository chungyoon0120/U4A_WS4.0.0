## 3. 줄 모양

```
[등급] [창] [화면] [추적번호] 무슨 일 | 대상 | 결과 | 걸린 시간 @ 파일:줄 함수()
```

**보기**

```
[INFO]  [U4A Workspace #Main] [WS20] [ZZ99] CLICK | 저장
[INFO]  [U4A Workspace #Main] [WS20] [ZZ99] DONE | save_app #12 | 성공 | 0.5초 @ ws_common.js:4546 sendAjax()
[WARN]  [U4A Workspace #Main] [WS20] [ZZ99] SLOW | save_app #12 | 5초째 응답 없음
[ERROR] [U4A Workspace #Main] [WS20] [ZZ99] SCRIPT_ERROR | 없는 값을 꺼내 씀 | 터진 자리 ws_html5_ws20_attr.js:6757 _attrDescLibName()
```

### 3-1. 등급 — 네 가지

| 등급 | 언제 | 예 |
|---|---|---|
| `INFO` | 정상 흐름의 주요 지점 | 앱 시작, 로그인 성공, 화면 열림, 저장 끝 |
| `WARN` | 정상은 아닌데 계속 갈 수 있음 | 값이 없어 기본값 사용, 다시 시도해서 성공, 응답이 늦음 |
| `ERROR` | **기능 하나가 실패** | 저장 실패, 서버가 오류를 돌려줌, 화면 코드가 터짐 |
| `FATAL` | **앱을 더 못 씀** | 앱 본체가 터짐, 창이 죽음, 뻗음 |

### 3-2. ★로그 글은 전부 영어 (2026-09-10 장군님 지시 — 앞 지시를 대체)

**로그를 읽는 것은 사람이 아니라 AI 다.** 그래서 로그 파일에 찍히는 글은 전부 영어로 쓴다.
등급(`INFO`/`WARN`/`ERROR`/`FATAL`) · 사건 이름(`CLICK`/`NAV`/`DONE`/…) · **설명과 결과까지 모두.**

**딱 하나 예외 — 화면에 실제로 적힌 글자는 그대로 둔다.**
버튼 이름·화면 이름·서버가 돌려준 글이 그것이다. 번역해 버리면 **소스에서 그 글자를 못 찾는다.**

```
[INFO] [U4A Workspace - Main] [WS20] [A7F3] CLICK | 저장 @ www/…/ws_events.js:120 onSave()
                                            ^^^^^   ^^^^
                                            영어    화면에 적힌 글자 그대로
```

**로그 함수를 부를 때는 한국어 사건 이름을 그대로 쓴다.** 표가 영어로 바꿔 준다.

```js
U4ALOG.action('눌렀음', '저장', '');   // → CLICK | 저장
U4ALOG.warn('값이 없어 그만둠', 'T_ATTR', 'attribute list cannot be drawn');   // → GUARD_EXIT | …
```

**앞 지시와 무엇이 달라졌나** — 2026-09-10 오전까지는 "설명은 한국어"였다.
크래시 보고서를 영어로 바꾸면서 로그만 한국어로 남으면 두 벌이 되므로, **로그도 영어로 통일**하라는 지시가 내려왔다.

| 사건 이름 | 뜻 |
|---|---|
| `APP_START` / `APP_EXIT` | 앱 시작 / 정상 종료 |
| `CLICK` / `SELECT` | 눌렀음 / 골랐음 |
| `NAV` | 화면 이동 |
| `WIN_OPEN` / `WIN_CLOSE` / `WIN_READY` | 별창 열림 / 닫힘 / 창 준비됨 |
| `REQ` / `DONE` / `SLOW` | 서버에 보냄 / 끝남 / 늦어짐 |
| `REQ_FAIL` | 서버 통신 실패 (상세) |
| `SERVER` | 접속 서버 정보 |
| `SCRIPT_ERROR` | 화면 코드가 터짐 |
| `UNHANDLED_REJECT` | 처리되지 않은 비동기 실패 |
| `EXCEPTION` | 기능 안에서 터짐 |
| `CAUGHT` | 오류를 잡고 넘어감 |
| `GUARD_EXIT` | 반드시 있어야 하는 값이 없어 그만둠 |
| `DOM_MISS` | 화면 요소를 못 찾음 |
| `CRASH` | 앱이 뻗음 |

> **표에 없는 새 사건**을 만들 때는 이 표에 한 줄 추가하고 쓴다. 임의로 만들어 쓰지 않는다.

### 3-3. 시각

- **우리 시각 그대로**(장군님 지시 2026-09-10). 세계 표준시로 바꾸지 않는다.
- 모양: `[2026-09-10 10:05:30.441]` — 로그 라이브러리가 자동으로 붙인다.

### 3-4. 추적 번호

- 사용자가 **뭔가 새로 시작할 때마다**(버튼 누름·화면 이동) 새 번호를 뽑는다.
- 그 뒤의 서버 요청·오류가 **같은 번호**를 물고 간다 → 「이 버튼 → 이 요청 → 여기서 터짐」이 한 줄기로 이어진다.
- 로그 함수가 **자동으로** 한다. 화면 코드에서 부를 필요 없다.

### 4-1. 화면 쪽 (`www/` 아래)

```js
    return;

// 오류를 잡는 자리 (★R2)
try {
    ...
} catch (e) { if (typeof U4ALOG !== "undefined" && U4ALOG.caught) { U4ALOG.caught(e); } }

// 기능이 실패
U4ALOG.error("EXCEPTION", "저장 실패", oError);
```

### 4-2. 앱 본체 쪽 (`electron/` 아래)

```js
const WsMainLog = require('./lib/log/ws_main_log');
WsMainLog.writeLog('WARN', '창이 응답 없음 — 주소: ' + sUrl);
```

### 4-3. 자동으로 되는 것 — 손댈 필요 없음

| 무엇 | 어디서 |
|---|---|
| 버튼 누름·고르기 | 누른 순간을 가로채 화면 글자로 이름을 알아낸다 |
| 그 줄을 남긴 코드 자리 | 로그 함수가 스스로 붙인다 |
| 창 이름·화면 이름 | 로그 함수가 스스로 알아낸다 |
| 추적 번호 | 버튼 누를 때마다 자동으로 새로 뽑는다 |
| 화면 요소를 못 찾음 | 요소 찾는 공통 기능을 감싸 두었다 |
| 서버 통신 | 공통으로 지나가는 한 곳에서 남긴다 |

## 8. 왜 이렇게까지 하나

이 프로그램은 고객사에 배포된 뒤 **AI 가 로그만 보고 운영·수정한다.**

1. 고객사에서 문제 접수 → 로그 파일을 받는다
2. 그 파일을 그대로 AI 에게 준다
3. AI 가 **로그가 짚은 소스 자리를 열어** 원인을 분석한다
4. 고치고, 시험하고, 배포한다

**이 흐름이 성립하려면 로그가 "그 줄만 보고 소스를 열 수 있는 수준"이어야 한다.**
사람이 읽기 좋은 로그가 아니라, **AI 가 소스를 짚을 수 있는 로그**를 남긴다.

이미 이 방식으로 검증했다 — 오류 세 건을 심고, **소스를 뒤지지 않고 로그가 짚은 파일·줄만 열어** 전부 고쳤다(2026-09-08).
