# Login — 히스토리

## LE 그룹 — 로그인 화면 시작 서버 호출 예외처리 원본대로 복원 (2026-09-16 고침 · 2026-09-16 장군님 테스트 통과)

> 서버가 오류 응답을 주면 원본처럼 「Server connection failed!」 창이 뜬다.
> 원본에 없던 SSO 30초 강제 끊기·쿠키 같이 보내기를 뺐고, 콘솔 안내 글을 원본 문장으로 되돌렸다.
> 근거 = [01_시작_서버호출_예외처리_원본대조.md](01_시작_서버호출_예외처리_원본대조.md)

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| LE1 | 서버 오류(502 등)면 **「Server connection failed!」 창**이 뜬다 | ① 앱을 완전히 껐다 켠다 ② 서버 목록에서 장군님이 캡처하신 **UHA** 서버(지금 502 가 나는 서버)를 골라 로그인 화면을 연다 ③ 「Server connection failed!」 창이 뜨는지 본다 — 창 없이 로그인 입력칸이 보이면 ❌ | ✅ O |
| LE2 | 오류 창의 **「Check Details」** 가 점검사항을 연다 | ① LE1 의 창에서 「Check Details」 를 누른다 ② 점검사항 창이 뜨는지 본다 | ✅ O |
| LE3 | 오류 창을 닫으면 **로그인 창이 닫힌다** | ① LE1 의 창을 닫는다 ② 로그인 창이 같이 닫히는지 본다 | ✅ O |
| LE4 | 콘솔에 **원본과 같은 안내**가 찍힌다 | ① LE1 상태에서 개발자 도구 Console 을 본다 ② `Bad Gateway` 한 줄과 「통신오류 발생!! / 접속 정보 확인 요망!! / … SAML 삭제!!」 가 찍히는지 본다 | ✅ O |
| LE5 | ★회귀 — **정상 서버**는 평소처럼 로그인 화면이 뜬다 | ① 서버 목록에서 정상 서버를 골라 로그인 화면을 연다 ② 오류 창 없이 입력칸과 언어 선택이 나오는지 본다 ③ 로그인이 되는지 본다 | ✅ O |
