- **로그인 거부**(비밀번호 비우기, 에러 코드 표시, 서버 메시지 창), **권한 체크 결과 오류 창**, **권한 없음 안내(ESC 막힘, OK 누르면 창 닫힘)**, **응답 오류 처리(시간 초과·빈 응답·서버 원문)** — 같다.
- **권한·라이선스 요청**: 200·201 이 아니면 오류로 본다 — 원본과 같다. 서버 오류를 성공으로 넘기는 곳은 없다.
- **메이저 업데이트 이벤트 6가지·패치 체크 로직**: 같다(지금은 C 때문에 안 돈다).
