### 그룹 SV — 팝업 틀 UI5 를 로컬 리소스 대신 **서버 UI5** 로 읽도록 변경 (2026-09-08)
> 배경: 패키지에 로컬 UI5(`node_modules/U4A/…`)를 더 이상 싣지 않음 → 패키지에서 팝업 틀이 못 떠 "통신 오류… 네트워크 상태 확인" 안내가 났던 것.
> 바뀜 것 = `control.js` 한 곳. **틀**(왼쪽 메뉴 목록·위아래 버튼줄) + **다른 CSS 가이드 별창 2개**(Responsive Margin · Removing Margin)가 이제 오른쪽 미리보기와 같은 **접속 서버의 UI5** 를 읽는다.
> ★**패지일 때만** 서버 UI5. 개발 모드(`npm start`)는 원본 설계대로 인터넷 CDN 그대로(일부러 나눠 둔 설계). → 개발 테스트는 **회귀 없음 확인**, 서버 UI5 경로 자체는 패키지에서 확인(장군님).
> 타이머·사전 ping·새 문구 **없음**. 실패 안내는 기존 그대로. ★앱 재시작 후 테스트. 패키지 빌드 확인은 장군님이 직접.
