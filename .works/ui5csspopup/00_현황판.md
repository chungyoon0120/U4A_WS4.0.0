### 그룹 SV — 팝업 틀 UI5 를 로컬 리소스 대신 **서버 UI5** 로 읽도록 변경 (2026-09-08)
> 배경: 패키지에 로컬 UI5(`node_modules/U4A/…`)를 더 이상 싣지 않음 → 패키지에서 팝업 틀이 못 떠 "통신 오류… 네트워크 상태 확인" 안내가 났던 것.
> 바뀜 것 = `control.js` 한 곳. **틀**(왼쪽 메뉴 목록·위아래 버튼줄) + **다른 CSS 가이드 별창 2개**(Responsive Margin · Removing Margin)가 이제 오른쪽 미리보기와 같은 **접속 서버의 UI5** 를 읽는다.
> ★**패지일 때만** 서버 UI5. 개발 모드(`npm start`)는 원본 설계대로 인터넷 CDN 그대로(일부러 나눠 둔 설계). → 개발 테스트는 **회귀 없음 확인**, 서버 UI5 경로 자체는 패키지에서 확인(장군님).
> 타이머·사전 ping·새 문구 **없음**. 실패 안내는 기존 그대로. ★앱 재시작 후 테스트. 패키지 빌드 확인은 장군님이 직접.

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| SV-1 | 팝업 틀이 전처럼 정상으로 뜨는지(개발 모드 회귀) — ★서버 UI5 경로는 패키지에서 확인 | ① 앱을 켜고 서버 로그인 후 WS20 에서 앱 하나를 연다. ② WS20 상단 메뉴 **CSS 스타일 클래스 → UI5 미리 정의된 CSS** 를 클릭한다. ③ **확인**: 로딩 표시 뒤 팝업이 뜨고 **왼쪽 메뉴 목록이 채워지는지**(전에는 여기서 통신 오류 안내가 떴다 닫혔). ④ 왼쪽 메뉴 하나를 클릭 → **오른쪽에 CSS 카드들이 뜨는지**. ⑤ 팝업 위 타이틀바 색과 안 내용 색(다크/라이트)이 맞는지. | ☐ |
| SV-2 | 다른 CSS 가이드 별창 2개(이번 변경 영향) | ① SV-1 팝업에서 왼쪽 메뉴 목록 **아래쪽** 물음표 아이콘 버튼 **Other CSS Guides**(한국어면 "다른 CSS 가이드")를 누른다. ② 목록에서 **Responsive Margin** 을 클릭 → 별창이 뜨고 안 내용(표·예시)이 그려지는지. ③ 닫고 **Removing Margin** 도 같이 확인. ④ (참고) **Enabling Responsive Paddings…** · **CSS Styling Issues** 는 UI5 를 안 쓰는 문서라 이번 변경과 무관 — 그냥 뜨는지만 본다. | ☐ |
| SV-3 | 회귀 — 미리 보기·적용·취소는 전과 같아야 정상 | ① WS20 왼쪽 UI 트리에서 UI 하나를 **체크**해 둔다. ② SV-1 팝업에서 CSS 카드 하나를 체크 → 아래 **미리 보기** → WS20 미리보기에 반영되고 완료 안내가 뜨는지. ③ **적용** → 같이 확인. ④ **취소** → 창이 닫히고 WS20 잠금이 풀리는지. | ☐ |
| SV-4 | 서버가 UI5 를 못 줄 때 안내(기존 그대로 동작하는지) | ① 로그인과 WS20 앱 열기까지 마친 뒤 **PC 네트워크를 끈는다**(와이파이 끄기 또는 랜선 뽑기). ② WS20 상단 메뉴 **CSS 스타일 클래스 → UI5 미리 정의된 CSS** 클릭. ③ **확인**: "통신 오류가 발생하였습니다. 네트워크 상태를 확인…" 안내가 뜨고, 확인을 누르면 창이 닫히며 **WS20 잠금이 풀리는지**(버튼 클릭 가능). ④ 네트워크를 다시 켜고 ②를 하면 정상으로 뜨는지. | ☐ |
