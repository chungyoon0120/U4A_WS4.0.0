## 1. 결론 (한 줄)

**패키지에서는 UI5 를 인터넷 서버가 아니라 PC 안에 함께 설치된 로컬 라이브러리에서 읽는데, 지금 작업 폴더에는 그 라이브러리(`node_modules/U4A`)가 없다 → 이 폴더로 만든 패키지엔 UI5 가 안 들어가고 → 팝업이 UI5 를 못 불러와 "통신 오류(네트워크 확인)" 안내가 뜬다.**
개발 모드(`npm start`)는 UI5 를 인터넷 서버(CDN)에서 받으므로 라이브러리가 없어도 잘 된다.

---

## 2. 그 "네트워크 오류" 문구의 정체

화면 문구: **"통신 오류가 발생하였습니다. 네트워크 상태를 확인하시고 문제가 지속 될 경우 U4A 솔루션 팀에 문의하세요."** (`ZMSG_WS_COMMON_001` 391)

이 문구는 이 팝업에서 **딱 한 곳**에서만 뜬다 — `main/frame.js` `fnOnUi5LoadFail`.
호출 조건은 둘뿐이다(`main/index.js`):
- ① UI5 부트 `<script src=WS30_BOOT_PATH>` 가 **로드 실패**(`onerror`) — 50행
- ② 로드는 됐는데 `window.load` 시점에 `sap` 이 **없음** — 234행

즉 **서버(SAP) 통신 오류가 아니라 "UI5 라이브러리 파일을 못 읽었다"는 뜻**이다. 문구가 "네트워크"라서 서버 문제로 오해하기 쉽다.
(서버 통신 실패는 다른 문구 = 243 "Connection error has occurred" + 228 — 팝업 안 오류 박스로 뜬다. 이번 건과 다름.)

## 3. 패키지 vs 개발 모드 — 실제로 다른 것 (소스 확인)

| | 개발 모드 (`npm start`) | 패키지 (설치본) |
|---|---|---|
| `resourceUrl` 결정 (`intro.js:1249 _setUI5BootStrapUrl`) | `APP.isPackaged === false` → **`testResource`** = `https://u000.u4aide.com:10001/public/lib/_org_files/sapui5-rt-1.107.1/resources/sap-ui-core.js` | **`file:///<process.resourcesPath>/node_modules/U4A/WS/lib/ui5/v11071/resources/sap-ui-core.js`** |

## 4. 왜 로컬 파일이 없나

| 사실 | 근거 |
|---|---|
| 패키지에 로컬 UI5 를 넣는 방법 = `package.json` `extraResources` `{ from: "node_modules/U4A", to: "node_modules/U4A" }` | `package.json:77` / `.analy/09_환경구축_런북.md:127` |
| `node_modules/U4A` 는 npm 의존성이 **아니다** (`dependencies` 에 없음). 수동으로 갖다 놓는 폴더. | `package.json` dependencies 전수 확인 |
| **지금 작업 폴더에 `node_modules/U4A` 없음** | `ls node_modules/U4A` → No such file |
| 원본 저장소 2곳(`U4A_WS3.0.0`·`U4A_WS_DESIGN`)과 `Documents\U4A_WS3.0` 에도 없음 | 각각 `ls` 확인 |
| README 도 이미 알고 있음 | `README.md:145` "`node_modules/U4A` — 설치 파일 만들 때 참조하는 항목인데 **이 개발 PC에도 없다**(미확인). 앱 실행에는 영향 없음" ← 개발 모드엔 영향 없다는 말이지 **패키지엔 영향 있다** |
| 로컬 UI5 를 갖고 있는 곳 = 이 PC 에 설치된 **옛 설치본(6/26)** `C:\Users\socce\AppData\Local\Programs\com.u4a_ws3.app\resources\node_modules\U4A\WS\lib\ui5\v11071\` (sap-ui-core.js 756KB + sap.m/sap.f/sap.ui.table 전체 + sap_horizon·sap_horizon_dark 테마 전부 존재 확인) | `ls` 실측 |

※ 그 옛 설치본은 **이 저장소로 만든 것이 아니다** — asar 안에 `ws_html5_ws20.js`·`u4a-ui.js` 등 HTML5 파일이 없고 옛 UI5 제품 코드다. 그래서 그 설치본을 이번 테스트에 쓴 게 아니라면, 장군님이 **이 작업 폴더(또는 같은 상태의 폴더)로 새로 빌드**한 패키지일 것이고, 그 패키지엔 로컬 UI5 가 없다.

## 5. 흐름 정리 (패키지)

```
WS20 메뉴 [UI5 미리 정의된 CSS]
```
