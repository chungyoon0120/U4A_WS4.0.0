## BR12 — 데이터 세트 탭 앱 설명 필수 제거 + 테이블 설명 자동 채움 (2026-08-11 통과)

**무엇을 고쳤나(쉽게)**: "생성 옵션" 팝업의 "데이터 세트" 탭에서 **앱 설명을 비워둬도 생성되도록** 원본대로 되돌렸다(예전엔 앱 설명이 비면 빨간 테두리로 막았다 — 원본엔 없던 막음). 앱 설명이 비어 있으면 **Transparent Table 검색으로 고른 표의 설명이 앱 설명에 자동으로 채워진다**(이 자동 채움은 원래부터 있던 동작 — 손대지 않고 확인만). 앱 설명을 직접 써 넣었으면 그 값을 그대로 둔다.

원본 대조: 앱 설명 필수 점검은 원본에서 "일반" 탭에서만 했음 → 현행이 데이터 세트 탭까지 막던 것을 원본대로 복원.

| 코드 | 동작 | 조작·확인 포인트 | O/X |
|---|---|---|---|
| BR12-1 | 앱 설명 비워도 생성 통과 | ① "생성 옵션" 팝업 → ② "데이터 세트" 탭 → ③ Transparent Table 고르고 표(예: MAKT) 넣기 → ④ 앱 설명 비우기 → ⑤ 오른쪽 아래 파란 체크(확인) → 안 막고 생성 확인 창으로 | ✅ O |
