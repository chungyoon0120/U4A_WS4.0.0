# 현황판 — 생성 옵션 팝업 (WS10)

> 화면: WS10에서 앱 생성 → **"생성 옵션 : &lt;앱ID&gt;"** 팝업 → **"데이터 세트"** 탭
> 상태 SSOT. 통과하면 그 자리 O/X 칸에 **✅ O** 만 표시. 그룹 전부 통과 시 히스토리로 이관.

## 지금 할 것 — BR12(앱 설명 필수 제거 + 자동 채움) 확인

**무엇을 고쳤나(쉽게)**: "데이터 세트" 탭에서 **앱 설명을 비워둬도 생성이 되도록** 되돌렸다(예전엔 앱 설명이 비면 빨간 테두리로 막았다 — 원본엔 없던 막음이라 원본대로 복원). 앱 설명을 비워두면, **Transparent Table을 검색해 테이블을 고를 때 그 테이블 설명이 앱 설명에 자동으로 채워진다**(이 자동 채움은 원래부터 있던 동작 — 그대로 확인만). 앱 설명을 직접 써 넣었으면 그 값을 그대로 둔다.

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| BR12-1 | 앱 설명 비워도 생성 통과 | ① WS10에서 앱을 하나 만들어 **"생성 옵션"** 팝업을 연다. ② 위쪽 탭에서 **"데이터 세트"**를 고른다. ③ 오브젝트 유형에서 **Transparent Table**을 고르고, **Transparent Table** 칸에 표(예: MAKT)를 넣는다. ④ **"앱 설명" 칸을 비운 채로 둔다.** ⑤ 팝업 오른쪽 아래 **파란색 체크(확인) 버튼**을 누른다. → **앱 설명이 비었다고 막지 않고**(빨간 테두리·경고 없음) 생성 확인 창으로 넘어가야 한다. | ☐ |
| BR12-2 | 테이블 검색하면 앱 설명 자동 채움 | ① "생성 옵션" 팝업 → "데이터 세트" 탭. ② **"앱 설명" 칸을 비운 상태**에서 ③ **Transparent Table** 칸의 **돋보기(검색)** 를 눌러 표를 조회하고 한 개를 고른다. → 고른 표의 **설명 글이 "앱 설명" 칸에 저절로 채워져야** 한다. | ☐ |
| BR12-3 | 앱 설명 직접 쓰면 안 덮어씀 | ① "데이터 세트" 탭에서 **"앱 설명" 칸에 아무 글이나 직접 써 넣는다.** ② 그 상태에서 **Transparent Table**을 돋보기로 검색해 표를 고른다. → 내가 쓴 앱 설명이 **그대로 남아 있어야**(표 설명으로 바뀌지 않아야) 한다. | ☐ |
