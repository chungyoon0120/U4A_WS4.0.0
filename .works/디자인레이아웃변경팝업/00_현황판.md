# 현황판 — 디자인 레이아웃 변경 팝업 (WS20)

> 화면: WS20 Design 화면 → 좌측 위 '레이아웃 변경' 버튼 → 레이아웃 변경 팝업(트리·미리보기·속성 3개 타일)
> 상태 SSOT. 통과하면 그 자리 O/X 칸에 **✅ O** 만 표시. 그룹 전부 통과 시 히스토리로 이관.
> 코드반영은 **앱을 껐다 켜야** 보인다(새로고침 아님).

## 지금 할 것 (미테스트)

### BR49 — 레이아웃 반복 저장 시 Critical Error(instanceof 형변환) 차단

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| BR49-1 | 순서 바꿔 저장을 반복해도 오류 안 뜸 | ① WS20 Design 화면에서 좌측 위 '레이아웃 변경' 버튼을 누른다. ② 팝업에서 타일 하나를 다른 자리로 끌어 순서를 바꾼다. ③ 하단 '저장'을 누르고 확인 창에서 '예'를 누른다. ④ 팝업이 닫히고 미리보기가 정상적으로 다시 그려지는지 본다. ⑤ 다시 '레이아웃 변경'을 열어 순서를 또 바꾸고 '저장→예'를 누른다. ⑥ 이 열기·바꾸기·저장을 5번 이상 반복한다. ⑦ **'Critical Error' 문구가 한 번도 안 뜨고, 매번 미리보기가 정상으로 다시 뜨는지** 확인 | ☐ |
| BR49-2 | 기본 배치로 되돌려 저장 반복해도 오류 안 뜸 | ① '레이아웃 변경'을 연다. ② 하단 '기본값' 버튼(되돌리기 모양)을 눌러 기본 배치로 되돌린다. ③ '저장→예'. ④ 다시 순서를 바꿔 저장한 뒤, 또 '기본값→저장→예'. ⑤ 되돌리기·저장을 몇 번 반복해도 'Critical Error' 없이 미리보기가 정상인지 확인 | ☐ |
| BR49-3 | 순서 안 바꾸고 저장해도 정상 | ① '레이아웃 변경'을 연다. ② 아무것도 안 바꾸고 바로 '저장→예'를 누른다. ③ 미리보기가 그대로 정상 유지되고 오류가 없는지 확인 | ☐ |
