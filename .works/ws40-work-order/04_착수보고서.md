## 6. 작업 방식

- **브랜치** : `bootstrap` 에서 새로 만든다(이름 예: `ws40-catch-log`). `autofix-skill-test` 는 쓰지 않는다.
- **백업 `.js` 만들지 않는다** — git 으로 되돌린다(지침서 규칙 7).
- **진행 파일** : `.docs/A1-progress.md` 를 만들어 커밋마다 같이 갱신(지침서 요구).
- **로그 글은 영어**, 새 사건 이름은 로그 표준 표에 먼저 한 줄 추가.
- 커밋·푸시는 **지시가 있을 때만**.
