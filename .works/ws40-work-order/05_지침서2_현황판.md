### UT4 재현 한 줄 (Console 에 붙여넣기)

메모리에만 **없는 UI5 class 를 가리키는 가짜 줄**을 하나 넣고, 트리의 UI 한 개를 그것으로 만들게 시킨다.
그러면 UI5 를 불러오다 실패하는 **실제 자리**를 지난다. 파일은 하나도 안 고친다.

```js
var w = document.getElementById("prevHTML").contentWindow;
oAPP.DATA.LIB.T_0022.push({ UIOBK: "UOTEST01", LIBNM: "sap.m.NoSuchControlForTest" });
var r = oAPP.DATA.APPDATA.T_0014.filter(a => a.OBJID !== "ROOT" && !oAPP.DATA.APPDATA.T_0014.some(b => b.POBID === a.OBJID))[0];
w.createUIInstance({ OBJID: r.OBJID, POBID: r.POBID, UIOBK: "UOTEST01", ISECP: r.ISECP });
```

- 세 번째 줄은 **자식이 없는 UI(맨 끝 UI)** 를 하나 고른다 — 피해를 가장 적게 하기 위해서다.
- **주의** : 이 조작은 고른 그 UI 의 미리보기 객체를 빈 것으로 바꿔 놓는다. **확인이 끝나면 앱을 껐다 켠다.**
  앱 데이터(저장 대상)는 건드리지 않으므로 **저장하지 말고** 그냥 끄면 된다.
- 왜 이렇게 하나 : 미리보기가 터지는 앱이 늘 있는 게 아니다. 터지는 자리를 **일부러 지나게** 해야
  「조합이 로그에 남는가」 를 확인할 수 있다. 소스로 확인한 경로다(UI5 를 불러오다 실패하는 쪽).
