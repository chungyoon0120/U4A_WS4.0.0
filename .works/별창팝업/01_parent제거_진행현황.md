## 고치는 방식 (전 번호 동일)

2026-10-07 장군님 결정(질문 1~4 전부 「니 생각대로」):

1. **선례를 기준으로 삼는다** — MIME 리포지토리 창이 이미 parent 없이 돌아가고 있다. 그 방식을 따른다.
2. **이미 열린 창 찾기** = 열려 있는 전체 창 중 **팝업 종류 이름 + 브라우저키가 둘 다 같은** 창.
   → MIME 리포지토리도 지금 종류 이름만 보므로 **같이 고친다**.
3. **뒤로가기 일괄 닫기 · busy 때 숨겼다 되살리기** = **전체 창 중 브라우저키가 같은 것**으로 통일한다.
   MIME 리포지토리가 쓰는 「메인 창 자식 목록에 등록」 방식은 **없앤다**(두 방식이 섞이면 못 찾는다).
   **닫기 예외 3개 · 숨김 예외 3개는 그대로 유지한다.**
4. **한 번호씩** 고치고 바로 보고 → 장군님 테스트 → 다음.
5. **안 쓰이는 옛 파일은 건드리지 않는다**(장군님 확인 2026-10-07 「5번 맞다」) — 아래 10곳.
