## BR48 — 파일·폴더 이름 검사와 안내 메시지 보강 (2026-08-18 전 항목 통과 · 노션=수정완료)

> 원본 UI5도 있던 결함(폴더명은 빈 문자열만 검사, 파일 중복 체크는 원본 개발자가 만들다 만 빈 껍데기 함수를 꺼둠 → WS3.0 동일 재현). BR48 이슈 기대결과대로 검사를 채움.

- `www/ws30/ws10_20/theme/u4a-ui.js` — 공통 확인창 긴 글자 강제 개행(모든 화면 메시지 박스 공통)

**메시지 키** (전부 재활용 우선)
- 중복 파일 = `/U4A/MSG_WS` 004 "중복된 파일 이름이 있습니다."(기존)
- 빈칸 폴더명 = `/U4A/MSG_WS` 050 "& is required"(기존, 원본 그대로)
- 파일 이름 길이 = `ZMSG_WS_COMMON_002` 004 "파일 이름은 &1 자리를 넘을 수 없습니다."(신규, &1=최대 길이 자동 치환) — 장군님 등록 완료

**부가 발견/조치**
- 파일 이름 60자 초과 안내가 예전엔 엉뚱한 문구(970 "브라우저 종료")를 가리켰음 → 위 002-004로 교정.
- `/U4A/MSG_WS`는 신규 추가 금지 클래스, `ZMSG_WS_COMMON_001`은 0~999 포화 → 신규 문구는 신설된 `ZMSG_WS_COMMON_002`에 등록.
