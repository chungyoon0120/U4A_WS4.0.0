> 화면: WS20 편집 모드 → 디자인 트리에서 UI 한 줄 우클릭/＋ → **UI Object Select**(UI 추가) 팝업

### BR45 — 올리기 주소(uploadUrl)가 항상 현재 앱 기준으로 설정되는지 (재검증)

> **2026-09-14 재수정.** 원작자가 원본에서 오탈자를 고쳤고(주소를 **값칸이 아니라 엉뚱한 칸**에 써서 무효였던 것 → 값칸으로), 그 정정을 내 파일에도 그대로 맞췄다. `/zu4a_srs/` 로 시작하는지를 **대소문자 구분 없이** 판단하도록 한 것도 원본대로 반영.
> 그래서 **예전에 "원작자 수정 대기"로 보류였던 아래 4건이 이제 실제 테스트 대상**이다. 이번엔 **네 건 모두 현재 앱 주소가 나와야 정상**이다.
> **전제:** 서로 다른 앱 **2개**(앱A·앱B), 둘 다 편집 가능. **확인 지점** = 파일올리기 UI 선택 시 속성 목록의 **uploadUrl** 값. 앱을 **껐다 켠 뒤** 테스트(새로고침 아님).
