## 지금 할 것 (미테스트)

### BR37 — UI 추가 팝업에서 집계 이름과 무관하게 Generated Cnt 가 계속 보이던 문제

> 원래 규칙: **Aggregation Name** 을 골랐을 때 그 집계가 **여러 개 넣을 수 있는 것일 때만** 아래에 **Generated Cnt**(넣을 개수) 줄이 보인다.
> 고치기 전엔 집계를 **안 골랐거나, 공백/한 개만 넣는 집계**를 골라도 **Generated Cnt 줄이 계속 보였다**. 이제 여러 개 넣는 집계일 때만 보인다.
> ★기준: `content`(여러 개 가능)=보임 / `customHeader`(한 개만)·공백·미선택=안 보임.

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| BR37-1 | 팝업을 **막 열었을 때**는 Generated Cnt 줄이 **안 보인다** | ① 편집 모드에서 디자인 트리의 **PAGE**(sap.m.Page) 줄을 왼쪽 클릭해 고른다 ② 그 줄 오른쪽 **＋ 아이콘**을 클릭한다(또는 우클릭 → **Insert Element**) ③ **UI Object Select** 팝업이 뜬다 → 이때 **Aggregation Name** 은 빈 상태이고, 그 아래 **Generated Cnt** 줄이 **보이지 않는다** | ☐ |
| BR37-2 | **공백 항목**을 고르면 Generated Cnt 줄이 **안 보인다** | ① 위 팝업에서 **Aggregation Name** 목록을 연다 ② 맨 위 **빈(공백) 항목**을 고른다 → **Generated Cnt** 줄이 **보이지 않는다** | ☐ |
| BR37-3 | **customHeader**(한 개만 넣는 집계)를 고르면 **안 보인다** | ① **Aggregation Name** 목록에서 **customHeader** 를 고른다 → **Generated Cnt** 줄이 **보이지 않는다** | ☐ |
| BR37-4 | **content**(여러 개 넣는 집계)를 고르면 **보인다** | ① **Aggregation Name** 목록에서 **content** 를 고른다 → **Generated Cnt** 줄이 **보이고**, 개수 입력칸(＋/－ 버튼과 숫자)이 나타난다 | ☐ |
| BR37-5 | content(보임)에서 다시 customHeader/공백으로 바꾸면 **다시 안 보인다** | ① BR37-4 상태(**content** 골라 Generated Cnt 보임)에서 ② **Aggregation Name** 을 **customHeader** 또는 **빈 항목**으로 다시 바꾼다 → **Generated Cnt** 줄이 **다시 사라진다** | ☐ |

> ★BR37-1·2·3·5 는 "안 보임" 확인, BR37-4 는 "보임" 확인. 다섯 다 통과해야 이관.
