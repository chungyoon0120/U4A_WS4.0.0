## 누락 아님(오판 방지·기록)

- 미리보기 호출(createUIInstance·moveUIObjPreView 등)은 원본이 iframe을 직접 부르는 걸 이식본은 래퍼로 부름 → 동일.
- 되돌리기(undo)는 원본 방식(액션 이력)을 HTML5 단일 스택으로 대체 → 문서화된 방식.
- 확정 시 개인화 체크값이 원본과 동일하게 넘어감(원본이 안 쓰는 자식목록 인자는 이식본도 안 넘김 = 원본과 동일).
- "선택한 라인 없음" 안내는 이식본이 행 선택 전 확정 버튼을 비활성화해 그 상황 자체가 안 생김(죽은 방어라 정상 제외).
- UI5 위젯 전용 뒷정리 마커·드래그 CSS 잔상 제거 등은 부트스트랩 화면엔 불필요(껍데기 차이).
