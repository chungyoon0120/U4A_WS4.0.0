## BR13 — 팝업 뒤 화면에 놓임 / 미리보기 파란 놓기 표시 (2026-08-11 통과)

**무엇을 고쳤나(쉽게)**: UI 추가 팝업에서 결과 목록의 UI를 끌 때, 예전엔 끄는 동안 팝업을 "클릭 통과"로 만들어 팝업에 **가려진** 뒤 화면(왼쪽 디자인 트리·가운데 미리보기)까지 끌기가 전달됐다 → 팝업 안인데도 뒤 화면에 놓이고, 미리보기엔 **파란 놓기 표시**가 잘못 떴다. 이제 끄는 동안에도 **팝업이 가린 부분은 뒤 화면이 끌기를 못 받게** 막아 → 파란 표시·놓기가 안 생기고, 팝업 **밖의 보이는** 트리/미리보기에 놓을 때만 추가된다.

| 코드 | 동작 | 조작·확인 포인트 | O/X |
|---|---|---|---|
| BR13-1 | 팝업 위에서 손 떼면 안 놓임 | ① WS20 편집 모드 ② UI 한 줄에서 UI 추가 → **UI Object Select** 팝업 ③ Aggregation 고르기 ④ 목록 UI(예: Button)를 팝업 위에서 손 떼기 → **안 추가**(팝업 위 "놓을 수 없음" 커서) | ✅ O |
| BR13-2 | 팝업이 가린 미리보기에 파란 표시 안 뜸 | ① 팝업이 미리보기 덮은 상태 ② 목록 UI를 팝업 안쪽(가려진 미리보기 위)으로 지나가기 → **파란 놓기 표시 안 뜸** | ✅ O |
| BR13-3 | 팝업 밖 보이는 트리에 놓으면 추가됨 | ① 목록 UI 끌기 ② 팝업 왼쪽 밖 보이는 트리 줄로 ③ 손 떼기 → **정상 추가** | ✅ O |
| BR13-4 | 팝업 밖 보이는 미리보기에 놓으면 추가됨 | ① 목록 UI 끌기 ② 팝업 밖 보이는 미리보기 자리로 ③ 손 떼기 → **정상 추가** | ✅ O |
| BR13-5 | 팝업 옮겨도 판정 정확 | ① 헤더 잡아 팝업 이동 ② 팝업 위=안 놓임 / 팝업 밖 트리=놓임 | ✅ O |

## BR14 — 같은 UI 중복 추가 막기 (2026-08-11 통과)

**무엇을 고쳤나(쉽게)**: UI 추가 팝업으로 UI를 넣을 때, **앱당 1개만 넣을 수 있는 UI(예: PressTrigger)를 이미 넣어놓고 또 넣으려 하면 막고 "추가 불가" 안내가 뜬다.** 예전엔 같은 걸 몇 번이고 넣을 수 있었다(테스터 캡처: PressTrigger 1·2·3 중복). 원본과 똑같이 되돌린 것.

원본 대조·코덱스·안티 3중 검수 통과.

| 코드 | 동작 | 조작·확인 포인트 | O/X |
|---|---|---|---|
| BR14-1 | 팝업 [확인]/더블클릭으로 같은 UI 두 번째 추가 시 막힘 | ① WS20에서 편집 모드로 들어간다. ② 디자인 트리에서 UI 한 줄을 골라 UI 추가(＋/우클릭 메뉴) → **UI Object Select** 팝업을 연다. ③ Aggregation을 하나 고른다. ④ 목록에서 **PressTrigger**를 골라 [확인](또는 그 줄 더블클릭)으로 **한 번 추가한다** → 트리에 정상 추가된다. ⑤ 다시 같은 방법으로 UI 추가 팝업을 열어 **같은 PressTrigger를 골라 [확인]** → 이번엔 **추가되지 않고 "추가 불가"(이미 있음) 안내 메시지**가 떠야 한다. | ✅ O |
| BR14-2 | 결과행을 트리로 끌어놓기 경로도 같은 UI 두 번째면 막힘 | ① 위처럼 PressTrigger를 한 번 추가해 둔다. ② UI 추가 팝업을 열고 목록의 **PressTrigger 한 줄을 팝업 밖 보이는 디자인 트리로 끌어다 놓는다.** → **추가되지 않고 "추가 불가" 안내 메시지**가 떠야 한다(★BR14-1의 [확인] 버튼과 다른, 끌어놓기 경로). | ✅ O |
