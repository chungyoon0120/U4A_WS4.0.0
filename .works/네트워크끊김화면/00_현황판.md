# 네트워크 끊김 화면 — 현황판

## 지금 할 것 (테스트)

Electron 앱을 실행한 상태에서 인터넷을 끊어야 재현되는 화면. 실제 랜선을 뽑는 대신, 개발자 도구 콘솔에서 `setNetworkBusy(true)` / `setNetworkBusy(false)` 로 켜고 끌 수 있음(랜선 안 뽑아도 됨).

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| NW1 | 화면 막힘 카드 디자인 | ① 콘솔에 `setNetworkBusy(true)` 입력 → ② 화면 전체가 짙게 덮이고(뒤 화면이 은은하게 비침) 가운데에 둥근 모서리 카드가 뜨는지 확인 | ✅ O |
| NW2 | 경과 시간 표시 | 카드가 뜬 채로 몇 초 기다린다 → 카드 안 "Disconnected 0:05" 식으로 흐른 시간이 1초마다 올라가는지 확인 | ✅ O |
| NW3 | 인터넷 복구 시 정상 해제 | 콘솔에 `setNetworkBusy(false)` 입력 → 카드가 사라지고 경과시간도 더 안 올라가는지 확인 | ☐ |
| NW4 | CLOSE 버튼 → 종료 확인창 | 카드 안 CLOSE 버튼을 누른다 → "프로그램을 종료하시겠습니까?" 확인창(예/아니오)이 뜨는지, "아니오" 누르면 화면이 그대로 남는지 확인 | ☐ |
| NW5 | CLOSE → 예 → 실제 종료 | (NW4와 별도로 다시 재현한 뒤) 확인창에서 "예"를 누른다 → 앱이 실제로 종료되는지 확인(마지막에 한 번만 테스트) | ☐ |

## 작업 내용

- 대상 화면: WS10/WS20을 담는 메인 창(`www/ws30/ws10_20/index.html`)의 `u4a_neterr` — 브라우저 온라인/오프라인 신호로 뜨는, 화면 전체를 막는 카드.
- 원본(as-is, `U4A_WS3.0.0`)엔 이 화면에 와이파이 그림과 "Network Disconnect...." 글자만 있고 버튼·경과시간 같은 조치 기능이 없었음(확인 완료). 장군님 명시 지시로 디자인·기능을 보강.

### 진행 경과(최신순)
- **탭키 새는 버그 수정(2026-09-08)**: 실제 앱 실측 결과, 화면이 그냥 `<div>`라서 카드가 뜬 상태에서 Tab키를 누르면 뒤 화면(검색창)에 커서가 넘어가 배경 요소를 그대로 조작할 수 있었음(심각). 로딩중 화면과 같은 진짜 "막는 창"(`<dialog>`+`showModal()`) 방식으로 전환 — 브라우저가 직접 뒤를 차단해 탭키·ESC 모두 못 새어나가게 함. 미리보기로 Tab 5회·ESC 실측 확인 완료, 실제 앱 확인은 NW6.
- **배경을 반투명 "스모크 유리"로(2026-09-08)**: 화면 전체를 완전히 가리는 방식이 답답하다는 지적 → 흐림 효과(블러)는 이 화면이 속한 문서(창 제목줄과 같은 파일)에 쓰면 창 리사이즈 시 제목줄 드래그가 깨지는 버그가 있어(소스에 경고 존재, Electron 실제 버그 사례로도 확인) 사용 불가. 대신 짙은 회청색을 반투명하게 올려 뒤가 은은히 비치는 방식으로 변경.
- **RETRY 버튼 삭제, CLOSE만 남김(2026-09-08)**: 네트워크가 끊긴 상태에서 앱만 재시작해봐야 의미 없다는 지적 → 재시작 버튼 제거, 종료 버튼만 유지.
- **CLOSE 클릭 시 확인창 추가(2026-09-08)**: 종료 전 "프로그램을 종료하시겠습니까?" 확인창을 반드시 거치도록 추가(브라우저 기본 대화상자 금지 규칙에 따라 공통 확인창 컴포넌트 사용).
- **메시지 DB 연동(2026-09-08)**: 카드 제목·설명·확인창 문구를 전부 메시지 DB 키 참조로 전환, 접속 언어에 맞춰 자동으로 바뀜.
- **디자인 카드형 보강(2026-09-07)**: 세션 끊김 안내창과 같은 둥근 카드형으로 통일, 크기 확대, 경과시간 표시 추가.
