# 네트워크 끊김 화면 — 현황판

## 지금 할 것 (테스트)

Electron 앱을 실행한 상태에서 인터넷을 끊어야 재현되는 화면이라, 브라우저 미리보기로는 확인이 안 됨. 아래를 실제 앱에서 확인해 주세요.

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| NW1 | 화면 막힘 카드 디자인 | ① 앱 실행 중 랜선을 뽑거나 와이파이를 끈다 → ② 화면 전체가 흐릿하게 덮이고 가운데에 둥근 모서리 카드(와이파이 그림+글자+버튼 2개)가 뜨는지 확인 | ☐ |
| NW2 | 경과 시간 표시 | 카드가 뜬 채로 몇 초~1분 정도 기다린다 → 카드 안 글자 밑에 "Disconnected 0:05" 식으로 끊긴 뒤 흐른 시간이 1초마다 올라가는지 확인 | ☐ |
| NW3 | 인터넷 복구 시 정상 해제 | 랜선을 다시 꽂거나 와이파이를 켠다 → 카드가 사라지고 경과시간 숫자도 더 안 올라가는지(뒤에서 계속 도는 타이머가 안 남는지) 확인 | ☐ |
| NW4 | RETRY 버튼(다시 시작) | 카드가 뜬 상태에서 카드 안 "RETRY" 버튼을 누른다 → 앱이 완전히 종료됐다가 새로 켜지는지 확인 | ☐ |
| NW5 | CLOSE 버튼(종료) | (NW4와 별도로 다시 재현한 뒤) 카드 안 "CLOSE" 버튼을 누른다 → 앱이 그대로 꺼지는지(다시 안 켜지는지) 확인 | ☐ |

## 작업 내용

- 대상 화면: WS10/WS20을 담는 메인 창(`www/ws30/ws10_20/index.html`)의 `u4a_neterr` — 브라우저 온라인/오프라인 신호로 뜨는, 화면 전체를 막는 카드.
- 원본(as-is, `U4A_WS3.0.0`)엔 이 화면에 와이파이 그림과 "Network Disconnect...." 글자만 있고 버튼·경과시간 같은 조치 기능이 없었음(확인 완료). 이번 작업은 장군님 명시 지시로 디자인·기능을 보강.
- 디자인: 화면 전체를 옅게 덮는 방식은 그대로 두고, 안쪽 내용을 다른 화면(세션 끊김 안내창)과 같은 둥근 카드 모양으로 통일. 색은 전부 공통 테마 값(`--surface-raised`/`--text`/`--line` 등) 사용, 하드코딩 없음.
- 추가 기능:
  - 끊긴 뒤 흐른 시간을 1초마다 "Disconnected 분:초" 형태로 표시.
  - RETRY(다시 시작)·CLOSE(종료) 버튼 — 로그인 화면의 업데이트 오류창에 이미 있던 것과 똑같은 방식(`APP.relaunch()+APP.exit()` / `APP.exit()`)을 그대로 가져다 씀. 새로 만든 동작 아님.
- 건드린 파일 3개: `www/ws30/ws10_20/index.html`, `www/ws30/ws10_20/css/frame.css`, `www/ws30/resources/index.js`.
- `node --check`로 문법 확인 통과.
