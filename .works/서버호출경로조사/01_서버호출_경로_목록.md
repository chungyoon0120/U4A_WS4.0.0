### 서버 주소를 만드는 자리는 **한 곳**

```
oWS.utill.fn.getServerPath(bIsStateLess)      ← www/ws30/resources/index.js:401
    = getServerHost() + "/zu4a_wbc/u4a_ipcmain"      (기본)
    = getServerHost() + "/zu4a_wbc/u4a_dynpro"       (bIsStateLess === true)

oWS.utill.fn.getServerHost()                   ← www/ws30/resources/index.js:412
    = `${protocol}://${host}` (+ `:${port}` 가 있으면)
      ← 값 출처 = oWS.oServerInfo.SERVER_INFO (서버리스트에서 고른 접속 정보)
```

- 전역 진입점 = `getServerPath()` / `getServerHost()` (`www/ws30/resources/index.js:1573`, `1578`)
- 화면들은 이것을 `oAPP.attr.servNm` 에 한 번 담아 두고 쓴다
  (`design/js/main.js:18`, `js/ws_html5_ws20_attr.js:2399`, `js/ws_html5_ws20_data.js:157`)
- 별창(팝업)은 부모가 넘겨준 값(`IF_DATA.SERVPATH` / `sServerPath` / `SERVER_PATH`)을 쓴다
  → 별창은 `parent.getServerPath()` 를 못 쓰는 경우가 있어 **부모가 넘겨준 문자열**이 출처다
