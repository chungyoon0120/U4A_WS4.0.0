# 히스토리 — UI 속성 영역 서버이벤트

> 완료(전 항목 통과)된 그룹을 현황판에서 이관 보관.

## BR33 — 서버이벤트 값칸 두 번 클릭 → 컨트롤러 클래스 메소드 이동 — 전 항목 통과 ✅ (2026-08-14)

> 이벤트에 서버이벤트를 설정한 뒤, 그 값칸을 두 번 클릭하면 원본(WS3.0)은 컨트롤러 클래스의 그 메소드로
> 이동(SAP GUI 호출)하는데 WS4.0은 이동 배선이 빠져 있던 문제. 원본 서버이벤트 두 번 클릭 함수를
> 그대로 이식하고, 값칸에서 일어난 두 번 클릭만 잡도록 속성 목록에 한 번만 배선(이벤트명 링크·아이콘 제외).
>
> 곁들여(장군님 요청): 두 번 클릭 시 서버이벤트 목록이 딸려 열리던 것을 막음. 공통 드롭다운에 옵션을
> 추가(기본 꺼짐)해 서버이벤트 값칸에만 켬 — 두 번 클릭 신호가 오면 열리려던 목록을 취소·닫기. 한 번
> 클릭 여는 길은 그대로라 단일 클릭은 안 굼떠짐.
>
> 수정 파일: `js/ws_html5_ws20_attr.js`(두 번 클릭 이식·배선 + 값칸 옵션 켜기), `theme/u4a-ui.js`(공통
> 드롭다운 옵션 추가). 백업 `_ws_html5_ws20_attr.js.br33bak`·`_u4a-ui.js.br33bak`.
> 검수: 코덱스·안티 둘 다 통과·지적 0(값칸 두 번 클릭 이식분). 노션 BR33=수정완료.

| 코드 | 동작 | O/X |
|---|---|---|
| SE1 | 서버이벤트 값칸 두 번 클릭 → 컨트롤러 클래스 메소드로 이동(SAP GUI) | ✅ O |
| SE2 | 이벤트명(왼쪽 밑줄 글자) 두 번 클릭 → 이동 안 됨 | ✅ O |
| SE3 | 줄 오른쪽 끝 아이콘(만들기·등록) 두 번 클릭 → 이동 안 됨 | ✅ O |
| SE4 | 빈 값칸 두 번 클릭 → 아무 일 없음 | ✅ O |
| SE5 | 값칸 한 번 클릭 → 서버이벤트 목록만 펼침(기존 유지) | ✅ O |
| SE6 | 두 번 클릭 → 이동만, 서버이벤트 목록 안 열림(새로 반영) | ✅ O |
| SE7 | 옵션 켠 뒤에도 한 번 클릭 목록 열기 정상(굼뜸·막힘 없음) | ✅ O |

## 그룹 B. 없는 서버이벤트 오류표시 (이슈2) — 전 항목 통과 ✅ (2026-08-12)

> 오류표시는 공통 드롭다운 컴포넌트로 이관(createSelect.setValueState + 공통 색/목록 문구). 접힘=빨간 테두리·옅은 빨강 배경·값 글자 / 펼침=목록 최상단 오류 문구. 문구 = ZMSG_WS_COMMON_001|999 "&1 의 이벤트 메서드가 없습니다".

| 코드 | 동작 | 조작·확인 포인트 | O/X |
|---|---|---|---|
| EV1 | 목록에 없는 이벤트값 → 접힘·펼침 오류 표시 | ① 값이 서버에 없는 이름인 이벤트 행 준비 → ② 값 칸 한 번 펼쳤다 닫기 → ③ 접힘: 테두리·배경·글자 빨강 / ④ 펼침: 목록 맨 위 오류 문구(안 가림, 그 아래 빈칸). | ✅ O |
| EV2 | 정상 이벤트를 고르면 오류 표시가 사라진다 | ① 목록에서 정상 이벤트 선택 → ② 빨강·문구 모두 사라짐. | ✅ O |
| EV3 | 정상 이벤트값은 빨강이 안 생긴다 | ① 서버 목록에 있는 정상값 행의 값 칸 펼침 → ② 테두리 평소색. | ✅ O |

## 그룹 C. 서버이벤트 생성 알림 언어 (BR24와 별개 건) — 전 항목 통과 ✅ (2026-08-12)

> 서버는 알림을 로그인 언어로 구워 보낸다. 화면 언어와 다르면 되돌려 표시하도록 고침(createEventPopup.js).

| 코드 | 동작 | 조작·확인 포인트 | O/X |
|---|---|---|---|
| LG1 | 서버이벤트 생성 성공 알림이 화면 언어로 뜬다 | ① 화면 언어=한국어, 로그인 언어=영어로 접속 → ② 서버이벤트 새로 생성 → ③ 성공 알림이 한국어로 나옴. | ✅ O |
| LG2 | 로그인·화면 언어가 같으면 그대로(회귀 없음) | ① 로그인=화면 언어 동일 접속 → ② 서버이벤트 생성 → ③ 알림 정상(깨짐 없음). | ✅ O |
