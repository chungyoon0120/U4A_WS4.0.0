# 현황판 — UI 속성 영역 서버이벤트

> 대상: WS20 오른쪽 **UI 속성 영역**의 이벤트(Event) 속성.
> 코드반영은 **앱을 껐다 켜야** 보인다(새로고침 아님).

## 지금 할 것 (미테스트)

### BR33 — 서버이벤트 값칸 두 번 클릭 → 컨트롤러 클래스 메소드 이동

> 공통 준비: ① WS20 화면을 연다. ② 왼쪽 트리에서 대상 UI(예: **PAGE1**)를 클릭해 선택한다.
> ③ 오른쪽 **UI 속성 영역**에서 **Events**(이벤트) 묶음으로 내려가 서버이벤트를 넣을 수 있는
> 이벤트 줄(예: **navButtonPress**)을 찾는다. ④ 그 줄의 값 칸(펼침 목록)을 한 번 눌러
> 목록에서 서버이벤트(예: **EV_TEST1**)를 고른다. → 이 상태에서 아래를 테스트.

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| SE1 | 서버이벤트 값칸을 두 번 클릭하면 컨트롤러 클래스의 그 메소드로 이동 | ① 값 칸에 **EV_TEST1**이 보이는 상태에서 ② 값 글자 부분을 **빠르게 두 번 클릭**한다. → "SAPGUI Launch / 잠시만 기다려 주세요" 대기 표시가 뜨고 **SAP GUI가 떠서 EV_TEST1 메소드 위치로 이동**하면 통과 | ☐ |
| SE2 | 이벤트명(왼쪽 밑줄 글자)을 두 번 클릭해도 이동 안 됨 | ① 같은 줄 **왼쪽의 이벤트명 글자**(navButtonPress, 마우스 올리면 밑줄) 부분을 두 번 클릭한다. → SAP GUI가 **뜨지 않으면** 통과(이 자리는 설명 도움말 자리라 이동 대상 아님) | ☐ |
| SE3 | 이벤트 줄 오른쪽 끝 아이콘(서버이벤트 만들기·클라이언트 이벤트 등록)을 두 번 클릭해도 이동 안 됨 | ① 같은 줄 **오른쪽 끝의 작은 아이콘**들을 두 번 클릭한다. → SAP GUI가 **뜨지 않으면** 통과(아이콘은 각자 자기 기능이라 이동 대상 아님) | ☐ |
| SE4 | 서버이벤트를 안 고른 빈 값칸을 두 번 클릭하면 아무 일 없음 | ① 서버이벤트를 **고르지 않아 값이 빈** 이벤트 줄의 값 칸을 두 번 클릭한다. → SAP GUI가 **뜨지 않고** 화면에 변화가 없으면 통과 | ☐ |
| SE5 | 값칸 한 번 클릭은 기존대로 서버이벤트 목록만 펼침(이동 아님) | ① 값 칸을 **한 번만** 클릭한다. → 서버이벤트 **목록이 펼쳐지면** 통과(두 번 클릭 이동 기능이 한 번 클릭 목록 열기를 망가뜨리지 않았는지 확인) | ☐ |
