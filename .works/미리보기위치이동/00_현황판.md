# 미리보기 "위치 이동" 버그(BR18) 수정 — 테스트 현황판

옛 UI5 팝업을 부르다 터지던 미리보기 우클릭 "위치 이동"을 공통 HTML5 팝업으로 교체 +
검수 지적/장군님 지시("원본대로")로 원본 동작 복원.

> 코드 반영은 **앱을 껐다 켜야** 적용됩니다(새로고침 아님).
> ★A: 미리보기 영역(가운데 화면)에서 우클릭 → "위치 이동"
> ★B: 왼쪽 트리에서 UI 줄 우클릭 → "위치 이동"  (★A와 다른 진입. 둘 다 같게 동작해야 함)

| RS1 | 확인 누르면 오류 없이 이동됨(★"getTreeIndexOfChild" 오류창 안 뜸) | ① ★A로 팝업 열기 ② 위치 번호 바꾸고 파란 ✓ 누름 ③ 빨간 X 오류창 없이 그 위치로 옮겨지는지 | ☐ |
| RS2 | 팝업 열면 왼쪽 트리에 "옮길 자리" 미리 색표시 | ① ★A로 팝업 열기 ② 왼쪽 트리에서 그 UI의 형제 줄들에 색 강조가 뜨는지(대상 줄·목표 위치 줄이 색으로 구분) | ☐ |
| RS3 | 슬라이더를 놓는 순간 강조 위치가 바뀜(끄는 중엔 트리 안 다시 그림) | ① ★A로 팝업 열기 ② 슬라이더를 끌면 숫자·슬라이더는 실시간으로 움직이되 트리 강조는 그대로 ③ 마우스를 놓으면 왼쪽 트리 "목표 위치" 색표시가 그 값으로 옮겨가는지 (숫자칸은 값 넣고 칸 밖 클릭/Enter 시 갱신) | ☐ |
| RS3b | 대상 위치가 화면 밖이면 그 줄로 스크롤됨 | ① ★A로 형제가 많은 UI에서 팝업 열기 ② 슬라이더를 트리에 안 보이는 먼 위치까지 끌고 놓기 ③ 왼쪽 트리가 그 위치 줄로 스크롤되어 강조가 보이는지 | ☐ |
| RS4 | 팝업 닫으면 강조 사라짐 | ① ★A로 팝업 열고 강조 확인 ② 빨간 ✗ 또는 확인으로 닫기 ③ 왼쪽 트리 색 강조가 없어지는지 | ☐ |
| RS5 | 숫자칸에서 Enter=확인 버튼으로 커서만 이동(바로 안 옮김) | ① ★A로 팝업 열기 ② 숫자칸에 값 넣고 Enter ③ 바로 안 옮겨지고 파란 ✓ 버튼에 커서(테두리)가 가는지 ④ 거기서 Enter/스페이스로 확정 | ☐ |
| RS6 | 트리 우클릭 팝업도 위(RS1~RS5)와 똑같이 동작 | ① ★B로 팝업 열기 ② RS1·RS2·RS3·RS4·RS5를 ★B에서도 동일하게 확인 | ☐ |
