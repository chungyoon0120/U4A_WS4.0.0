# 미리보기 "위치 이동" 팝업(BR18) — 완료 히스토리

## 2026-08-12 — BR18 미리보기 우클릭 "위치 이동" 팝업 HTML5 전환 + 원본 동작 복원 (전 항목 통과)

옛 UI5 팝업(`uiMovePosition.js`)이 메인 창에서 없는 화면라이브러리를 불러 터지던 것을 공통 HTML5 팝업으로 교체.
확인 시 옛 공통 이동 함수(없는 함수 호출로 터짐)를 트리와 동일한 HTML5 이동으로 우회. 검수·장군님 지시로 원본 동작(연타·엔터·닫기·미리 강조·스크롤) 복원.

수정 파일: `design/js/uiMovePosition.js`(전면 재작성), `js/ws_html5_ws20_edit.js`(공용 이동 함수+트리 팝업 통일),
`js/ws_html5_ws20_prev.js`(위치 이동 위임), `js/ws_html5_ws20_tree.js`(스크롤 함수 공개). 원본 UI5 백업: `design/js/_uiMovePosition_ui5_asis.js.bak`.

## BR59 — 컨텍스트 메뉴 UI 이동 시 트리·미리보기 순서 불일치 (2026-08-21 통과)

미리보기에 넘길 자리 번호를 부모 밑 전체 자식 순서로 계산해, 서로 다른 그룹의 자식이 섞인 부모에서 트리와 미리보기 순서가 어긋나던 것 → **같은 그룹 자식만 골라 그 안에서의 순서**로 교정(부모에 실제로 안 붙는 UI 제외). 그룹 안 순서가 실제로 바뀐 경우에만 미리보기를 손댄다(원본 계약). 더불어 미리보기를 **다 그리기 전에** 선택을 불러 화면이 그 자리로 안 굴러가던 것 → 제거·재생성·다시 그리기 완료를 기다린 뒤 선택하도록 원본 순서 그대로 이식. 위/아래·위치 지정 이동 두 경로 공용.
