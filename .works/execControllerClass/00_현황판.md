# 컨트롤러(클래스 빌더) 실행 — 현황판

## 0. 지금 할 것 — 테스트 (VBS 실행 오류 창 HTML5 변환 · 콘솔 비밀번호 가림, 2026-09-17)

> **고쳤다(2026-09-17, 장군님 지시).** 컨트롤러 실행이 실패할 때 뜨는 「VBS 실행 오류」 창이 옛 UI5 코드 그대로라,
> 뜨는 순간 `sap.m.Button` 크리티컬 스크립트 오류가 났다 → 공통 팝업으로 옮겼다. 콘솔에 찍히던 SAP 비밀번호는 `******` 로 가렸다.
> **앱을 완전히 껐다 켜야 반영된다.** 원인 조사 = [01_sap_m_Button_크리티컬오류_조사.md](01_sap_m_Button_크리티컬오류_조사.md)
>
> **오류를 일부러 내는 방법 (CE2~CE4) — 소스로 확인한 것**
> - 오류 창은 **SAP GUI 가 꺼진 상태에서** 컨트롤러를 눌러 「SAP Logon 을 새로 띄우는 스크립트」가 돌다가 실패할 때만 뜬다.
> - 그 스크립트는 SAP Logon 프로그램 위치를 레지스트리 `HKEY_CURRENT_USER\SOFTWARE\U4A\WS\GUIPath` 의 **(기본값)** 에서 읽어 실행한다(`sapgui_ws.vbs` 215·504·508줄). 여기를 **없는 파일 경로로 바꾸면 실행이 반드시 실패**한다.
> - 이 값은 **앱을 켤 때 서버 목록 화면이 다시 써 넣는다**(`www/ServerList_v2/ServerList.js` 689~695줄) → **앱을 껐다 켜면 원래대로 돌아온다.** 지금 이 PC 의 원래 값 = `C:\Program Files\SAP\FrontEnd\SAPGUI\saplogon.exe` (2026-09-17 조회).
> - ⚠ **신규 네임스페이스 서버에서만 통한다.** 구 서버(네임스페이스 미적용)는 다른 스크립트(`asis_sapgui_ws.vbs`)가 다른 레지스트리를 읽어 이 방법이 안 먹는다. 테스트하실 서버가 어느 쪽인지는 **미확인** — 안 뜨면 「안 뜸」 으로 적어 주시면 다른 방법을 찾는다.
> - 오류 원문의 정확한 문장은 **미확인**(윈도우 언어에 따라 다르다) — 「파일을 찾을 수 없다」 는 뜻의 문장일 것으로 본다.
