## 2. 확정된 사실

| 항목 | 결과 | 근거 |
|---|---|---|
| registry 쓰기 | **정상** | `ActionParam` 지우고 실행 → 값이 생김 (장군님 실측) |
| registry 읽기 | **정상** | 임시 값 `YOON` 은 실시간 반영 (장군님 ABAP 테스트 프로그램) |
| no-build / 빌드 차이 | **아님** | 장군님 재확인 |
| VBS 파일 | 양쪽 동일 | 크기·날짜 동일. 해제 처리는 조건 없이 항상 돈다 |
| registry 경로 | 앱·VBS·ABAP 동일 | `HKEY_CURRENT_USER\SOFTWARE\U4A\WS\TCProxy` |
| 발생 양상 | **간헐적** | 재부팅으로 일시 해소, 다시 재발 |
