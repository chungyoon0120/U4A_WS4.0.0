### 이 그룹 진행 중 있었던 일

**`sap-adt` 등록이 한 번 지워졌다 → 재등록으로 해결.**
서버 실체(`yoon-agent-kit\mcp\sap_adt_mcp`)는 멀쩡했고 `C:\Users\socce\.claude.json` 의
user scope 등록만 사라져 있었다. 이 작업 뒤에 돈 다른 세션이 같은 파일의 `mcpServers` 를
다시 쓰면서 덮어쓴 것으로 보인다(**덮어쓴 주체는 직접 확인 못 함 — 미확인**).
`claude mcp add sap-adt --scope user` 로 재등록 → `claude mcp list` 3개 다 ✔ Connected.

→ **다음 agent 가 알아야 할 것:** `~\.claude.json` 을 손으로 고치지 마라. Claude Code 가 계속
쓰는 파일이라 덮어쓰인다. 그리고 **세션을 여러 개 동시에 돌리면 이 파일이 서로 덮어쓴다.**
MCP 가 "없다"고 나오면 실체보다 **등록부터** 봐라.
