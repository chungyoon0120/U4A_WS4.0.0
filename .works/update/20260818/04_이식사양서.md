## 4. 새로 찾은 위험 5가지 (이번 이식과 직접 연관)

1. **금지 조합 검사가 경로마다 다르게 동작.** 끌어놓기 쪽은 검사가 실패하면 **막지 않고 통과**, 팝업 쪽은 막는다.
2. **미리보기용 원본 파일 불러오기가 실패해도 아무도 모른다.** 파일 교체 중 오류가 나면 미리보기가 안 뜨고
   화면 잠금이 남는다(감시 시간이 지나야 풀림) — 이번처럼 원본 파일을 갈아끼울 때 가장 조용히 실패하는 지점.
3. **우리 수정이 원본 폴더 파일 42개에 섞여 있다.** 이번 대상 중 3개에 우리 수정이 들어 있어, 통째 덮어쓰면
   미리보기 우클릭의 "내 패턴"·"사용처 조회"가 되돌아가 죽는다.
4. **자리선택 팝업은 "이미 있으면 안 부른다" 규칙 하나로만 우리 것이 살아 있다.** 로드 순서가 한 번만 바뀌어도
   옛 방식이 실려 화면에 아무 표시 없이 죽는다.
5. **우리 처리들이 "이미 있으면 설치 안 함"으로 걸려 있어**, 원본 로드 지점이 하나만 늘어도 조용히 뒤바뀐다
   (D05가 바로 그 사례).

## 5. 원본 쪽 결함 3건 (보고만, 옮기지 않음)

1. 도움말 말풍선 닫기에서 넘기는 값 이름이 잘못됨 — 원작자 확인 완료(붙여넣기 잔재, 지금은 도달 불가).
2. **화면 마법사의 "넣을 자리 없음" 차단이 죽음** — 결과를 담는 칸과 읽는 칸이 다름.
3. **예제를 별도 창으로 띄우는 지정값을 받는 쪽이 옛 상태** — 원본끼리도 동작 안 함(그 파일은 다른 저장소).

## 6. 원작 개발자께 요청할 것

1. 예제 창 여는 함수가 새 지정값을 받도록 수정.
2. UI 추가 팝업 새 폴더 통째 전달(안 오면 팝업이 안 열림).
3. 빠른 검색 폴더를 켤지 여부 — 지금은 부르는 데가 한 곳도 없음.
4. 화면 마법사 차단 죽은 것(위 결함 2) 확인.
