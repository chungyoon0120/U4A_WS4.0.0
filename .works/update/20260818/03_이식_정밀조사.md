## ★ 새로 드러난 위험 6가지 (1판에 없던 것)

1. **판정 결과를 쓰는 곳이 2곳이 아니라 3곳.** 세 번째는 AI로 화면 만들기 기능이 실행 중 불러오는 원본 파일이다.
   안 고치면 **오류 한 줄 없이 항상 통과** → 넣으면 안 되는 자리에 UI가 들어간다. 한 번에 같이 고쳐야 한다.
2. **안내문만 고치면 화면은 안 바뀐다.** 우리 우클릭 메뉴 쪽 처리는 **미리보기가 뜨는 순간 원본 파일이 같은 이름으로 덮어쓴다.**
   우리 파일에서 덮어쓰기 **뒤에 다시 설치**하거나, 원본 폴더를 새 것으로 받아야 한다.
3. **새 문구 묶음이 우리 저장소에 아예 없다(실측: 폴더·파일 0).** 지금 이식하면 화면에 문구 대신 키가 그대로 뜬다.
   더구나 우리 문구 도우미는 그 키에서 번호만 남기고 버려, **미등록이라는 사실조차 안 보인다.**
4. **표 열 자리 판정은 넣는 줄 위치 하나로 멀쩡한 바인딩이 지워진다.** 새 조건이 쓰는 값이 끌고 온 쪽 계산에도 쓰여,
   원본이 정한 자리보다 위에 넣으면 살아 있어야 할 바인딩이 해제된다.
5. **미리보기 스크롤은 우리 것과 정면충돌.** 우리는 화면 밖일 때만 살짝 옮기고, 원본 새 코드는 입력 초점을 옮긴다.
   둘 다 넣으면 화면이 두 번 튀고, 입력 초점이 미리보기로 끌려가 트리 키보드 이동·단축키가 먹통이 될 수 있다.
6. **0:1 자리(하나만 들어가는 자리) 막는 시점이 바뀐다.** 지금은 후보가 안 생겨 조용히 지나갔는데,
   바꾸면 후보로 뜨고 놓는 순간 "하나만 넣을 수 있다" 안내가 새로 뜬다. **화면 마법사 경로에는 그 뒷검사가 없어**
   0:1 자리에 두 번째가 들어갈 수 있다.

## ★ 원본 쪽 결함 3건 (보고만, 우리 코드에 옮기지 않음)

1. 도움말 말풍선 닫기에서 종료 코드 넘기는 부분 — 원작자 확인 완료(붙여넣기 잔재, 도달 불가).
2. **화면 마법사의 "넣을 자리 없음" 차단이 죽었다.** 새 판정이 결과를 담는 칸 이름이 바뀌었는데 받는 쪽은 옛 칸만 본다.
3. **예제를 별도 창으로 띄우는 옵션을 받는 쪽이 아직 옛날 상태다**(그 파일은 다른 원본 저장소, 반영일이 더 앞섬).
   → 원본끼리도 이 2건은 지금 동작하지 않는다.

## 참고 — 문서에 없는 신규 기능 규모(참고용, 이번 범위 밖)

UI 추가 팝업: 안내 영역 약 900줄 / 예제 실행 약 130줄 / 구문 복사 단추 약 90줄 / 자리 설명 말풍선 약 90줄.
기존 UI 키 값이 보이던 열이 **단추 2개짜리 기능 열로 바뀌며 그 열의 거르기·정렬이 없어짐.**
빠른 검색 연동 부분은 소스에 "임시 코드"라고 적혀 있음.
안내 영역이 읽는 그림 목록은 **우리 팝업의 그림 미리보기가 이미 쓰는 것과 같아** 나중에 재활용 가능.
