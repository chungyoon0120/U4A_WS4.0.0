# 테스트 체크리스트

### D03 — Ctrl 누른 채 복사할 때 못 쓰는 바인딩 경로 지우기

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| D03-T1 | 다른 부모로 Ctrl 복사하면 복사본의 바인딩이 풀린다 | ① 화면에 **Table**을 넣고 데이터 여러 건 바인딩을 건다 ② 그 표 안 **Column** 의 UI에 속성 바인딩을 하나 건다 ③ 화면 다른 곳에 **Panel** 같은 부모 UI를 하나 더 넣는다 ④ 왼쪽 UI 트리에서 그 UI를 **Ctrl 누른 채** Panel 위로 끌어다 놓는다 ⑤ 자리 고르는 목록이 뜨면 자리를 고른다 ⑥ 복사돼 들어간 UI를 클릭해 **속성 영역의 바인딩 표시가 풀려 있는지** 확인 | ☐ |
| D03-T2 | 같은 부모 안에서 복사하면 바인딩이 그대로다 | ① 같은 표 안에서 Column 하나를 **Ctrl 누른 채** 같은 표의 열 자리에 끌어다 놓는다 ② 복사된 UI의 **바인딩이 그대로 남아 있는지** 확인 | ☐ |
| D03-T3 | 하위 UI까지 같이 풀린다 | ① 바인딩된 UI 안에 자식 UI가 있고 그 자식에도 바인딩이 걸린 상태를 만든다 ② 그 UI를 다른 부모로 **Ctrl 복사**한다 ③ 복사된 **자식 UI의 바인딩도 풀려 있는지** 확인 | ☐ |
| D03-T4 | 되돌리기가 정상이다 | ① D03-T1 을 한 뒤 **되돌리기**를 누른다 ② 복사 전 상태로 돌아가는지 확인 ③ 다시 실행했을 때도 어긋나지 않는지 확인 | ☐ |
| D03-T5 | (회귀) 그냥 옮기기는 영향 없다 | ① Ctrl 없이 UI를 다른 부모로 끌어다 놓는다(이동) ② 평소대로 이동되고 바인딩 처리도 전과 같은지 확인 | ☐ |
