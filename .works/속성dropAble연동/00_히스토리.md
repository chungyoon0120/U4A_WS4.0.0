# 히스토리 — UI 속성 영역 dropAble ↔ DnDDrop 연동 (BR31)

> 대상: WS20 오른쪽 **UI 속성 영역**. "끌어다 놓기 허용(dropAble)" 값에 따른 "놓았을 때(DnDDrop)" 이벤트 잠금·초기화.

### 수정 요약
- 원본에 있으나 현행 미이식이던 `attrSetDropAbleException`(uiAttributeArea.js:3388) 이식 — dropAble 값에 따라 DnDDrop 입력 잠금(`edit`) + 끄면 서버/클라이언트 이벤트 초기화(_T_0015 라인 제거). UIASN(DROPABLE/DNDDROP) 의미명 기준 → 모든 해당 UI 공통. 조회 실패 오판 방지(코덱스 P1 반영), 초기화 3개 호출 오류 표면화(console.error).
- (장군님 지시 추가) DnDDrop 잠길 때 오른쪽 두 버튼 숨김(자동증가 예외처리와 동일 icon1/2_visb).
- (장군님 지시 추가) dropAble 끌 때 자동증가와 동일한 확인 팝업(메시지 283 재사용, 이벤트 유무 무관 무조건). 진입부 게이트 attrChangeDropAbleProp, YES=초기화·NO=원복.
- 파일: `js/ws_html5_ws20_attr.js`. 백업: `_ws_html5_ws20_attr.js.br31bak`.
- 검수: 코덱스·안티 통과(원본 이식분). 추가분(버튼 숨김·확인 팝업)은 검수 이후 장군님 지시로 반영.
