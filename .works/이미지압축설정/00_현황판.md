## 지금 할 것 — 테스트 (IC1 ~ IC12)

준비: ① 앱 실행 → 앱 하나 열기 → **편집** 상태로 만든다 ② 화면 왼쪽 트리에서 아무 페이지 아래에 **FileUploader** 를 추가하고 그 UI를 클릭해 선택한다 ③ 오른쪽 속성 목록을 아래로 내려 **imageCompressSettings** 줄을 찾는다

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| IC1 | 버튼 겉모습 | ① imageCompressSettings 줄의 값 칸을 본다 ② 버튼에 **글자가 없고 사진 모양 아이콘 하나만** 있는지 ③ 버튼이 **파랗게 채워져** 있는지 ④ 버튼 위에 마우스를 올리면 설명으로 imageCompressSettings 가 뜨는지 | ☐ |
| IC2 | 창 열기 | ① 그 버튼을 한 번 누른다 ② **이미지 압축 설정** 창이 열리는지 ③ 창이 열린 뒤 화면 잠금(도는 표시)이 풀리는지 | ☐ |
| IC3 | 처음 값 | ① 창 안에 **이미지 압축 옵션 설정** 상자가 있고 그 상자 오른쪽에 켜기/끄기 스위치가 있는지 ② **이미지 압축 활성화** 스위치가 **꺼짐**인지 ③ **이미지 품질 (Quality)** 숫자칸이 **0.5**, 옆의 미는 막대도 가운데쯤인지 | ☐ |
| IC4 | 스위치 두 개 연동 | ① 상자 오른쪽 위 스위치를 켠다 ② 아래 **이미지 압축 활성화** 스위치도 같이 켜지는지 ③ 반대로 아래 스위치를 끄면 위 스위치도 같이 꺼지는지 | ☐ |
| IC5 | 막대·숫자칸 연동 | ① 미는 막대를 좌우로 끌어 본다 ② 숫자칸 값이 같이 바뀌는지 ③ 숫자칸에 `0.2` 를 직접 입력한다 ④ 막대가 그 위치로 옮겨가는지 | ☐ |
| IC6 | 잘못된 값 | ① 숫자칸을 지우고 `2` 를 입력한다 ② 아래 **파란 체크 버튼**(적용)을 누른다 ③ 창이 **닫히지 않고**, 숫자칸이 빨갛게 되며 "0.01 ~ 1 입니다" 안내가 뜨는지 ④ 숫자칸에 `abc` 를 넣고 같은 버튼을 눌러도 똑같이 막히는지 | ☐ |
| IC7 | 저장 | ① 압축 스위치를 **켜고** 숫자칸에 `0.8` 을 넣는다 ② **파란 체크 버튼**(적용)을 누른다 ③ 창이 닫히는지 ④ imageCompressSettings 줄이 **변경된 항목 표시**로 바뀌는지 ⑤ 버튼을 다시 눌러 창을 열었을 때 **켜짐 + 0.8** 이 그대로 남아 있는지 | ☐ |
| IC8 | 처음값으로 되돌리면 값 비움 | ① 창을 열어 압축 스위치를 **끄고** 숫자칸을 `0.5` 로 되돌린다 ② **파란 체크 버튼**(적용)을 누른다 ③ 창을 다시 열면 꺼짐 + 0.5 인지 (원본은 이 경우 저장값을 비운다) | ☐ |
| IC9 | 취소·닫기 | ① 창을 열어 스위치를 켜고 숫자칸을 `0.9` 로 바꾼다 ② 아래 **빨간 X 버튼**(취소)을 누른다 ③ 창을 다시 열었을 때 **바꾸기 전 값 그대로**인지 ④ 창 오른쪽 위 **X** 로 닫아도, 키보드 **ESC** 로 닫아도 같은지 | ☐ |
| IC10 | 볼 수만 있는 상태 | ① 편집을 끝내고 **조회 상태**(편집 아님)로 만든다 ② 같은 버튼을 눌러 창을 연다 ③ **파란 체크 버튼(적용)이 없고**, 스위치·숫자칸·막대가 **눌리지 않는지** ④ 빨간 X 버튼 설명이 "닫기"로 뜨는지 | ☐ |
| IC11 | 되돌리기 | ① IC7 처럼 값을 저장한다 ② 키보드 **Ctrl+Z** 를 누른다 ③ 저장 전 값으로 돌아가는지 | ☐ |
| IC12 | 다른 버튼 확인(부작용) | ① 트리에서 **ROOT** 를 선택한다 ② 속성 목록의 **CSS Link Add · JS Link Add · Web Security Settings** 버튼을 본다 ③ 원본과 같이 **글자 없이 아이콘만** 남았는지 ④ 각 버튼을 눌러 창이 예전처럼 열리는지 | ☐ |
