## 저장이 안 되는 이유 (IC7 보류 근거 — 앱에서 실측, 2026-08-31)

이 속성은 **자료형이 "덩어리 값(object)"** 으로 등록돼 있는데, 창이 저장하는 값은 **글자 한 줄**입니다.
값을 모으기 직전에 도는 **입력값 형식 점검**이 "형식이 안 맞음"으로 판정 → 값을 **기본값(빈칸)으로 되돌립니다.**
그래서 창이 닫혀도 속성 줄에 변경 표시가 안 뜨고, 다시 열면 처음 값만 보입니다.

- 실측 : 이 속성의 자료형 = 덩어리 값 / 우리가 넣는 값 = 글자 → 형식 점검 결과 **맞지 않음**
- **원본도 이 점검 코드가 똑같습니다** — 그래서 원본에서도 저장이 안 됩니다(장군님 실측과 일치)
- 이런 속성을 위한 **예외 처리 자리는 SAP 설정에 한 줄 있는데, 처리할 함수 이름이 비어 있습니다.**
  그 함수가 채워지면 형식 점검을 통과하게 되어 있습니다 → **원작 개발자/서버 쪽 몫**

우리 쪽에서 임의로 형식 점검을 건너뛰게 만들지 않았습니다(원본과 달라지므로).

## 이미 확인한 것 (돌아가는 앱에서 실측, 2026-08-31)

| 확인 | 결과 |
|---|---|
| SAP가 내려준 목록에 등록 | 있음 — 파일 올리기 2종 + 올린파일 목록 1종, 셋 다 같은 처리 파일 지정 |
| 창 열림·문구 | 제목 "이미지 압축 설정" / 상자 "이미지 압축 옵션 설정" / "이미지 압축 활성화" / "이미지 품질 (Quality)" 정상 표시 |
| 처음 값 | 꺼짐 + 0.5 |
| 허용 범위 밖 값 | 창 유지 + 숫자칸 빨강 + "0.01 ~ 1 입니다" 안내, 저장 안 됨 |
| 막대 이동 | 숫자칸 같이 바뀜 (빨간 표시는 다시 적용을 누를 때까지 남음 — 원본과 같음) |
| 숫자칸 | 숫자만 입력됨 / 1 넘게 넣으면 바로 1 로 내려감(★원본에 없는 동작, 장군님 지시) |
| 스위치 2개 | 한쪽 바꾸면 다른 쪽 따라감 |
| 취소 | 값 반영 안 됨 |

남은 것 : **저장(IC7) · 값 비움(IC8) · 되돌리기(IC11) 3건만 보류** — 원본도 저장이 안 되는 상태라 확인 불가.
서버 쪽에 예외 처리 함수가 등록되면 그때 이어서 테스트. 그 외 항목은 모두 통과.
