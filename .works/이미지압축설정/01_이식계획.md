## 1. 원본 확인 결과 (읽기 전용 폴더 `U4A_WS_DESIGN`)

### 1.1 버튼이 도는 길

```
속성 값칸 버튼 누름
  → (로딩표시 켜기 + 단축키 잠금)
  → 공통 "속성값 변경" 처리        design/js/uiAttributeArea.js 1523행 attrChange(_sAttr,"BUTTON",false,false)
  → 되돌리기 이력 저장
  → 전용 예외처리 모듈             design/attributesArea/attrChangeException.js
      · SAP가 내려준 목록(UW13)에서 이 속성줄을 찾음
      · 그 줄이 알려준 경로의 파일을 그때 불러 실행 → 참이면 이후 값처리 통째로 건너뜀
  → design/attributesArea/imageCompress.js (352행) 실행 = 압축 설정 창
```

### 1.2 앱 실측(2026-08-31, 디버그 연결)

| 확인 | 값 |
|---|---|
| SAP 목록에 등록 | **있음** — 파일 올리기(2종)+올린파일 목록(1종) 3줄 모두 같은 파일(`./imageCompress.js`) 지정 |
| 관련 기능 켜짐 | 켜짐 |
| 버튼 모양 지정 | 종류=버튼 / 글자=**없음** / 아이콘=**사진 모양** / 색=**파랗게 채움** |
| 현재 선택 속성줄 | 값 비어 있음, 편집 가능 |

### 1.3 창 안의 내용 (원본 1:1)

- 접었다 펼 수 있는 상자
  - 머리줄 : 제목(메시지 503) + **켜기/끄기 스위치**
  - 항목1 : 굵은 라벨(504) + **켜기/끄기 스위치** ← 머리줄 스위치와 **같은 값**(스위치가 2개)
  - 항목2 : 굵은 라벨(505) + 숫자 입력칸(가로 60) + **좌우로 미는 막대**(0.01~1, 0.01 단위, 손잡이에 값 표시·값 직접 입력 가능)
- 창 : 제목(506), 가로 30%·세로 20%, 드래그·크기조절 O, **최대화 막음**, 헤더에 도움말 문서 버튼(문서번호 000268)
- 버튼 : **적용**(232, 편집 가능할 때만 보임) / **취소**(003 · 조회 상태면 "닫기" 056)

### 1.4 값 처리 (원본 1:1)

- 열 때 : 저장값이 있으면 그대로, 없는 항목은 **기본값**(압축 끔 / 화질 0.5)
- **적용** :
  1. 화질 점검 → 빈칸 / 숫자아님 / 0.01~1 벗어남 이면 **입력칸 빨강 + 안내 문구**, 저장 안 함, 창 유지
     - 원본 문구가 메시지표에 없는 한글 통짜 문장이다 → **원본 그대로 사용**(보고 사항)
  2. 통과하면 화질을 숫자로 바꿈
  3. **전부 기본값(끔+0.5)이면 속성값을 비움**, 하나라도 다르면 설정을 글자로 묶어 저장
  4. 창 닫기 → 속성줄 반영·미리보기 갱신 → 바인딩 팝업 화면 갱신
- **취소** : 아무것도 안 하고 닫기
- 로딩표시·단축키 잠금은 **모든 끝나는 갈래**에서 해제(적용/취소/오류)

## 3. 작업 단계 (단계마다 테스트 후 다음)

### 단계 1 — 버튼 겉모습 원본 맞추기
- 파일 : `www/ws30/ws10_20/js/ws_html5_ws20_attr.js`
- 아이콘 대응표에 **사진 아이콘** 추가
- 버튼 글자 = SAP가 내려준 글자만(비면 아이콘만) ← **결정1 필요**
- **파랗게 채운 버튼** 지정 처리 추가(지금은 노란 테두리 지정만 처리)
- 수용 기준 : 파일 올리기 UI 선택 시 버튼이 **사진 아이콘 하나만 있는 파란 버튼**으로 보임

### 단계 2 — 버튼 누르면 원본과 같은 길로
- 파일 : `www/ws30/ws10_20/js/ws_html5_ws20_attr.js`
- 버튼 클릭 → 기존 5종 분기에 없으면 **공통 속성값 변경 처리**로 넘김(원본 1523행과 동일)
- 전용 예외처리 실행 자리에서, SAP가 알려준 파일이 **원본 UI5 파일이면 우리 화면용 파일로 갈아끼움**
  (원본 파일 손대지 않음 — 갈아끼우기 목록은 내 파일 안에)
- 수용 기준 : 버튼 누르면 "작업중" 안내 대신 우리 창이 열림(단계 3 완료 후 확인)

### 단계 3 — 압축 설정 창 만들기
- 새 파일 : `www/ws30/ws10_20/js/fnImageCompressPopupOpen.js`
- 여는 함수 등록 : `www/ws30/ws10_20/js/fnDialogPopupOpener.js` (기존 팝업들과 같은 방식)
- 만드는 방법 : 공통 자산 사용 — 창틀(공통 대화상자) · 스위치 · 입력칸 · 버튼 · 헤더 드래그 · 가운데 복귀 · 크기조절.
  미는 막대는 공통 부품이 없어, 이미 쓰고 있는 방식(브라우저 기본 막대 + 강조색)을 그대로 쓴다(`ws_html5_ws20_edit.js` 위치 이동 창 전례).
- 창 크기 : 원본 가로 30%·세로 20% 를 그대로. 고정 px 금지, 최소 크기만 둠
- 문구 : 전부 메시지 키 사용(제목 506 / 상자 제목 503 / 라벨 504·505 / 적용 232 / 취소 003 / 닫기 056), 도움말 문서 버튼(000268)
- 조회 상태 : 적용 버튼 숨김 + 스위치·입력칸·막대 비활성 + 취소가 "닫기"
- 값 처리·검증·저장 규칙은 위 1.4 그대로
- 로딩표시/단축키 잠금 : 창이 다 뜬 뒤 해제, 적용·취소·오류 모든 갈래에서 짝 맞추기
