# 저장 · 활성화 · 구문 검사 — 히스토리 (완료분)

## SV — 서버 왕복이 끝나면 왼쪽 UI 트리의 선택 줄을 다시 클릭 (2026-09-03 통과)

> **무엇을 했나** (장군님 지시 2026-09-03)
> - WS20 에서 **저장 · 활성화 · 구문 검사**를 누르면 서버까지 다녀온다. 그 일이 **성공으로 다 끝난 시점**에
>   왼쪽 UI 트리에서 **지금 골라 놓은 줄을 한 번 더 클릭한 것과 같은 상태**로 만든다.
> - 새 동작을 따로 만들지 않았다. **트리 줄을 마우스로 클릭했을 때 도는 그 처리**를 그대로 다시 부른다.
>   그래서 순서가 클릭과 똑같이 간다 — ① 앞서 그려 둔 선택 테두리 지움 ② 오른쪽 맨 위 UI 오브젝트 정보
>   다시 채움 ③ 오른쪽 속성 목록을 통째로 비우고 다시 만들어 다시 그림 ④ 가운데 미리보기 갱신(보고 있던
>   화면 그대로면 손대지 않고, 다른 화면이면 그 화면을 다시 붙임) ⑤ 트리에서 그 줄이 화면 안에 보이도록
>   스크롤 맞춤 ⑥ 바인딩 팝업이 떠 있으면 그 줄도 같이 맞춤 ⑦ 마지막에 미리보기에서 그 UI 에 선택 테두리.
> - 선택된 줄이 없으면 아무것도 하지 않는다.
>
> **어디에 붙였나 — 성공했을 때만**(장군님 확인 2026-09-03)
> - 저장 = 성공 안내가 뜨고 되돌리기 이력까지 비운 뒤 맨 마지막
> - 활성화 = 성공 안내 뒤 맨 마지막
> - 구문 검사 = 서버가 "오류 없음"으로 답한 갈래 안
> - 서버가 오류를 돌려주는 갈래, 저장 후 앞 화면으로 나가기, 저장 후 보기 전용 모드 전환은
>   그 앞에서 이미 빠져나가므로 여기까지 오지 않는다.
