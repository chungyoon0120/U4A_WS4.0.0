## 지금 할 것 — BR23(미리보기 우클릭 "내 패턴"이 오류로 미동작) 수정 확인

**무엇을 고쳤나(쉽게)**: 미리보기에서 UI를 우클릭해 **"내 패턴"**을 고르면, 예전엔 화면에 없는 옛날식 팝업을 만들려다 오류가 나서 **개인화 팝업이 안 열리고 [Critical Error] 팝업**만 떴다. 게다가 화면이 **바쁨 상태(멈춤)와 단축키 잠김**으로 남아 조작이 안 됐다. 이제 **왼쪽 트리에서 이미 잘 되는 그 "내 패턴" 팝업 파일을 먼저 불러온 뒤** 실행하게 바꿔, 오류 없이 개인화 팝업이 뜨고 화면도 정상으로 돌아온다.

> ※ "내 패턴" 메뉴 아이콘은 **저장(디스켓) 모양**이다. 문서(DOCUMENT)/최상위가 아닌 **실제 UI 한 개**를 우클릭해야 이 메뉴가 활성화된다.

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| BR23-1 | 미리보기 우클릭 "내 패턴" → 오류 없이 개인화 팝업 열림 | ① WS20에서 편집 모드로 들어간다. ② 미리보기 영역에서 UI 하나를 **마우스 우클릭** → 메뉴가 뜬다. ③ 메뉴에서 **내 패턴**(저장/디스켓 아이콘) 항목을 고른다. → **[Critical Error] 팝업이 안 뜨고**, **UI 개인화 팝업**이 열린다. | ☐ |
| BR23-2 | 팝업 대상 UI 표시 + 바쁨(멈춤) 해제 | ① BR23-1의 ②③을 수행한다. → 열린 개인화 팝업 **제목에 우클릭한 그 UI 이름**(예: PAGE5 등)이 붙어 표시된다. ② 팝업이 뜬 뒤 화면이 **멈추지 않고**(바쁨 표시 사라짐) 팝업을 조작할 수 있다. | ☐ |
| BR23-3 | 취소해도 화면 안 멈춤(단축키 잠김 해제) | ① BR23-1처럼 개인화 팝업을 연다. ② 팝업을 **닫기(X)/취소**로 닫는다. → 화면이 계속 조작 가능하고, **키보드 단축키도 다시 먹는다**(잠김 잔류 없음). | ☐ |
| BR23-4 | 왼쪽 트리 "내 패턴"과 동일 + 반복 안정 | ① 왼쪽 트리에서 UI를 **우클릭 → 내 패턴**을 골라 열리는 팝업과, 미리보기 우클릭 "내 패턴"으로 열리는 팝업이 **같은 팝업**인지 본다. ② 미리보기에서 "내 패턴"을 **여러 번 반복해서 열고 닫아**도 매번 오류 없이 정상 동작한다(팝업·동작 중복/누적 없음). | ☐ |
| BR23-5 | 왼쪽 트리 "내 패턴" 회귀 없음 | ① 왼쪽 트리에서 UI를 **우클릭 → 내 패턴**을 고른다. → 예전처럼 개인화 팝업이 정상으로 열린다(이번 수정으로 트리 쪽이 깨지지 않았는지 확인). | ☐ |

## 다음 — BR21(미리보기 우클릭 "붙여넣기"가 오류로 미동작) 수정 확인

**무엇을 고쳤나(쉽게)**: 미리보기에서 UI를 우클릭해 **"붙여넣기"**를 고르면, 예전엔 없는 함수를 부르다 오류가 나서 **붙여넣기가 안 되고 [Critical Error] 팝업**만 떴다. 이제 **왼쪽 트리에서 이미 잘 되는 그 붙여넣기를 그대로 쓰게** 바꿔, 오류 없이 새 UI가 들어간다.

> ※ 먼저 UI를 하나 복사해 둬야 붙여넣기 메뉴가 활성화된다(복사가 없으면 붙여넣기 항목이 회색).

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| BR21-1 | 미리보기 우클릭 "붙여넣기" 정상(오류 없음) | ① WS20에서 편집 모드로 들어간다. ② 미리보기 영역에서 UI 하나를 **마우스 우클릭 → 복사**(문서 두 장 겹친 아이콘) 한다. ③ 붙여넣을 자리의 UI를 **마우스 우클릭** → 메뉴가 뜬다. ④ 메뉴에서 **붙여넣기**(클립보드 아이콘) 항목을 고른다. → **[Critical Error] 팝업이 안 뜨고**, 화면이 멈추지 않는다. | ☐ |
| BR21-2 | 붙여넣기로 UI가 실제로 추가됨 | ① BR21-1의 ②③④를 수행한다. → 복사했던 UI가 **그 자리에 새로 추가**된다(하위 UI·속성·설명 포함). ② 왼쪽 트리에도 같은 UI가 추가돼 보인다. ③ 넣을 수 있는 자리(aggregation)가 여러 개면 **선택 팝업**이 뜨고, 하나 고르면 그 자리에 들어간다. | ☐ |
| BR21-3 | 취소·되돌리기 정상(멈춤 없음) | ① BR21-1처럼 붙여넣기를 하다가 aggregation **선택 팝업에서 취소**한다. → 아무것도 안 들어가고 화면이 계속 조작 가능하다(멈춤·오류창 없음). ② 붙여넣기 성공 뒤 **되돌리기(Undo) 한 번**으로 방금 넣은 UI가 통째로 사라진다. | ☐ |
| BR21-4 | 왼쪽 트리 붙여넣기 회귀 없음 | ① 왼쪽 트리에서 UI를 **우클릭 → 복사** 후, 다른 UI를 **우클릭 → 붙여넣기** 한다. → 예전처럼 정상 추가된다(이번 수정으로 트리 붙여넣기가 깨지지 않았는지 확인). | ☐ |

## 완료 대기 — BR20(미리보기 우클릭 "복사"가 오류로 미동작) 수정 확인

**무엇을 고쳤나(쉽게)**: 미리보기에서 UI를 우클릭해 **"복사"**를 고르면, 예전엔 없는 함수를 부르다 오류가 나서 **복사가 안 되고 [Critical Error] 팝업**만 떴다. 이제 **왼쪽 트리에서 이미 잘 되는 그 복사를 그대로 쓰게** 바꿔, 오류 없이 복사되고 미리보기에서 복사한 것을 **붙여넣기**로 넣을 수 있다.

> ※ 확인하려면 붙여넣기 대상(같은 부모 등)이 있어야 한다. 재현 원 보고 대상은 화면 UI 이름 "TOOLBAR6".

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| BR20-1 | 미리보기 우클릭 "복사" 정상(오류 없음) | ① WS20에서 편집 모드로 들어간다. ② 미리보기 영역에서 UI 하나를 **마우스 우클릭** → 메뉴가 뜬다. ③ 메뉴에서 **복사**(문서 두 장 겹친 아이콘) 항목을 고른다. → **[Critical Error] 팝업이 안 뜨고**, 화면이 멈추지 않는다(계속 조작 가능). | ☐ |
| BR20-2 | 복사한 것을 붙여넣기로 확인 | ① BR20-1처럼 UI를 **우클릭 → 복사** 한다. ② 붙여넣을 자리(같은 부모 또는 다른 컨테이너)의 UI를 **우클릭** → 메뉴에서 **붙여넣기** 항목을 고른다. → 복사했던 UI가 **그 자리에 새로 추가**된다(속성·이벤트·설명 포함). 왼쪽 트리에도 추가된다. | ☐ |
| BR20-3 | 여러 번 복사해도 안 멈춤(회귀) | ① 서로 다른 UI들을 골라 **우클릭 → 복사**를 여러 번 반복한다. → 매번 오류창 없이 복사되고, 화면이 계속 조작 가능하다. **[Critical Error]가 안 뜬다.** | ☐ |
