## BR22 — 미리보기 우클릭 "UI 사용위치"가 오류로 화면 멈춤 (2026-08-12 통과)

**무엇을 고쳤나(쉽게)**: 미리보기에서 UI를 우클릭해 **"UI Where use"(UI 사용위치)**를 고르면, 예전엔 "계속하시겠습니까?" 창이 뜨고 **예**를 누르면 없는 옛 팝업을 만들려다 오류가 나서 **[Critical Error] 팝업**만 뜨고 화면이 **멈춤·단축키 잠김**으로 남았다. 이 기능은 전체 앱을 다 뒤지는 무거운 조회라 **일부러 꺼둔** 것이라(왼쪽 트리도 동일), 이제 확인창·팝업·서버 조회 없이 **"서버 부하로 지금은 꺼둔 기능" 안내 글만** 뜨고 화면도 바로 정상으로 돌아온다.

| 코드 | 동작 | 조작·확인 포인트 | O/X |
|---|---|---|---|
| BR22-1 | 미리보기 우클릭 "UI Where use" → 오류·확인창 없이 안내 글만 | 미리보기 UI 우클릭 → UI Where use(돋보기) 선택 → "계속하시겠습니까?"·[Critical Error] 없이 "서버 부하로 현재 비활성화" 안내 글만 | ✅ O |
| BR22-2 | 화면 안 멈춤 + 단축키 다시 먹음 | 안내 글 뒤 화면 안 멈추고 다른 UI 클릭됨, 키보드 단축키 다시 먹음 | ✅ O |
| BR22-3 | 반복해도 안정 | "UI Where use" 여러 번 반복 → 매번 안내 글만, 오류·멈춤 없음 | ✅ O |
| BR22-4 | 왼쪽 트리 "UI Where use"와 안내 글 동일 | 트리에서 우클릭 → UI Where use → 미리보기와 같은 문구(공용 함수라 100% 일치) | ✅ O |

### 수정 위치
- `www/ws30/ws10_20/js/ws_html5_ws20_edit.js` — 트리 안내 처리를 공용 함수(`fnWs20WhereUseNotice`)로 노출. 트리 "UI Where use"도 이 함수를 호출.
- `www/ws30/ws10_20/design/js/callDesignContextMenu.js` — 미리보기 "UI 사용위치"(`contextMenuUiWhereUse`) 본문 교체: 옛 확인창·옛 팝업 로드·서버 조회 제거 → 진입 시 화면잠금·로딩표시 즉시 원복 후 공용 안내 호출. 미리보기 문구 복붙 제거(문구는 트리 한 곳에서만 관리).
- 원인: 미리보기 "UI 사용위치"가 옛 UI5 팝업(`callUiWhereUsePopup.js`)을 로드 → 없는 창 만들기(`sap.m.Dialog`)로 죽고, 진입 시 걸린 로딩표시·단축키 잠김이 잔류. 옛 팝업 원본(KEEP-UI5)은 무수정, 연결 지점만 차단·공용화.
- 검수: `.audit/br22/` — 코덱스·안티 둘 다 통과(지적 0). 노션=수정완료.
