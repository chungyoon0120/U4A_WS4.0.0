# Design Tree UI 삭제 — 테스트 현황판

> 코드 반영은 **앱을 껐다 켜야** 적용됩니다(새로고침 아님).
> 아래 항목들은 화면·미리보기엔 안 보이고 **내부 저장 정보**에만 남던 문제라, 확인은 **개발자도구(F12) 콘솔**에서
> 저장소를 조회해 삭제한 UI가 목록에 남아 있는지로 판정합니다(테스터 계측과 동일 방식).

## 지금 할 것

### BR41 — UI 삭제 시 클라이언트 이벤트·HTML 내용(T_CEVT) 잔존 제거

UI 이벤트에 클라이언트 이벤트 코드(JavaScript)를 넣거나, `sap.ui.core.HTML` UI의 내용(content)을 넣은 뒤
그 UI를 지우면, 화면 트리·미리보기·내부 속성목록에서는 지워지는데 **이벤트·내용 저장소(`oAPP.DATA.APPDATA.T_CEVT`)**
에는 지운 UI 정보가 남던 문제. 부모를 지워 자식이 함께 지워질 때 자식 정보도 남았음.

**공통 확인 방법(콘솔):** 개발자도구(F12) → Console 탭에 아래를 입력해 실행합니다.

```
copy(oAPP.DATA.APPDATA.T_CEVT); console.table(oAPP.DATA.APPDATA.T_CEVT)
```

표에서 지운 UI 이름으로 시작하는 줄(예: `PAGE5NAVBUTTONPRESS`, `BUTTON116PRESS`, `...CONTENT`)이
**남아 있지 않으면 통과**입니다.

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| DE1 | 클라이언트 이벤트(JavaScript) 넣은 UI를 지우면 그 이벤트 정보가 저장소에서 사라짐 | ① 왼쪽 디자인 트리에서 UI를 하나 추가한다(예: 트리 줄 오른쪽 `+` 버튼으로 Page 추가). ② 그 UI를 클릭해 오른쪽 속성 목록을 연다. ③ 이벤트 줄(예: `navButtonPress`)의 코드 편집 아이콘을 눌러 JavaScript Editor 를 연다. ④ 아무 코드나 한 줄 입력하고 저장 버튼을 누른다. ⑤ F12 콘솔에서 위 확인 명령을 실행해 그 이벤트 줄이 **생겼는지** 먼저 본다. ⑥ 왼쪽 트리에서 그 UI를 우클릭 → "삭제"(또는 트리 줄 오른쪽 휴지통 버튼)로 지운다. ⑦ 삭제 확인창에서 확인을 누른다. ⑧ 다시 F12 콘솔에서 확인 명령을 실행 → 그 UI 이벤트 줄이 **사라졌으면 통과**. | ☐ |
| DE2 | 부모 UI를 지우면 함께 지워진 자식 UI의 이벤트 정보도 저장소에서 사라짐 | ① Page UI 를 추가하고, DE1 ③④처럼 Page 이벤트에 클라이언트 코드를 입력·저장한다. ② 그 Page 줄 오른쪽 `+` 버튼으로 하위에 Button UI 를 추가한다. ③ Button 을 클릭해 그 이벤트(예: `press`)에도 클라이언트 코드를 입력·저장한다. ④ F12 콘솔 확인 명령으로 Page·Button 두 이벤트 줄이 **둘 다 생겼는지** 본다. ⑤ 왼쪽 트리에서 **부모 Page** 를 우클릭 → "삭제" 로 지운다(자식 Button 도 함께 사라짐). ⑥ 삭제 확인창에서 확인을 누른다. ⑦ 다시 확인 명령 실행 → Page·Button **두 줄 모두 사라졌으면 통과**(부모뿐 아니라 자식 정보까지). | ☐ |
| DE3 | `sap.ui.core.HTML` UI의 내용(content)을 넣고 지우면 그 내용 정보가 저장소에서 사라짐 | ① 디자인 트리에 `sap.ui.core.HTML` UI 를 추가한다. ② 그 UI 를 클릭해 오른쪽 속성 목록에서 `content` 줄의 편집 아이콘을 눌러 HTML 편집 팝업을 연다. ③ 아무 HTML(예: `<div>test</div>`)이나 입력하고 저장한다. ④ F12 콘솔 확인 명령으로 그 UI 이름 + `CONTENT` 로 된 줄(유형칸 `HM`)이 **생겼는지** 본다. ⑤ 왼쪽 트리에서 그 HTML UI 를 우클릭 → "삭제" 로 지운다. ⑥ 삭제 확인창에서 확인을 누른다. ⑦ 다시 확인 명령 실행 → `...CONTENT`(HM) 줄이 **사라졌으면 통과**. | ☐ |
| DE4 | 여러 개(체크) 한꺼번에 삭제해도 각 UI의 이벤트·내용 정보가 저장소에서 사라짐 | ① DE1 처럼 서로 다른 UI 2개에 각각 클라이언트 이벤트 코드를 입력·저장한다. ② 트리 위쪽에서 편집(Change) 모드로 두고, 각 UI 줄 앞의 체크박스를 켠다. ③ 트리 위 휴지통 버튼(여러 개 삭제)을 누른다. ④ "몇 건 선택됨 / 정말 삭제?" 확인창에서 확인을 누른다. ⑤ F12 콘솔 확인 명령 실행 → 체크했던 UI들의 이벤트 줄이 **모두 사라졌으면 통과**. | ☐ |
