# Design Tree UI 삭제 — 완료 히스토리

## 2026-08-13 — BR26 부모 UI 삭제 시 하위 UI 정보(oAPP.attr.prev) 잔존 (전 항목 통과)

부모 UI(예: HBOX3)를 지우면 화면·미리보기에선 하위 버튼까지 사라지나, 내부 저장정보(`oAPP.attr.prev`)엔
하위 버튼과 각 속성정보가 남아 화면과 내부 상태가 어긋나던 문제.

원본 단건 삭제 함수(`uiDesignArea.js` `designUIDelete`의 재귀 정리부)가 자식부터 재귀로 내부 저장정보를
모두 지우는데, HTML5는 삭제한 최상위 하나만 지웠던 것. 자식 재귀 정리(`_purgePrevSubtree`)를 신규 추가해
단건 삭제·여러 개(체크) 삭제 두 경로에 배선.

수정 파일: `js/ws_html5_ws20_edit.js`(신규 `_purgePrevSubtree` + 단건·멀티 삭제 배선). 백업: `_ws_html5_ws20_edit.js.br26bak`.
검수: 안티 지적(멀티 경로 배선) 반영 / 코덱스 P1(이벤트·설명·바인딩·팝업 수집정보 정리)은 선재·광범위 결손이라 반론→별도 이슈 권고.

| 코드 | 동작 | O/X |
|---|---|---|
| DT1 | 우클릭 "삭제"로 자식 있는 부모를 지우면 하위 UI 정보도 콘솔에서 사라짐 | ✅ O |
| DT2 | 3단 이상 깊은 구조도 손자까지 정보가 안 남음 | ✅ O |
| DT3 | 트리 위 휴지통 버튼으로 체크 삭제해도 하위 정보가 안 남음 | ✅ O |
