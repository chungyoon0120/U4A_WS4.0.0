# macOS 테마 이식 자료 모음 (README)

이 폴더는 기존 애플리케이션에 macOS 스타일 UI를 이식하기 위한 자료 3종을 담고 있습니다. AI(Claude Code 등)에게 이식을 맡길 때 **세 파일을 함께 제공**하세요.

## 파일 구성

1. **`MACOS_THEME_GUIDE.md`** — 디자인 토큰(색·반경·그림자·폰트·포커스링)과 컴포넌트별 정확한 수치.
   → *"어떤 값으로 그리는가"*의 근거. 모든 스타일 값은 여기서 가져옵니다.

2. **`MACOS_ELECTRON_MIGRATION_GUIDE.md`** — Electron + Bootstrap 앱에 이식하는 전략·순서·함정.
   → *"기존 코드베이스에 어떻게 얹는가"*. Bootstrap 리매핑 방식, 트래픽 라이트(창 버튼) 처리, 단계 이식 순서.

3. **`macOS UI Kit (reference).html`** — 살아있는 참조 구현 (오프라인 단일 파일).
   → *"완성된 컴포넌트가 실제로 어떻게 생기고 동작하는가"*. 60여 종의 macOS 컴포넌트가 인터랙티브하게 들어 있습니다.

## AI에게 지시하는 방법 (권장 프롬프트 예시)

> 아래 세 자료를 참조해 우리 Electron+Bootstrap 앱에 macOS 테마를 이식해줘.
> - 스타일 값은 `MACOS_THEME_GUIDE.md`를 따른다.
> - 이식 전략·순서는 `MACOS_ELECTRON_MIGRATION_GUIDE.md`를 따른다(리매핑 우선, 창 크롬은 마지막 Phase).
> - 각 컴포넌트가 어떻게 생기고 동작해야 하는지는 `macOS UI Kit (reference).html`을 열어 확인한다.
> Phase 0부터 시작하고, 각 Phase 종료 시 변경 요약과 함께 멈춰서 확인받아라.

## 참조 HTML 활용 팁 (AI용)

- **브라우저로 열어** 각 컴포넌트의 hover/active/focus/열림 상태를 직접 확인하세요. 정지된 스크린샷보다 코드와 상태 전이를 함께 보는 것이 정확합니다.
- **소스를 읽어** 인라인 스타일 값(그라데이션, 그림자, 반경, 포커스 링)을 그대로 추출하세요. 이 값들은 `MACOS_THEME_GUIDE.md`의 토큰과 일치합니다.
- 왼쪽 사이드바에 전체 컴포넌트 목록이 있습니다: 버튼·컨트롤·입력·드롭다운·탭·테이블(6종)·다이얼로그·트리 테이블·캐러셀·타임라인·토스트·앵커 바·창 크롬·Dock·위젯 등.
- 단, 참조 HTML의 **신호등(트래픽 라이트)은 디자인 목업**입니다. 실제 Electron 앱에서는 네이티브 창 버튼을 쓰세요(마이그레이션 가이드 §5 참조).
