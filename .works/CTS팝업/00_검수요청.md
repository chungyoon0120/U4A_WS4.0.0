# 검수 요청 — BR11 (CTS 팝업 목록 가상 스크롤 전환)

- `www/ws30/ws10_20/js/fnCtsPopupOpen.js`
- 확인 명령: `git --no-pager diff -- www/ws30/ws10_20/js/fnCtsPopupOpen.js`

## 배경 (테스터 이슈 BR11)
- 화면: "CTS 번호" 값도움(F4) 돋보기로 뜨는 **CTS(이관요청) 선택 공통 팝업**(`oAPP.fn.fnCtsPopupOpen`).
- 지적: 결과 목록이 스크롤 밖(안 보이는 영역)까지 전체 행을 DOM 으로 그려서 대용량 시 무겁다 → **보이는 구간만 그리게(가상 스크롤)** 요청. UX 개선(성능).

## 변경 요약 (원본 1:1 유지가 상위 원칙, 이번 건은 "안 보이는 줄 안 그리기"만 목적)
1. **목록 렌더를 공통 가상 스크롤로 전환**: `U4AUI.makeVScroller(oTbWrap, oTbody, { colCount:4, buildRow:_buildRow, getSelKey: r => r.TRKORR })`.
   - 스크롤 컨테이너 = `.u4aCtsTbWrap`(overflow:auto, 다이얼로그 flex 안 bounded height), 행 컨테이너 = `oTbody`.
   - `_renderRows()` 는 `_vs` 있으면 `setRows(aRows)`, 없으면(폴백) 기존처럼 전체 `forEach` 로 그림.
2. **선택 상태를 인덱스 → 행 객체 기준으로 변경**: `oState.iSel`(정수) → `oState.oSel`(행 객체).
   - 이유: 가상 스크롤은 보이는 행만 DOM 에 있어 인덱스 순회(`querySelectorAll("tr")`)로는 선택 강조 유지가 불가 → 키(TRKORR) 기준.
   - `_selectRow(oRow)` → `_applySel()`: `_vs` 있으면 `setSel(TRKORR)+refresh()`, 없으면 보이는 tr 순회(`tr.__row === oState.oSel`).
   - `_accept()` 도 `oState.aRows[oState.iSel]` → `oState.oSel` 로 변경.
3. **빈 목록 안내**(`.u4aCtsEmpty` div)·**건수 라벨**(A73)·**콜백 계약**(선택 행 객체 그대로 전달: TRKORR/AS4TEXT/AS4DATE/AS4TIME/AS4USER/STRKORR)·**날짜/시간 표시 포맷**(표시만, 콜백 데이터 원본 유지)은 **그대로**.
4. 공통 유틸(`U4AUI.makeVScroller`) 미로드 환경(별도창 oDeps 주입 등) 대비 **전체 렌더 폴백** 유지 → 원본 동작 보존.

## 검수 관점 (아래를 중점적으로 봐 달라)
1. **정확성/버그**: `const _vs` 는 `_buildRow`(함수선언, 호이스팅) 참조로 생성하고, `_applySel/_renderRows` 는 `_vs`(const)를 참조한다. 호출 시점(최초 `_loadData→_renderRows` 는 팝업 함수 말미)에는 `_vs` 초기화가 끝나므로 TDZ 문제 없다고 판단 — **맞는지 확인**. 그 외 `iSel` 잔재 참조나 선택 전환 누락은 없는가.
2. **가상 스크롤 소비 정확성**: `makeVScroller` 시그니처(oWrap, oTbody, opt)와 opt(colCount/buildRow/getSelKey) 사용이 정의(`theme/u4a-ui.js` 2044~)와 일치하는가. 스크롤 컨테이너가 bounded height 라 windowing 이 동작하는가.
3. **선택 강조 이중 소스**: `buildRow` 가 `oState.oSel===oRow` 로 aria-selected 를 세팅하고, `makeVScroller._render` 도 `getSelKey` 일치 시 aria-selected 를 세팅한다. 충돌/불일치 가능성은 없는가.
4. **폴백 경로**(`_vs===null`): 전체 렌더 + `tr.__row` 비교 선택강조가 원본과 동일 UX 인가.
5. **누수/정리**: `makeVScroller` 가 oWrap 에 scroll/wheel/ResizeObserver 를 붙인다. 팝업 닫힘(`oDlg.remove()`) 시 컨테이너째 제거되어 정리되는가(별도 해제 불필요 확인). busy 짝(_setBusy on/off)은 이번 변경으로 깨지지 않았는가.
6. **원본 계약 유지**: 콜백으로 넘기는 행 데이터·메시지 키(268/A73/346 등)·확정 흐름(더블클릭 확인질문 → 콜백)이 변경 전과 동일한가.
