## BR11 — 목록 안 보이는 줄까지 다 그림 → 가상 스크롤 전환 (2026-08-11 통과)

**무엇을 고쳤나(쉽게)**: CTS(이관요청) 목록 팝업이 스크롤 밖 안 보이는 줄까지 전부 그려 목록이 많으면 무거웠다. 이제 **보이는 구간만 그리고 스크롤에 따라 갈아끼운다**(공통 가상 스크롤). 곁들여 선택을 순서번호 → 줄 자체(CTS 번호) 기준으로 바꿔, 스크롤로 고른 줄이 화면 밖에 나갔다 와도 파란 강조가 유지된다. 공통 유틸이 없는 환경에선 예전처럼 전체를 그리는 안전장치도 남겨 원본 동작을 보존.

코덱스·안티 검수 6개 관점 모두 통과(막을 문제 없음) + `node --check` 통과.

| 코드 | 동작 | 조작·확인 포인트 | O/X |
|---|---|---|---|
| BR11-1 | 목록 스크롤 정상 | ① "CTS 번호" 돋보기로 목록 팝업 열기 ② 위/아래로 굴리기 → 끊김·빈칸·튐 없이 매끄럽게 | ✅ O |
| BR11-2 | 줄 고르면 위 칸 채워짐 | ① 줄 한 번 누르기 → 파란 강조 + 위쪽 Request No/Short Description 채워짐 | ✅ O |
| BR11-3 | 스크롤해도 고름 유지 | ① 줄 고르기 ② 많이 굴려 화면 밖으로 ③ 다시 그 줄로 → 여전히 파란 강조 | ✅ O |
| BR11-4 | 더블클릭으로 확정 | ① 줄 빠르게 두 번 누르기 ② 확인 창 예 → 팝업 닫히고 "CTS 번호" 칸에 값 | ✅ O |
| BR11-5 | 확인 버튼으로 확정 | ① 줄 한 번 눌러 고르기 ② 오른쪽 아래 파란 체크 버튼 → 닫히고 값 채워짐(★더블클릭과 다른 경로) | ✅ O |

### 수정 위치(참고)
- `www/ws30/ws10_20/js/fnCtsPopupOpen.js` — 목록 렌더를 공통 가상 스크롤(`U4AUI.makeVScroller`)로 전환. 선택을 행 인덱스 → 행 객체/키(TRKORR) 기준으로 변경. 공통 유틸 미로드 시 전체 렌더 폴백(원본 동작 보존). 빈 목록 안내(`.u4aCtsEmpty`)·건수·콜백 계약·메시지 키(268/A73/346)는 그대로.
