# 디자인 트리 우클릭 메뉴 — 히스토리 (완료 이관)

## BR47 — 창(팝업)류 UI 줄 우클릭 시 메뉴가 뜨자마자 사라짐 (전부 통과, 2026-08-18)

원인: 창(Dialog/Popover)류 UI는 미리보기에서 그 창이 열리며 화면 초점을 미리보기로 가져간다.
메뉴가 뜰 때 이미 초점이 미리보기에 있어, 전역 "미리보기로 초점 이동 시 열린 메뉴 닫기" 처리가
곧바로(≈2ms) 메뉴를 지웠다. 시간 맞추기(기다렸다 열기)로는 못 막힘.
수정: ① 우클릭 시 [선택 완료까지 기다림 → 한 박자 → 메뉴 열기]로 원본 순서 복원.
② 메뉴가 뜰 때 메뉴에 화면 초점을 줘, 전역 닫기 로직이 "초점이 미리보기 아님"으로 판정해
건너뛰게 함(공통 파일 미수정, 제 파일에서 해결. 상태 기반이라 PC 속도와 무관).

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| WC1 | 창(대화상자)류 UI 줄 우클릭 시 메뉴 유지 | ① WS20 Design 화면을 연다. ② 디자인 트리에 창(대화상자, Dialog) 종류 UI를 추가한다. ③ 그 줄을 마우스 오른쪽 버튼으로 누른다. → 메뉴가 뜨고 사라지지 않고 유지. | ✅ O |
| WC2 | 다른 창류 UI(팝오버/선택창)도 유지 | ① 팝오버(Popover)/선택 대화상자(SelectDialog)를 추가한다. ② 그 줄을 우클릭한다. → 메뉴 유지. ③ 메뉴 항목 표시 정상. | ✅ O |
| WC3 | 일반 UI(버튼 등) 우클릭 — 회귀 없음 | ① 일반 UI(버튼)를 추가한다. ② 그 줄을 우클릭한다. → 메뉴 정상 표시·유지. | ✅ O |
| WC4 | 우클릭한 줄이 선택+메뉴 위치 | ① 창류 UI 줄을 우클릭한다. → 줄 강조 + 미리보기에 창 열림 + 메뉴가 마우스 자리 근처에 뜸. | ✅ O |
| WC5 | 연속 우클릭 — 메뉴 겹침 없음 | ① 줄 A 우클릭 → 메뉴. ② 곧바로 줄 B 우클릭. → A 메뉴 닫히고 B 메뉴만 하나. | ✅ O |
