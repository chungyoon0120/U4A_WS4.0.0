# 디자인 트리 우클릭 메뉴 — 히스토리 (완료 이관)


## BR61 — 붙여넣기가 막힐 때 이유를 알려주는 안내 (전부 통과, 2026-08-21)

> **무엇을 고쳤나:** 복사한 UI를 **넣을 수 없는 줄**에 붙여넣으면, 원본은 왜 안 되는지 알려주는데
> 이식본은 ① 아무 말도 없거나 ② 붙여넣기와 상관없는 **"파일을 여기에 놓아주세요"** 가 떴다.
> 원본과 똑같이, 넣을 자리 자체가 없으면 **확인 버튼 하나짜리 알림창**으로, 그 밖의 경우엔
> **화면 가운데 잠깐 뜨는 알림**으로 이유를 알려주도록 되돌렸다.
> ※ **앱을 껐다 켜야** 반영된다(새로고침 아님).

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| BR61-1 | 넣을 자리가 아예 없는 줄에 붙여넣기 → **알림창**으로 이유 안내 | ① 앱을 꺼다 켜다 ② 편집(Change) 모드로 열기 ③ 표의 열(Column) 우클릭 → 복사 ④ 화면(Page) 우클릭 → 붙여넣기 ⑤ UI 안 만들어지는지 확인 ⑥ 확인 버튼 알림창 = **"추가 및 이동 가능한 Aggregation이 존재하지 않습니다."** → 아무 안내도 안 뜨면 실패 ⑦ 확인 눌러 닫기 | ✅ O |
| BR61-2 | 나란히 있는 형제끼리 붙여넣기 → **잠긐 뜨는 알림**으로 이유 안내 | ① 앱을 꺼다 켜다 ② 편집(Change) 모드로 열기 ③ VBox 추가 ④ VBox 안에 Label 2개 추가 ⑤ 첫 번째 Label 우클릭 → 복사 ⑥ 두 번째 Label 우클릭 → 붙여넣기 ⑦ UI 안 만들어지는지 확인 ⑧ 화면 가운데 잠긐 뜨는 알림 = **"붙여넣을 수 있는 aggregation이 없습니다."** → "파일을 여기에 놓아주세요" 뜨면 실패 |✅ O |
| BR61-3 | 붙여넣기 막힌 뒤에도 화면이 안 잠긴다 | ① BR61-1 끝난 직후(알림창 닫은 상태) ② 트리에서 아무 줄이나 클릭 → 선택 바뀌는지 확인 ③ 그 줄 우클릭 → 메뉴 뜨는지 확인 ④ BR61-2 끝난 직후에도 ②③ 반복 → 화면이 흐리게 덮인 채 조작 안 되면 실패 |✅ O |
| BR61-4 | (회귀) 넣을 자리가 하나면 그냥 붙는다 | ① VBox 안의 Button 우클릭 → 복사 ② 그 VBox 우클릭 → 붙여넣기 ③ Button이 하나 더 만들어지고 미리보기에도 보이는지 확인 ④ 아무 안내도 안 떠야 정상 |✅ O |
| BR61-5 | (회귀) 넣을 자리가 여럿이면 고르는 창 + 취소 시 "작업 취소" | ① Button 우클릭 → 복사 ② 넣을 자리가 둘 이상인 줄(예: Page) 우클릭 → 붙여넣기 ③ **"Aggregation 목록 - ○○"** 창 뜨는지 확인 ④ 그 창의 **닫기** 클릭 ⑤ UI 안 만들어지고 잠긐 뜨는 알림 = **"작업 취소"** 확인 ⑥ 다시 ② → 자리 고르고 **확인** → 정상으로 붙는지 확인 |✅ O |

## BR47 — 창(팝업)류 UI 줄 우클릭 시 메뉴가 뜨자마자 사라짐 (전부 통과, 2026-08-18)

원인: 창(Dialog/Popover)류 UI는 미리보기에서 그 창이 열리며 화면 초점을 미리보기로 가져간다.
메뉴가 뜰 때 이미 초점이 미리보기에 있어, 전역 "미리보기로 초점 이동 시 열린 메뉴 닫기" 처리가
곧바로(≈2ms) 메뉴를 지웠다. 시간 맞추기(기다렸다 열기)로는 못 막힘.
수정: ① 우클릭 시 [선택 완료까지 기다림 → 한 박자 → 메뉴 열기]로 원본 순서 복원.
② 메뉴가 뜰 때 메뉴에 화면 초점을 줘, 전역 닫기 로직이 "초점이 미리보기 아님"으로 판정해
건너뛰게 함(공통 파일 미수정, 제 파일에서 해결. 상태 기반이라 PC 속도와 무관).

| 코드 | 동작 | 조작·확인 포인트 | O/X(☐) |
|---|---|---|---|
| WC1 | 창(대화상자)류 UI 줄 우클릭 시 메뉴 유지 | ① WS20 Design 화면을 연다. ② 디자인 트리에 창(대화상자, Dialog) 종류 UI를 추가한다. ③ 그 줄을 마우스 오른쪽 버튼으로 누른다. → 메뉴가 뜨고 사라지지 않고 유지. | ✅ O |
| WC2 | 다른 창류 UI(팝오버/선택창)도 유지 | ① 팝오버(Popover)/선택 대화상자(SelectDialog)를 추가한다. ② 그 줄을 우클릭한다. → 메뉴 유지. ③ 메뉴 항목 표시 정상. | ✅ O |
| WC3 | 일반 UI(버튼 등) 우클릭 — 회귀 없음 | ① 일반 UI(버튼)를 추가한다. ② 그 줄을 우클릭한다. → 메뉴 정상 표시·유지. | ✅ O |
| WC4 | 우클릭한 줄이 선택+메뉴 위치 | ① 창류 UI 줄을 우클릭한다. → 줄 강조 + 미리보기에 창 열림 + 메뉴가 마우스 자리 근처에 뜸. | ✅ O |
| WC5 | 연속 우클릭 — 메뉴 겹침 없음 | ① 줄 A 우클릭 → 메뉴. ② 곧바로 줄 B 우클릭. → A 메뉴 닫히고 B 메뉴만 하나. | ✅ O |
