## 무엇을 고쳤나 (2026-09-08)

**증상** — 쇼컷링크 생성 창에서 **U4A 앱 검색 도움말**을 열어 목록을 다 그린 직후
`[Critical Error] ... ResizeObserver loop limit exceeded` 오류창이 뜨고 앱이 꺼졌다.

**원인** — 도움말 목록의 **맨 아래 가로 이동 막대** 길이를 맞추는 코드가,
**크기 변화를 감시하는 장치 안에서 곧바로 길이를 다시 써서** 같은 화면 갱신 안에서
되먹임이 생겼다. 되먹임 경로는 이렇다.

> 막대 길이 늘림 → 아래 칸에 가로 스크롤바가 생김 → 아래 칸 높이가 커짐
> → 위 목록 칸 높이가 줄어듦 → 크기 변화 감시가 다시 울림 → 다시 길이를 씀 → 되풀이

브라우저가 이걸 막으면서 던지는 경고를 이 앱의 **전체 오류 감시**가
**심각한 오류**로 보고 오류창을 띄운 것이다.

**고친 곳** — `www/ws30/ws10_20/js/fnAppF4PopupOpen.js` (백업 `_fnAppF4PopupOpen.js.robak`)

1. 길이 값이 **그대로면 아예 쓰지 않는다** (되먹임의 고리를 끊음)
2. 크기 감시가 울리면 **다음 화면 갱신으로 미뤄서** 쓴다 (같은 갱신 안 되먹임 제거)
3. 바깥에서 표를 새로 그린 뒤 부르는 갱신은 **그대로 즉시 반영** (가로 막대가 늦게 맞는 일 없음)

**실제 앱으로 확인함** (자동)

| 도움말 열었을 때 해당 경고 건수 | **1건 (오류창 발생)** | **0건** |
| 도움말 창 열림 / 그린 줄 수 | 열림 / 20줄 | 열림 / 20줄 |
