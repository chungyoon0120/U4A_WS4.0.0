# 02_audit_agy — BR20 미리보기 우클릭 "복사" 예외로 미동작

## 판정

**통과**

미리보기 영역 우클릭 메뉴의 "복사" 선택 시 런타임에 미정의된 `getUiClientEvent` 호출로 인해 발생하는 예외 및 단축키 잠금 잔류 결함을 해결하기 위해, 이미 정상 동작이 검증된 HTML5 트리 복사(`fnWs20CopyUI`)로의 위임 래퍼를 구성한 설계가 완벽히 구현되었습니다.

## 지적

없음.

## 검수 결과

| 검수 항목 | 결과 | 확인 근거 |
|---|---|---|
| **원인 분석 정확성** | 통과 | 원본 `callDesignContextMenu.js:662` 에서 HTML5 런타임에 로드되지 않는 `oAPP.fn.getUiClientEvent` 함수를 호출하여 TypeError 크래시가 발생하고, 그로 인해 이후의 복사 처리 및 단축키 락 해제(`setShortcutLock(false)`) 코드가 실행되지 못한 채 중단되는 버그 원인을 정확히 짚어냈습니다. |
| **위임 자체완결성** | 통과 | `edit.js`에 이미 정의된 `_copyUI` 함수를 `oAPP.fn.fnWs20CopyUI`로 바르게 노출하고, `getUiClientEvent` 원본의 수집 메커니즘을 1:1로 재현하여 T_CEVT의 클라이언트 이벤트, 속성, 설명 정보를 동봉하여 붙여넣기 모듈과의 데이터 호환성을 완벽히 보장합니다. |
| **잠금(Busy) 대칭성** | 통과 | `prev.js` 내 위임 래퍼에 `try/finally` 예외 보호 장치를 추가하여 복사 연산 중 어떠한 오류가 발생하더라도 `finally` 블록을 통해 단축키 잠금 해제(`oAPP.fn.setShortcutLock(false)`) 및 로컬 Busy 해제(`parent.setBusy("")`)가 무조건 실행되도록 락 대칭성을 완벽히 보장했습니다. |
| **노드 참조 일관성** | 통과 | `prev.js` 래퍼가 원본과 동일하게 `/lcmenu/OBJID` 바인딩 속성으로부터 우클릭 대상 OBJID를 얻고, 라이브 트리 노드(`getTreeData`)를 호출하여 위임 함수로 전달하는 흐름이 안전하게 작동합니다. |
| **fallback 설계** | 통과 | 대상 노드를 얻지 못하는 불확실한 예외적 상황 시에는 원본 `contextMenuUiCopy`로 흐름이 안전하게 복귀(`_origCopy.apply`)하도록 예외 가드를 설계했습니다. |
| **멱등성 및 설치 타이밍** | 통과 | `__ws20CopyDelegate` 플래그 속성을 통해 중복 래핑을 물리적으로 방지하며, 미리보기 모듈 갱신 및 스크립트 로드 콜백 등 이미 다른 메뉴(BR17 등)의 설치 시점으로 검증된 3개 진입점에서 래퍼가 함께 로드되어 안정성이 뛰어납니다. |
| **비침습적 재정의 (Override)** | 통과 | 원본 callDesignContextMenu.js 코드를 임의로 수정하지 않고 호스트 파일(`prev.js` / `edit.js`)만을 활용한 override 패턴으로 패치하여 원본의 안전성을 100% 보존했습니다. |
| **ROOT/APP 가드** | 통과 | ROOT 및 APP UI 노드 복사 시도 시, 원본과 동일하게 복사 연산을 수행하지 않고 락만 정상 해제한 채 종료되는 분기가 정상적으로 유지됩니다. |
