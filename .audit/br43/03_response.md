## 반영 내역
- 파일: `www/ws30/ws10_20/js/ws_html5_ws20_edit.js` (`designAddUIObject`)
  - `_readAttrPreset` await 를 `fnWs20PushUndo()` 앞으로 이동(순서만 교체). 이후 push → clamp(BR43) → 동기 삽입 루프 → 재구성/미리보기/선택 까지 **중간 await 없음** = 원자적.
  - BR43 clamp 자체는 변경 없음(루프 직전 유지).
- 검사: `node --check` 통과. 원본 KEEP-UI5 무수정.

- 6c(WS20 재진입 잠금·세대 토큰): 원본에 없는 방어·선재 공통 결손 → 별건 권고. (참고: UI 추가 팝업 전수 감사에서도 "추가 중 메인 미잠금 → 재진입/이중추가 여지"가 팝업 전반 공통 사안으로 이미 식별됨.)
