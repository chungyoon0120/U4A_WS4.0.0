# BR62 검수 결과 반영·해명 (03)

## 종합 판정

- **코덱스: 수정필요** — P1 1건(되돌리기 중 화면잠금 누락), P2 2건(이동 떼어내기 인자, 실패 전파 안 됨)
- **안티: 수정필요** — P1 2건(이동 떼어내기 인자, 예외 삼킴), P2 1건(스크롤 복원 타이밍)

두 검수가 **같은 지적 2건**(이동 떼어내기 인자 / 실패 전파)에 독립적으로 도달했고, 나머지는 각자 1건씩이다.
**지적 4건 전부 반영**했다. 반론 0건. A(이름 변경)·C(삭제) 선택 앵커, 분류 정확성, 이중 부착 방지,
상·하위 중복 처리, 부모 재렌더 순서, 원본 무수정은 양측 모두 통과.

## 검수 포인트 회신 (요청서 P1~P12)

- **P1 분류 정확성 / P2 이중 부착 / P3 상·하위 중복 / P6 부모 재렌더 순서 / P7 이름 변경 앵커 / P8·P9 삭제 앵커 / P11 원본 무수정** — 양측 통과, 변경 없음.
- **P4 이름 변경 경로** — 위 5번(사실 인정, 별건 권고).
- **P5 폴백 안전성 / P12 오류 삼킴** — 위 2번으로 해소. 이제 부분 갱신 중 어느 단계가 실패해도 예외가 위로 올라가 전체 재생성이 반드시 돈다.
- **P10 재진입·잠금** — 안티는 통과, 코덱스가 "메인 화면 잠금 없음"을 잡아냈다. **코덱스 판정 채택**(원본 소스로 직접 확인) → 위 3번 반영.

## 남은 위험(솔직히 밝힘)

- 엄격 모드로 바꾼 결과, **미리보기 쪽이 한 번이라도 실패하면 그 되돌리기는 전체 재생성으로 넘어간다**(깜빡임 발생). 이는 의도한 계약(반쪽 갱신보다 안전)이지만, 실화면에서 특정 UI가 늘 폴백으로 빠지는지는 테스트로 봐야 한다.
- **실화면 검증 미실시** — 아래 테스트 현황판(BR62-1~14)이 통과해야 최종 완료다. 특히 이번에 고친 이동 되돌리기(BR62-11·12)와 화면잠금(BR62-13)은 새로 추가한 항목이다.
